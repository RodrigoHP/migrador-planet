
# Canvas Rendering & Pagination Specification
Project: PlanetPress → HTML Template Migrator
Module: Editor Canvas
Purpose: Define how the visual Canvas renders paginated documents, including header/footer repetition,
flow layout, dynamic data simulation, and interaction with the template structure.

---

# 1. Canvas Purpose

The Canvas is the **visual representation of the generated HTML template**.

It is NOT the original PDF and NOT the template editor itself.

The Canvas is responsible for:

- Rendering the **final HTML template preview**
- Showing **live layout changes**
- Simulating **real pagination**
- Allowing **element selection**
- Reflecting **template structure changes**

Editing actions happen through:

- Structure Tree
- Inspector panels
- Optional drag interactions

The Canvas is the **visual feedback layer**.

---

# 2. Canvas Rendering Model

The rendering pipeline:

Structure Tree
→ Template State Store
→ HTML Generator
→ Canvas Renderer (iframe)

Example pipeline:

Structure
↓
Template JSON
↓
HTML Generator
↓
iframe DOM

The Canvas renders the HTML inside an **isolated iframe** to avoid style conflicts.

---

# 3. Page Simulation

Documents generated by the template are **paginated**.

Therefore the Canvas must simulate real pages.

Each page is rendered as:

<div class="page">
    <div class="page-header"></div>
    <div class="page-flow"></div>
    <div class="page-footer"></div>
</div>

Multiple pages are rendered vertically.

Example visual representation:

PAGE 1
----------------------
Header
Content
Content
Footer

PAGE 2
----------------------
Header
Content
Footer

---

# 4. Page Dimensions

Page dimensions follow standard print sizes.

Default values:

A4
Width: 794px
Height: 1123px

Margins are configurable in Page Inspector.

Example:

Page Height = 1123px
Header Height = 120px
Footer Height = 80px

Available Flow Space:

1123 - 120 - 80 = 923px

# 7. Flow Content

The Flow section contains dynamic elements:

Examples:

Tables
Text blocks
Charts
Lists

Flow grows vertically.

Example:

<div class="flow">
    Transactions table
</div>

When flow exceeds page space:

Automatic page break occurs.

---

# 8. Pagination Algorithm

Pagination is calculated dynamically.

Pseudo algorithm:

remainingHeight = pageHeight - headerHeight - footerHeight

for each element in flow:

    if element.height <= remainingHeight:
        place element
        remainingHeight -= element.height

    else:
        create new page
        render header
        place element
        remainingHeight = pageHeight - headerHeight - footerHeight - element.height

↓

Tree → Canvas highlight
Canvas → Tree selection

# 12. Element Identification

Each element rendered in the Canvas includes metadata attributes.

Example:

<div
data-template-id="field_cliente"
data-template-type="text"
data-template-parent="header"
>

This allows event mapping.

# 15. Performance Strategy

Large documents must not render all pages.

Strategy:

Render only first N pages.

Example:

Max rendered pages = 5

Additional pages simulated but not rendered.
