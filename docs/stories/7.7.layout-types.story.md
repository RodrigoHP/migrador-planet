# Story 7.7: Layout Types Switching

## Status
Draft

## Story
**As a** operador,
**I want** alternar entre Layout Types via seletor na toolbar e ver todo o editor atualizar (tree, canvas, inspector, confiança, cobertura),
**so that** eu possa trabalhar em cada template de layout independentemente.

## Acceptance Criteria
1. Seletor de Layout Type na toolbar: dropdown com layouts detectados (ex: Capa, Transações, Resumo) (FR37)
2. Seletor mostra nome do layout + contagem de páginas (ex: "Transações (285 pgs em 3 docs)")
3. Alternar layout atualiza: templateStore.documentTree, conteúdo do HTMLCanvas, StructureTree, InspectorPanel, métricas do confidenceStore, métricas do coverageStore
4. Cada Layout Type tem independente: document tree, scores de confiança, dados de cobertura
5. Seletor oculto quando apenas 1 Layout Type detectado
6. Layout ativo persistido em layoutStore.activeLayoutId
7. Transição suave (indicador de carregamento se necessário)
8. Ao alternar Layout Type, edições não salvas do layout anterior são preservadas automaticamente no state (não requer salvamento explícito)
9. Layout Types são populados pelo pipeline de análise (Stories 5.7/5.8) e armazenados em layoutStore durante a fase Analyzing; se pipeline não detectar, layout único padrão é criado
10. `npm run build` passa sem erros
