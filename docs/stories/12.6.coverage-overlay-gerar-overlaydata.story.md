# Story 12.6 — Feat: Coverage Overlay — gerar overlayData no pipeline e renderizar

## Story
**Como** usuário do editor,
**Quero** ativar o modo "Cobertura" e ver quais elementos foram mapeados (verde) ou não (vermelho),
**Para** identificar visualmente quais campos precisam ser revisados.

## Status
Done

## Context

### Problema
O botão "Cobertura" na toolbar existe e tem toggle, mas ao ativar não aparecem highlights no canvas nem no PDF. A overlay fica completamente invisível.

### Root Cause

**`frontend/src/stores/coverageStore.ts`**
```typescript
// Estado que NUNCA é populado:
overlayDataByLayout: Map<string, Record<'canvas'|'pdf', OverlayItemData[]>>
```

**`backend/services/stages/pipeline_result.py`**
```python
# result_json inclui coverage:
coverage = {"layout-id": {"fields": {"mapped": 5, "total": 10}, "percentage": 50}}
# MAS NÃO inclui overlayItems:
# [{node_id, bbox_css, bbox_pdf, status, xsd_path, page_number}]
```

O pipeline retorna apenas os números agregados (5/10 campos), mas NÃO as coordenadas individuais de cada campo para renderizar o overlay.

### Arquitetura de Solução

#### Backend — Adicionar `overlay_items` ao pipeline result

```python
# pipeline_result.py::_get_overlay_items()
def _get_overlay_items(field_mappings, context):
    overlay_items = []
    page_dims = _get_page_dimensions(context)  # {0: (595, 842), 1: (595, 842)}

    for mapping in field_mappings:
        bbox = mapping.get("bbox")
        page_num = mapping.get("page_number", 0)
        if not bbox:
            continue

        page_w, page_h = page_dims.get(page_num, (595, 842))
        SCALE_X = 794 / page_w
        SCALE_Y = 1123 / page_h

        x0, y0, x1, y1 = bbox
        overlay_items.append({
            "node_id": mapping.get("block_id"),
            "xsd_path": mapping.get("xsd_field_path"),
            "label": mapping.get("label_text", ""),
            "value": mapping.get("pdf_text", ""),
            "status": mapping.get("status", "unmapped"),  # mapped|unmapped|ambiguous
            "page_number": page_num,
            # Coordenadas CSS (canvas)
            "bbox_canvas": {
                "left": round(x0 * SCALE_X, 1),
                "top": round((page_h - y1) * SCALE_Y, 1),
                "width": round((x1 - x0) * SCALE_X, 1),
                "height": round((y1 - y0) * SCALE_Y, 1),
            },
            # Coordenadas PDF brutas (para overlay no PDFReference)
            "bbox_pdf": {
                "left": round(x0, 1),
                "top": round(y0, 1),
                "width": round(x1 - x0, 1),
                "height": round(y1 - y0, 1),
            },
        })

    return overlay_items
```

```python
# pipeline_result.py — Incluir em result_json:
result_json = {
    ...
    "overlay_items": {
        layout_id: _get_overlay_items(field_mappings, context)
        for layout_id in layout_ids
    }
}
```

#### Frontend — Carregar overlayData no coverageStore

```typescript
// coverageStore.ts
interface OverlayItemData {
  nodeId: string
  xsdPath: string
  label: string
  value: string
  status: 'mapped' | 'unmapped' | 'ambiguous'
  pageNumber: number
  bboxCanvas: {left: number, top: number, width: number, height: number}
  bboxPdf: {left: number, top: number, width: number, height: number}
}

// session.ts — Adicionar à cadeia de loadFromPipelineResult():
if (result.overlay_items)
  coverageStore.loadOverlayItems(result.overlay_items)

// coverageStore.ts
loadOverlayItems(itemsByLayout: Record<string, OverlayItemData[]>) {
  for (const [layoutId, items] of Object.entries(itemsByLayout)) {
    this.overlayDataByLayout.set(layoutId, {
      canvas: items,  // Todos — usa bboxCanvas
      pdf: items,     // Todos — usa bboxPdf
    })
  }
}
```

#### Frontend — Renderizar no CoverageOverlay.vue

```vue
<!-- CoverageOverlay.vue -->
<template>
  <div class="coverage-overlay" :class="`coverage-overlay--${target}`">
    <div
      v-for="item in visibleItems"
      :key="item.nodeId"
      :class="['coverage-item', `coverage-item--${item.status}`]"
      :style="getItemStyle(item)"
      :title="`${item.label}: ${item.status === 'mapped' ? item.xsdPath : 'não mapeado'}`"
    />
  </div>
</template>

<script setup>
const getItemStyle = (item: OverlayItemData) => {
  const bbox = props.target === 'canvas' ? item.bboxCanvas : item.bboxPdf
  return {
    position: 'absolute',
    left: `${bbox.left}px`,
    top: `${bbox.top}px`,
    width: `${bbox.width}px`,
    height: `${bbox.height}px`,
  }
}
</script>

<style>
.coverage-item--mapped { background: rgba(34, 197, 94, 0.3); border: 1px solid #22c55e; }
.coverage-item--unmapped { background: rgba(239, 68, 68, 0.3); border: 1px solid #ef4444; }
.coverage-item--ambiguous { background: rgba(234, 179, 8, 0.3); border: 1px solid #eab308; }
</style>
```

## Acceptance Criteria

1. **AC1 — Overlay ativo:** Ao clicar "Cobertura", aparecem retângulos coloridos sobre os campos no canvas
2. **AC2 — Cores corretas:** Verde = mapeado (xsd_path), Vermelho = não mapeado, Amarelo = ambíguo
3. **AC3 — Overlay PDF:** Overlay também funciona na aba PDF (sobre o PDF renderizado)
4. **AC4 — Multi-página:** Overlay correto em todas as páginas do documento
5. **AC5 — Tooltip:** Hover sobre overlay mostra nome do campo e XSD path (se mapeado)
6. **AC6 — Toggle:** Botão "Cobertura" liga/desliga o overlay sem refresh
7. **AC7 — Performance:** ≤5ms para renderizar overlay em documento com 50 campos
8. **AC8 — Testes:** Backend testa `_get_overlay_items()` gera coords corretas; frontend testa toggle
