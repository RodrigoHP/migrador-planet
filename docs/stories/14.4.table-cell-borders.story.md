# Story 14.4 — Table Cell Borders (F2)

## Story

**Como** operador do editor de templates,
**Quero** selecionar células individuais da tabela e configurar bordas (top/right/bottom/left), cor de fundo e padding por célula,
**Para** reproduzir fielmente documentos como boletos onde cada célula tem estilo visual distinto (ex: "Beneficiário" com borda grossa embaixo, "Valor" com fundo cinza no header).

## Status

Done

## Context

### Problema

O `TableInspector.vue` atual exibe colunas em modo read-only (campo, largura, alinhamento) e permite configurar propriedades a nível de tabela (row height, padding, paginação, keep together). Não há:

1. **Seleção de célula individual:** Não é possível clicar em uma célula específica da tabela para editá-la
2. **Bordas per-célula:** Bordas são configuráveis apenas a nível de tabela (quando existem), não por célula individual — documentos como boletos têm células com bordas distintas (grossa, fina, nenhuma)
3. **`border-collapse` toggle:** Não existe controle para alternar entre `border-collapse: collapse` e `border-collapse: separate`
4. **Background color por célula:** O InspectorColorPicker existe mas não é usado no contexto de células individuais
5. **Padding por célula:** Padding é configurável apenas a nível de linha (`row_padding`), não por célula

### Estado Atual do Código

**`TableInspector.vue`** (organisms/inspectors/):
- Mostra seções: Geral (nome, binding), Colunas (read-only grid), Linhas (altura, padding), Paginação, Posição, Visibilidade
- Usa `templateStore.updateNodeProperty()` para edições a nível de tabela
- Não tem conceito de célula selecionada nem sub-componente de edição de célula

**`InspectorColorPicker.vue`** (molecules/):
- Componente genérico de color picker com label, swatch e hex display
- Interface: `modelValue: string`, `emit('update:modelValue', value)`
- Reutilizável para background color por célula

**`templateStore.ts`** (stores/):
- `documentTree` com nós tipo `'table'` que contêm propriedades como `columns`, `row_height`, `row_padding`
- `updateNodeProperty(nodeId, key, value)` — precisa ser estendido para suportar paths aninhados (célula dentro de tabela)

**Story 14.2 — Border Editor:**
- Componente `BorderEditor` reutilizável que permite configurar bordas (top/right/bottom/left) com width, style, color
- Este componente DEVE ser reusado para bordas per-célula (não reimplementar)

### Solução Necessária

1. **Seleção de célula:** Clicar em uma célula no canvas (ou na grid de colunas do inspector) seleciona essa célula para edição
2. **TableCellEditor sub-component:** Novo sub-componente dentro do TableInspector que aparece quando uma célula está selecionada
3. **Border per-célula:** Reusar o `BorderEditor` da story 14.2 para cada lado (top/right/bottom/left)
4. **`border-collapse` toggle:** Checkbox a nível de tabela para alternar border-collapse
5. **Background e padding por célula:** Usar InspectorColorPicker e InspectorInput para configurar por célula

### Exemplo Concreto — Boleto Bancário

Tabela do corpo do boleto:
- **"Beneficiário"** — borda grossa embaixo (2px solid #000), sem borda lateral
- **"Agência/Cód. Cedente"** — borda fina (1px solid #999), padding 4px
- **"Valor do Documento"** — borda grossa + fundo cinza (#f0f0f0) no header
- **Separador horizontal** — borda bottom apenas, sem conteúdo

Cada célula tem estilo visual distinto — impossível com configuração única a nível de tabela.

## Acceptance Criteria

1. **AC1 — Seleção de Célula:** Ao clicar em uma célula na visualização de colunas do TableInspector (ou no canvas), essa célula é marcada como selecionada e o sub-componente `TableCellEditor` é exibido com as propriedades da célula
2. **AC2 — Border Per-Célula:** O `TableCellEditor` exibe o componente `BorderEditor` (de story 14.2) permitindo configurar border-top, border-right, border-bottom e border-left individualmente (width em px, style: solid/dashed/dotted/none, color)
3. **AC3 — Border-Collapse Toggle:** Novo checkbox "Border Collapse" na seção "Linhas" do TableInspector, que aplica `border-collapse: collapse | separate` na tabela. Valor default: `collapse`
4. **AC4 — Background Color Per-Célula:** O `TableCellEditor` exibe um `InspectorColorPicker` para definir background-color da célula selecionada. Valor default: transparente
5. **AC5 — Padding Per-Célula:** O `TableCellEditor` exibe 4 inputs numéricos (top/right/bottom/left) ou shorthand para definir padding da célula selecionada, com valores em px
6. **AC6 — Persistência no Store:** Alterações de célula são persistidas no `templateStore.documentTree` sob a estrutura do nó da tabela (ex: `node.properties.cells[row][col].border`, `.backgroundColor`, `.padding`). `pushUndoSnapshot()` é chamado antes de cada mutação
7. **AC7 — Canvas Reflete Mudanças:** Bordas, background e padding configurados por célula são refletidos visualmente no canvas HTMLCanvas em tempo real (sem reload)
8. **AC8 — Sem Regressão:** Todas as funcionalidades existentes do TableInspector (colunas read-only, row height, paginação, visibilidade, keep together) continuam funcionando sem alteração

### Modelo de Dados — Cell Properties

```typescript
// template.types.ts
interface BorderSide {
  width: number    // px
  style: 'solid' | 'dashed' | 'dotted' | 'none'
  color: string    // hex
}

interface BorderConfig {
  top?: BorderSide
  right?: BorderSide
  bottom?: BorderSide
  left?: BorderSide
}

interface CellProperties {
  border?: BorderConfig
  backgroundColor?: string  // hex or 'transparent'
  padding?: {
    top: number
    right: number
    bottom: number
    left: number
  }
}

// No nó table: properties.cells é Record<`${row}-${col}`, CellProperties>
```
