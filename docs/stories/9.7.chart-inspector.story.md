# Story 9.7: Chart Detection + Chart.js Inspector

## Status
Draft

## Story
**As a** operador,
**I want** que o sistema detecte áreas de gráfico nos PDFs e forneça um Chart Inspector para configurar tipo de gráfico, binding de dados, dimensões e estilos, gerando código Chart.js,
**so that** gráficos no documento original sejam reproduzidos como gráficos dinâmicos Chart.js no template.

## Acceptance Criteria
1. Áreas de gráfico detectadas no pipeline (Vision AI) aparecem como nós 📊 Gráfico na StructureTree (FR26)
2. ChartInspector (Level 3) mostra: nome, confiança %, dropdown de tipo de gráfico (Barras, Linhas, Pizza, Rosca, Área, Empilhado) (FR26)
3. Seção de binding de dados: dropdown de campo Labels + lista de Datasets (cada um com: label, dropdown de campo, color picker) (FR26)
4. Botão "+ Adicionar dataset" para múltiplos datasets (FR26)
5. Dimensões: inputs de largura e altura (px)
6. Seção de estilo (colapsável): toggle de legenda, toggle de grid, toggle de animação, label do eixo X, label do eixo Y
7. Preview: mini gráfico renderizado no Inspector usando Chart.js com config atual (FR26)
8. Alta confiança (≥60%): tipo de gráfico pré-selecionado; Baixa confiança (<60%): operador seleciona manualmente (FR26)
9. Fallback: opção "Usar imagem estática" se gráfico não puder ser reproduzido dinamicamente (exporta como PNG) (FR26)
10. Código gerado: `<canvas id="chartName">` no HTML + configuração Chart.js no base.js (FR26)
11. Biblioteca Chart.js referenciada de `../Bibliotecas/js/Chart.min.js`
12. `npm run build` passa sem erros
