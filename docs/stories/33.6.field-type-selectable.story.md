## Story

Como operador do editor de templates,
quero selecionar o tipo de campo (Texto, Número, Moeda, Data, etc.) via dropdown no Inspector,
para que eu possa controlar a formatação do campo.

## Acceptance Criteria

- [x] Badge read-only substituído por dropdown/select
- [x] Opções: Texto, Número, Moeda (BRL), Data, CPF, CNPJ, Percentual, Telefone, Personalizado
- [x] Seleção atualiza `templateStore.updateNodeProperty(id, 'fieldType', value)`
- [x] Tipo influencia formatação no FormatStringEditor

## Tasks

- [x] Substituir InspectorField badge por select dropdown
- [x] Criar CSS para dropdown
- [x] Implementar onFieldTypeChange handler

## Scope
