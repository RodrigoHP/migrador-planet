# Story 14.9 — Copy/Paste + Padding per-Elemento + KO Validation (F15 + F11 + Gap A)

## Story
**Como** usuário do editor visual,
**Quero** copiar/colar elementos, configurar padding individual e ter validação de bindings Knockout.js em comentários,
**Para** acelerar a montagem de templates e evitar erros silenciosos de runtime na exportação.

## Status
Done

## Context

### Problema 1 — Copy/Paste (F15, MEDIO)
O editor não oferece operações de copiar/colar elementos. Para duplicar um elemento o usuário precisa criá-lo do zero e reconfigurar todas as propriedades CSS manualmente. Isso torna a edição lenta e propensa a inconsistências visuais.

### Problema 2 — Padding per-Elemento (F11, MEDIO)
Hoje o padding só existe no `SectionInspector` (nível section). Elementos individuais com `position: absolute` não têm margin funcional (margin não se aplica a position absolute). O que falta é **padding interno** por elemento para controlar o espaçamento do conteúdo dentro do bounding box.

### Problema 3 — KO Comment Validation (Gap A, ALTA)
O `usePreExportValidation.ts` valida bindings `data-bind="text: campo"` contra o XSD, mas **NÃO** valida comentários Knockout.js:
```html
<!-- ko if: secao_xyz -->
<!-- ko foreach: items -->
<!-- /ko -->
```
Se o Stage 5.1 gerar um binding condicional com nome inválido (ex: `secao_xyz` quando o XSD define `SecaoXYZ`), o template exporta sem erro mas **quebra em runtime** no Knockout.js. Isso é um gap de severidade ALTA porque o erro é silencioso.

## Acceptance Criteria

### F15 — Copy/Paste
1. **AC1 — Ctrl+C/Ctrl+V:** Selecionar elemento → Ctrl+C → Ctrl+V cola novo elemento com offset de +10px em X e Y, preservando todas as propriedades CSS
2. **AC2 — Ctrl+D:** Duplicate in-place — cria cópia com offset de 10px sem alterar clipboard
3. **AC3 — Propriedades preservadas:** Cópia herda todas as propriedades CSS do original (position, dimensions, font-family, font-size, color, background, padding, border, etc.)
4. **AC4 — Multi-select:** Ctrl+C com múltiplos elementos selecionados → Ctrl+V cola todos com offsets relativos preservados
5. **AC5 — Undo:** Paste e duplicate registram snapshot no undo stack (`pushUndoSnapshot`)

### F11 — Padding per-Elemento
6. **AC6 — Inspector UI:** `organisms/inspectors/ElementInspector.vue` exibe 4 campos numéricos: padding-top, padding-right, padding-bottom, padding-left (px)
7. **AC7 — Aplicação:** Alteração no padding aplica `padding: Tpx Rpx Bpx Lpx` no style inline do elemento no canvas
8. **AC8 — Persistência:** Padding é salvo na `documentTree` do `templateStore` e restaurado ao reabrir

### Gap A — KO Comment Validation
9. **AC9 — Regex detection:** `usePreExportValidation.ts` detecta comentários KO: `<!-- ko if: path -->`, `<!-- ko foreach: path -->`, `<!-- ko with: path -->`, `<!-- ko ifnot: path -->`
10. **AC10 — Validação contra XSD:** Cada path extraído dos comentários KO é validado contra `knownPaths` do XSD. Path inválido → erro de validação com mensagem clara
11. **AC11 — Nested paths:** Suporta paths com dot notation (`secao.subsecao.campo`) e `$data`, `$parent`, `$root` (estes últimos são válidos sem verificação XSD)
12. **AC12 — Cobertura de testes:** ≥90% de cobertura para os 3 módulos novos/modificados

## Dev Notes

### Copy/Paste — Estratégia de IDs
Ao colar, NUNCA reutilizar `data-node-id` do original. Gerar novos UUIDs para cada elemento colado. Manter referência ao original via `data-cloned-from` (opcional, para debug).

### Padding — Nota sobre margin vs padding
Em `position: absolute`, margin não tem efeito visual significativo (o elemento já está posicionado por coordenadas). O padding interno é o que controla o espaçamento entre o bounding box e o conteúdo de texto. Não adicionar margin no inspector.

### KO Validation — Regex Pattern
```typescript
const koCommentRe = /<!--\s*ko\s+(if|foreach|with|ifnot)\s*:\s*([\w.$]+)\s*-->/g;
// Grupo 1: tipo de binding (if, foreach, with, ifnot)
// Grupo 2: path do binding (ex: "secao_xyz", "items", "dados.cliente.nome")

const KO_INTERNAL_VARS = new Set(['$data', '$parent', '$root', '$index', '$parentContext']);
```
