# Story 8.4: Gerador de Dados Sintéticos + Relatório de Testes

## Status
Draft

## Story
**As a** operador,
**I want** gerar dados de teste sintéticos a partir do XSD (tamanhos pequeno/médio/grande) e ver um relatório de testes com matriz de cobertura,
**so that** eu possa testar o template completamente sem precisar de dados reais.

## Acceptance Criteria
1. **AC1** — Botão "Gerar Sintético" no painel de Dados de Teste com opções de tamanho: pequeno (1 linha), médio (10 linhas), grande (100+ linhas) (FR42, FR2b)
2. **AC2** — Dados gerados correspondem à estrutura do XSD: nomes de campos corretos, tipos corretos, valores sintéticos realistas
3. **AC3** — Valores sintéticos são coerentes: nomes parecem nomes, datas parecem datas, CPFs parecem CPFs, moeda parece moeda
4. **AC4** — Tamanho varia principalmente comprimento de loops/arrays (foco em teste de paginação)
5. **AC5** — Datasets gerados são auto-adicionados à lista de datasets com nomes: synthetic_small, synthetic_medium, synthetic_large
6. **AC6** — Botão "▶ Testar Todos": executa todos os datasets sequencialmente, exibe resultados na aba Report
7. **AC7** — Aba Report: segunda aba do painel inferior (ao lado de "Dados de Teste"); tabela com colunas — Dataset × Páginas × Cobertura × Status (✓ OK, ⚠ Aviso, ❌ Erro)
8. **AC8** — Matriz de cobertura: grid elemento × dataset mostrando quais elementos do template aparecem em cada dataset
9. **AC9** — Execução de cada dataset tem timeout de 30 segundos; se exceder, marca como ⚠ Timeout e prossegue ao próximo
10. **AC10** — Botão "Cancelar" substitui "▶ Testar Todos" durante execução, permitindo interromper a sequência; datasets já executados mantêm seus resultados
11. **AC11** — `npm run build` passa sem erros
