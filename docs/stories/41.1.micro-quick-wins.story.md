## Dev Notes

### SYS-007 — Dead code removal
- Deleted `frontend/src/components/HelloWorld.vue` (Vite scaffold, no imports in codebase).
- No other unused scaffold files found.

### SYS-021 — faker to devDependencies
- Moved `@faker-js/faker` from `dependencies` to `devDependencies` in `frontend/package.json`.
- Confirmed: zero imports of faker in `frontend/src/` (only used in test fixtures).

### DB-010 — Index on jobs.created_at
- Created `idx_jobs_created_at` in migration `20260409100000_micro_quick_wins.sql`.

### DB-013 — FK templates->jobs
- Added `source_job_id uuid` column (nullable) to templates table with FK to `jobs.id` ON DELETE SET NULL.
- Column name follows DB-AUDIT.md recommendation: "add optional source_job_id FK column".
- Nullable to avoid breaking existing data (no orphan risk).

### DB-014 — UPDATE policy for storage
- Added UPDATE policies for both `jobs` and `templates` storage buckets.
- Original migration only had INSERT/SELECT/DELETE.

### REDIS-001 — Key prefix
- All Redis keys now use `migrador:job:{id}` pattern (was `job:{id}`).
- `_KEY_PREFIX = "migrador:"` class constant on RedisJobStore.
- `scan_iter` pattern updated to match new prefix.
- All 22 backend tests pass.

### FE-005 — ConfidenceBadge consolidation
- **NOT A DUPLICATE.** Investigation revealed two distinct components:
  - `atoms/ConfidenceBadge.vue`: accepts `confidence: 'high'|'medium'|'low'` (string enum). Used by FieldMappingTable.
  - `molecules/ConfidenceBadge.vue`: accepts `score: number` (0-1 float). Used by AutoFixPanel.
- Different APIs, different consumers, different visual styles. Consolidation would be a breaking refactor, not a quick win.
- Marked as N/A — original assessment incorrectly identified as duplicate.

### FE-007 — Barrel exports
- Created `frontend/src/composables/index.ts` with all 27 composable exports.
- Includes named function exports and type re-exports from `table-pagination.ts`.

### SEC-002 — DOMPurify upgrade
- Already at v3.3.3 (latest stable). No action needed.
- `htmlSanitizer.ts` verified — uses standard DOMPurify API, no deprecated features.
