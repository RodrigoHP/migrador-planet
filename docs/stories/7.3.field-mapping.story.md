# Story 7.3: Field Mapping Manual

## Status
Draft

## Story
**As a** operador,
**I want** arrastar campos do FieldNavigator para a StructureTree para criar bindings, e mapear manualmente campos que a IA não reconheceu,
**so that** eu possa completar o mapeamento do template.

## Acceptance Criteria
1. Arrastar campo do FieldNavigator → soltar em nó da StructureTree → cria binding (node.binding = field.path) (FR8)
2. Status do campo atualiza: não mapeado → mapeado
3. Quando campo é solto em nó que já tem binding, confirmar substituição
4. Ação "Confirmar" em campos não confirmados: clique confirma auto-mapeamento → status torna-se mapeado
5. "Remover binding" via Inspector ou clique direito no nó da tree → limpa binding, campo retorna a não mapeado
6. Campos ambíguos (múltiplos candidatos do pipeline) mostram indicador; clique abre lista de candidatos para operador escolher
7. Percentual de cobertura atualiza em tempo real conforme campos são mapeados/desmapeados
8. `npm run build` passa sem erros
