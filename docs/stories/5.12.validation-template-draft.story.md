# Story 5.12: Bloco 8: Validação + Template Draft — Consistency, Coverage, HTML/CSS Generation

## Status
Ready for Review

## Story
**As a** bloco do pipeline,
**I want** validar a consistência dos mapeamentos do bloco 7 e gerar um draft HTML/CSS completo para o Canvas,
**so that** o editor possa carregar com um template completo auto-populado.

## Acceptance Criteria
1. Stage 22 — Layout Consistency Validation: validar cruzado skeleton vs resultado final, verificar todos campos XSD contabilizados, verificar que não há mapeamentos órfãos
2. Stage 23 — Template Draft Generation: gerar estrutura HTML (Document > Header > Flow > Footer > elements), CSS (dimensões de página, fontes, posições), bindings Knockout básicos
3. Coverage calculado: elementos mapeados vs total detectado (FR29)
4. Pipeline result JSON: { document_structure, field_mappings[], confidence_scores{}, coverage{}, layout_types[], template_draft{ html, css }, ambiguous_fields[], format_functions[] }
5. Resultado armazenado no Supabase (jobs.result_json) e disponível via GET /api/analyze/{job_id}/result
6. Testes cobrem: regras de validação, estrutura do template draft, pipeline result JSON

## Dev Notes

### Template Draft HTML
```html
<div class="page page-capa" data-layout-type="Capa">
  <div class="header">
    <img src="logo.png" class="logo"/>
    <span data-bind="text: titulo">Extrato</span>
  </div>
  <div class="flow">
    <div class="field-group">
      <span class="label">Nome:</span>
      <span data-bind="text: cliente.nome"></span>
    </div>
    <!-- ko foreach: movimentos -->
    <tr>
      <td data-bind="text: data"></td>
      <td data-bind="text: formatCurrency(valor)"></td>
    </tr>
    <!-- /ko -->
  </div>
  <div class="footer">
    <span data-bind="text: rodape"></span>
  </div>
</div>
```
