# Story 20.2 — Model-Aware Pricing Table

## Story
**Como** operador que quer controlar custos de execucao,
**Quero** uma tabela de pricing por modelo em .aios/cost-config.yaml com budget limits e alert thresholds,
**Para** que o engine possa calcular custo real em USD a partir dos tokens consumidos.

## Status
Draft

## Context

### Problema

Sem uma tabela de pricing por modelo, nao ha como converter token counts em custo monetario. Cada modelo tem precos diferentes por MTok (million tokens) de input e output. O engine precisa dessa referencia para calcular custos reais.

### Design

#### Arquivo .aios/cost-config.yaml

```yaml
pricing:
  models:
    claude-opus-4:
      input_per_mtok: 15.00    # USD per 1M input tokens
      output_per_mtok: 75.00   # USD per 1M output tokens
    claude-sonnet-4:
      input_per_mtok: 3.00
      output_per_mtok: 15.00
    claude-haiku-3.5:
      input_per_mtok: 0.80
      output_per_mtok: 4.00

  fallback_model: "claude-opus-4"  # Usar pricing mais caro se modelo desconhecido

budget:
  per_workflow:
    limit_usd: 50.00             # Budget maximo por execucao de workflow
    alert_thresholds: [0.50, 0.75, 0.90]  # Percentuais para alertas

  per_story:
    limit_usd: 25.00
    alert_thresholds: [0.50, 0.75, 0.90]
```

#### Funcao de Calculo

```
FUNCTION calculate_cost(token_data, pricing_config):
  model_pricing = pricing_config.models[token_data.model]
    OR pricing_config.models[pricing_config.fallback_model]

  input_cost = (token_data.input_tokens / 1_000_000) * model_pricing.input_per_mtok
  output_cost = (token_data.output_tokens / 1_000_000) * model_pricing.output_per_mtok

  RETURN {
    input_cost_usd: input_cost,
    output_cost_usd: output_cost,
    total_cost_usd: input_cost + output_cost,
    model_used: token_data.model,
    pricing_source: "config" or "fallback"
  }
```

#### Fallback para Modelo Desconhecido

Quando o modelo retornado nao esta na tabela de pricing, usar o fallback_model (default: opus, o mais caro). Isso garante que o custo nunca seja subestimado.
