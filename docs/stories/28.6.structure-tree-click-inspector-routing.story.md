# Story 28.6 — StructureTree: click bug fix + inspector routing correto

## Story
**Como** operador navegando pela árvore de estrutura,
**Quero** que clicar em um nó selecione-o no Inspector sem expandir/colapsar a árvore,
**Para** poder inspecionar qualquer nó sem perder o contexto visual da hierarquia.

## Status
Done

## Context

Dois bugs compounding que causam a percepção de "clicar não muda o inspector":

**Bug 1 — `StructureTreeNode.vue:handleClick()` faz select E toggle simultaneamente**

```javascript
// ATUAL — com bug:
function handleClick() {
  emit('select', props.node)        // ← correto: seleciona
  if (hasChildren.value) {
    emit('toggle', props.node.id)   // ← BUG: também colapsa/expande
  }
}
```

O usuário clica em um container node → a árvore colapsa visualmente → essa é a ação dominante. O inspector *muda* mas o usuário está olhando para o collapse e percebe que "não aconteceu nada útil".

O ícone ▶/▼ já tem `@click.stop` separado para toggle — é o comportamento correto. A linha `emit('toggle')` dentro de `handleClick` deve ser removida.

**Bug 2 — `inspectorStore.ts:LEVEL_MAP` mapeia `header`/`footer`/`flow` para `'page'`**

```typescript
// ATUAL — com bug:
const LEVEL_MAP = {
  document: 'page',   // → PageInspector ✓
  header:   'page',   // → PageInspector ← PROBLEMA
  footer:   'page',   // → PageInspector ← PROBLEMA
  flow:     'page',   // → PageInspector ← PROBLEMA
  section:  'section', // → SectionInspector ✓
  text:     'element', // → ElementInspector ✓
  // ...
}
```

`PageInspector` foi construído para o nó raiz `document` e lê propriedades como `size`, `orientation`, `margin_top`, `header_height` — que não existem em nós `header`/`footer`/`flow`. Resultado: inspector abre com todos os campos vazios, parecendo que "não mudou nada".

**Referências de design:**
- Audit completo com código dos bugs: `frontend/docs/epic-28-estrutura-audit.md`
- Wireframes before/after: `frontend/docs/epic-28-estrutura-audit.md` (seção "Redesign Proposto")
- Epic: `docs/epics/epic-28-field-mapping-redesign.md`

**Esta story é desbloqueador:** sem ela, a aba Estrutura não funciona de verdade mesmo com 28.1 completa.

## Dev Notes

### Fix 1 — `StructureTreeNode.vue`

Localizar a função `handleClick` e remover APENAS a linha `emit('toggle')`:

```typescript
// ANTES:
function handleClick() {
  emit('select', props.node)
  if (hasChildren.value) {
    emit('toggle', props.node.id)  // ← REMOVER ESTA LINHA
  }
}

// DEPOIS:
function handleClick() {
  emit('select', props.node)  // apenas seleciona
}
```

**ATENÇÃO:** NÃO tocar no handler do ícone ▶/▼ — ele já funciona corretamente com `@click.stop`. Esta é uma mudança cirúrgica de 3 linhas.

### Implementação — `StructuralNodeInfo.vue`

Novo componente inspector minimalista para nós estruturais que não têm propriedades editáveis:

```vue
<template>
  <div class="structural-node-info">
    <h3 class="inspector-title">{{ humanizedType }}</h3>
    <div class="inspector-fields">
      <div class="inspector-field">
        <span class="inspector-field__label">TIPO</span>
        <span class="inspector-field__value">{{ humanizedType }} ({{ node.type }})</span>
      </div>
      <div class="inspector-field">
        <span class="inspector-field__label">FILHOS</span>
        <span class="inspector-field__value">{{ childCount }} elementos</span>
      </div>
      <div class="inspector-field">
        <span class="inspector-field__label">COM BINDING</span>
        <span class="inspector-field__value">{{ boundCount }} de {{ bindableCount }}</span>
      </div>
    </div>
    <p class="structural-node-info__hint">
      ⓘ Propriedades de layout são configuradas no nó Documento.
    </p>
  </div>
</template>
```

**Props:**
```typescript
interface Props {
  node: TemplateNode  // nó selecionado (header | footer | flow)
}
```

**Computed:**
```typescript
const humanizedType = computed(() => ({
  header: 'Cabeçalho',
  footer: 'Rodapé',
  flow: 'Fluxo',
}[props.node.type] ?? props.node.type))

const childCount = computed(() =>
  props.node.children?.length ?? 0
)

const bindableCount = computed(() =>
  getAllDescendants(props.node).filter(n => n.type === 'text' || n.type === 'field').length
)

const boundCount = computed(() =>
  getAllDescendants(props.node).filter(n =>
    (n.type === 'text' || n.type === 'field') && n.binding
  ).length
)
```
