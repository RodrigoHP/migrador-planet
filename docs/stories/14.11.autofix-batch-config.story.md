# Story 14.11 — AutoFix Batch Accept + Confidence Display (F13 + M8)

## Story
**Como** usuário do editor que usa AutoFix,
**Quero** aceitar sugestões em lote e ver o score de confianca de cada sugestão,
**Para** agilizar a revisão de correções automáticas e tomar decisões informadas sobre quais sugestões aplicar.

## Status
Done

## Context

### Problema
O AutoFix atual opera sugestão por sugestão (accept/reject/skip), o que é lento quando há muitas sugestões similares. O score de confianca já existe no backend mas não é exibido no frontend — o usuário não tem visibilidade sobre a qualidade das sugestões.

### Estado Atual do Código

**`frontend/src/stores/autoFixStore.ts`**
- Array de `fix suggestions` com dados de confianca vindos do backend (não expostos na UI)
- Ações individuais: accept, reject, skip por sugestão

**`frontend/src/organisms/AutoFixPanel.vue`**
- Renderiza lista de sugestões com botões accept/reject/skip por item
- Não agrupa por tipo, não tem operações em lote
- Score de confianca não é exibido

**`frontend/src/stores/templateStore.ts`**
- `pushUndoSnapshot()` — suporte a undo já existe, precisa ser integrado com batch

### Solução

Duas melhorias independentes mas complementares:

1. **F13 — Batch Accept:** botões "Accept All" e "Accept All of Type" com preview e undo
2. **M8 — Confidence Display:** badge visual com score numérico e cor por faixa

## Acceptance Criteria

1. **AC1 — Accept All:** Botão "Accept All" no `AutoFixPanel` aceita todas as sugestões pendentes de uma vez
   - Chama `pushUndoSnapshot()` ANTES de aplicar
   - Aplica todas as sugestões sequencialmente
   - Toast de confirmação com contagem: "N sugestões aplicadas"

2. **AC2 — Accept All of Type:** Botão "Accept All of Type" agrupa sugestões por tipo (ex: spacing, font, alignment)
   - Dropdown ou segmented control para selecionar tipo
   - Aplica apenas sugestões do tipo selecionado
   - Toast com contagem e tipo: "N sugestões de spacing aplicadas"

3. **AC3 — Preview Batch:** Antes de confirmar batch accept, exibir preview resumido
   - Lista de sugestões que serão aplicadas (colapsável se > 5)
   - Contagem por tipo
   - Botão "Confirm" / "Cancel"

4. **AC4 — Undo Batch:** `Ctrl+Z` ou botão undo reverte TODAS as sugestões do batch de uma vez
   - Um único `pushUndoSnapshot()` antes do batch (não um por sugestão)
   - Restaura estado completo pre-batch

5. **AC5 — Confidence Badge:** Cada sugestão no `AutoFixPanel` exibe badge com score de confianca
   - Score numérico visível (ex: "0.85")
   - Cor do badge por faixa:
     - Verde (>0.8): alta confianca
     - Amarelo (0.5-0.8): média confianca
     - Vermelho (<0.5): baixa confianca
   - Tooltip com texto descritivo (ex: "Alta confianca — sugestão segura")

6. **AC6 — Testes:** Cobertura unitária para todas as funcionalidades
   - `autoFixStore` — batch accept, batch accept by type
   - `AutoFixPanel` — renderização de badges, preview modal, botões batch
   - Mínimo 90% de cobertura nas linhas novas
