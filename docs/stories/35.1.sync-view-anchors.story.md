# Story 35.1 — Ancoras de layout no SyncView + selecao sincronizada

- **ID:** 35.1
- **Title:** Ancoras de layout no SyncView + selecao sincronizada
- **Type:** feature
- **Status:** Done

- **Epic:** 35
- **Complexity:** L

## Story

As a template operator, I want to see layout anchors connecting canvas and PDF panels in SyncView, and click elements to highlight their counterparts, so that I can visually verify field positioning accuracy.

## Acceptance Criteria

- [ ] Pipeline retorna `anchors[]` por Layout Type com `{id, label, bbox_canvas, bbox_pdf}`
- [ ] `SyncView.vue` substitui `anchors = []` por consumo de dados reais do store
- [ ] `LayoutAnchor` renderizado em ambos os paineis com posicionamento correto
- [ ] Clique em elemento no painel Canvas destaca bounding box correspondente no painel PDF
- [ ] `syncSelection` conectado a cliques nos iframes via `postMessage`

## Tasks

- [x] Adicionar geracao de anchors no stage5 backend (`_generate_anchors`)
- [x] Estender `PipelineResult` com campo `anchors` por layout type
- [x] Criar tipo `AnchorEntry` em `pipeline.types.ts`
- [x] Adicionar `anchors` ao `coverageStore` (getAnchors, loadAnchors)
- [x] Consumir anchors reais em `SyncView.vue` (substituir `computed(() => [])`)
- [x] Implementar `postMessage` handler para selecao sincronizada nos iframes
- [x] Testes unitarios atualizados (LayoutAnchor refatorado para side prop)

## Scope

**IN:** Backend anchor generation, frontend anchor consumption, selection sync via postMessage
**OUT:** Anchor editing UI, custom anchor creation, connector lines between panels
