# 33.10 — LayerPanel: toggle visibilidade + lock/unlock

- **ID:** 33.10
- **Title:** LayerPanel: toggle visibilidade + lock/unlock
- **Type:** feature
- **Status:** Done
- **Priority:** P1
- **Epic:** 33
- **Complexity:** M

## Story

Como operador do editor de templates,
quero alternar visibilidade e bloqueio de camadas diretamente no LayerPanel,
para que eu possa ocultar elementos temporariamente e impedir edições acidentais.

## Acceptance Criteria

- [x] Botao de visibilidade por camada que alterna visible/hidden
- [x] Botao de lock por camada que alterna locked/unlocked
- [x] Estado locked/visible persiste no `templateStore` como propriedades do nó
- [x] Canvas respeita locked: elemento não é arrastável nem redimensionável
- [x] Canvas respeita hidden: elemento não é renderizado no iframe

## Tasks

- [x] Adicionar botões de visibilidade e lock em cada layer item
- [x] Implementar isHidden/isLocked helper functions
- [x] Implementar toggleVisibility com patchNodeVisibility
- [x] Implementar toggleLock com updateNodeProperty
- [x] Adicionar CSS para action buttons
- [x] Adicionar aria-labels para acessibilidade

## Scope

**IN:** LayerPanel toggle buttons, property persistence, canvas patch
**OUT:** Drag/resize lock enforcement in canvas interaction (reads locked property)

## Dev Notes

- visibility uses VisibilityConfig {mode:'hidden'}/{mode:'always'} for consistency with Story 33.5
- lock uses boolean node.properties.locked
- useCanvasInteraction already checks node.properties.locked for drag/resize
