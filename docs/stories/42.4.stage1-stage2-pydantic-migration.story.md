# Story 42.4 — Stage 1 + Stage 2 Pydantic Migration

## Status: Draft

## Descricao

Migrar os sub-pacotes dos stages 1 e 2 de `dict[str, Any]` para modelos Pydantic tipados. Upgrade de `EnrichedPage.text_blocks`, `images` e `tables` de `list[dict[str, Any]]` para `list[TextBlock]`, `list[ImageInfo]`, `list[TableInfo]` — os modelos já existem em `pipeline_context.py`, apenas não são usados.

## Dev Notes

### Abordagem

1. Ler `pipeline_context.py` para entender modelos existentes: `TextBlock`, `ImageInfo`, `TableInfo`, `EnrichedPage`
2. Cada arquivo: substituir construção de dict por instanciação de modelo
3. Substituir `context["text_blocks"][i]["field"]` por `context.text_blocks[i].field`
4. Rodar mypy no arquivo migrado antes de prosseguir
5. Rodar pytest após cada arquivo

### Padrão de migração

```python
# ANTES
block = {
    "text": "...",
    "bbox": {"x": 0, "y": 0, "w": 100, "h": 20},
    "font_size": 12,
}

# DEPOIS
from models.pipeline_context import TextBlock, BoundingBox
block = TextBlock(
    text="...",
    bbox=BoundingBox(x=0, y=0, w=100, h=20),
    font_size=12,
)
```
