# Story 11.7 — Adicionar UUID validation em analyze.py

## Story
**Como** sistema seguro,
**Quero** que `POST /api/analyze` valide o `job_id` como UUID v4 estrito,
**Para** prevenir path traversal e garantir consistência com a validação já existente em `upload.py`.

## Status
Done

## Context
O audit identificou inconsistência de segurança:
- `upload.py` tem `_validate_job_id()` com regex UUID v4 estrito + verificação de path traversal
- `analyze.py` aceita qualquer string como `job_id` no body JSON sem validação equivalente

```python
# analyze.py — SEM VALIDAÇÃO
class AnalyzeRequest(BaseModel):
    job_id: str  # Qualquer string aceita
```

```python
# upload.py — COM VALIDAÇÃO (padrão correto)
_UUID_RE = re.compile(r"^[0-9a-f]{8}-...-4[0-9a-f]{3}-...")
def _validate_job_id(job_id: str) -> str: ...
```

## Acceptance Criteria

1. **Validação presente** — `POST /api/analyze` rejeita `job_id` que não é UUID v4 com HTTP 400.
2. **Path traversal bloqueado** — Path canonicalization verifica que `TMP_BASE / job_id` resolve dentro de `TMP_BASE`.
3. **Consistência** — A lógica de validação é idêntica (ou reutiliza) a de `upload.py`.
4. **Sem breaking change** — Clientes que enviam UUID v4 válido não são afetados.
5. **Testes** — Teste com job_id inválido (`../etc/passwd`, strings aleatórias) retorna 400.

## Dev Notes

### Módulo compartilhado recomendado
```python
# backend/utils/validation.py
import re
from pathlib import Path
from fastapi import HTTPException

_UUID_RE = re.compile(r"^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$")
TMP_BASE = Path(os.environ.get("JOBS_DIR", "/tmp/jobs"))

def validate_job_id(job_id: str, tmp_base: Path = TMP_BASE) -> str:
    if not _UUID_RE.match(job_id.lower()):
        raise HTTPException(status_code=400, detail="jobId inválido: deve ser UUID v4.")
    resolved = (tmp_base / job_id).resolve()
    if not str(resolved).startswith(str(tmp_base.resolve())):
        raise HTTPException(status_code=400, detail="jobId inválido: path fora do escopo.")
    return job_id
```
