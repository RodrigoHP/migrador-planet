# Story 14.14 — Fix: is_table_cell flag não sempre presente em células de tabela

## Story

**Como** usuário do editor visual,
**Quero** que o Vertical Align apareça no inspector sempre que selecionar uma célula de tabela,
**Para** poder alinhar o conteúdo verticalmente em qualquer célula.

## Status

Done

## Context

Gap identificado no Epic 14 Gap Report (2026-03-28).

`ElementInspector.vue` usa `v-if="isTableCell"` para exibir o controle de Vertical Align. O computed `isTableCell` verifica `node.type === 'table-cell'` ou `node.properties.is_table_cell === true`. O gap é que células criadas via pipeline podem não ter essa flag ou tipo definido, tornando o Vertical Align invisível mesmo em células válidas.

## Acceptance Criteria

1. Todos os nós de célula de tabela gerados pelo pipeline têm `node.type === 'table-cell'` OU `node.properties.is_table_cell === true`
2. `isTableCell` computed em `ElementInspector.vue` detecta corretamente células de tabela em 100% dos casos
3. Vertical Align aparece no inspector ao selecionar qualquer célula de tabela
4. Nós que não são células de tabela continuam sem o controle de Vertical Align
5. Testes unitários cobrem os casos de detecção

## Scope

**IN:** Garantir flag/tipo correto em criação de células; ajustar computed se necessário
**OUT:** Sem mudanças no layout visual do inspector

## Tasks / Subtasks

- [x] Localizar onde nós de célula de tabela são criados (templateStore ou loadFromPipelineResult)
- [x] Verificar como `isTableCell` está implementado em `ElementInspector.vue`
- [x] Identificar o gap: tipo ausente, flag ausente, ou lógica de detecção incompleta
- [x] Corrigir na origem (criação do nó) ou no computed (detecção mais robusta)
- [x] Adicionar/ajustar testes
