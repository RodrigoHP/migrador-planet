# Story 23.9 — Barrier Criticality: Contrafactual Real

## Story
**Como** investigador na Fase 5,
**Quero** que cada barreira falhada tenha criticality scoring real,
**Para** priorizar qual defesa reforcar primeiro.

## Status
Done

## Context

### Problema
Barrier analysis produz tabela "failed/absent" sem criticality. Contrafactual declarado no v6.0 mas nunca aplicado. Nenhum relatorio tem coluna Criticality nem ranking "Fix This First".

### Design
Reescrever barrier analysis na Fase 5 com template obrigatorio:

```
## Swiss Cheese Model — Barrier Analysis

| Camada | Barreira | Status | Criticality | Contrafactual |
|--------|----------|--------|-------------|---------------|
| Code | Guard/validacao | failed/absent/present | HIGH/MED/LOW | "Se apenas este guard existisse, preveniria? {resposta}" |
| Test | Teste unitario/integracao | ... | ... | "..." |
| Static | Linter/type-check | ... | ... | "..." |
| CI/CD | Pipeline check | ... | ... | "..." |
| Monitoring | Log/alerta | ... | ... | "..." |
| Process | Code review/checklist | ... | ... | "..." |

### Criticality Criteria
- **HIGH:** Se APENAS esta barreira funcionasse, o bug seria prevenido
- **MEDIUM:** Reduziria impacto significativamente mas nao preveniria sozinho
- **LOW:** Contribuiria mas nao preveniria

### Fix This First (ordenado por criticality)
1. 🔴 {barreira HIGH} — {acao concreta}
2. 🟡 {barreira MEDIUM} — {acao concreta}
3. 🟢 {barreira LOW} — {acao concreta}
```

Fase 7 DEVE referenciar este ranking ao priorizar fixes defensivos.
