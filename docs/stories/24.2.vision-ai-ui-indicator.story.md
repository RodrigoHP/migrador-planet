# Story 24.2: Exibir custo API em R$ e distinguir Vision AI desabilitado

## Status
Done

## Story
**As a** usuário do sistema,
**I want** ver o custo de API em Reais (R$) e ser avisado quando Vision AI não foi utilizada,
**so that** eu entenda o custo em moeda local e saiba quando a análise rodou em qualidade reduzida.

## Contexto
**RCA:** `rca-2026-03-31-custo-api-zero`
**Depende de:** Story 24.1 (que adiciona `vision_ai_used` no SSE summary)

Atualmente `CompletedSummary.vue:20` exibe `$0.00` (em dólar) tanto quando:
- Vision AI foi chamada e custou zero (improvável, mas possível)
- Vision AI **não foi chamada** (fallback silencioso)

Dois problemas: (1) moeda errada — sistema é BR, usuário espera R$; (2) impossível distinguir "não chamada" de "gratuita".

O backend retorna `api_cost` em USD. A conversão para BRL acontece no frontend com taxa fixa configurável.

## Acceptance Criteria

1. `AnalyzingPage.vue` recebe e armazena `vision_ai_used` do SSE summary em `summaryData`
2. `CompletedSummaryData` inclui campo `visionAiUsed?: boolean`
3. Existe constante `USD_TO_BRL_RATE = 5.70` em `analyzingPageConstantsV2.ts` (configurável)
4. Quando `visionAiUsed === true`:
   - Campo CUSTO API exibe valor convertido em Reais: `R$ X,XX` (ex: `R$ 0,29` para $0.05 USD)
   - Formato brasileiro: vírgula decimal, prefixo `R$`
5. Quando `visionAiUsed === false`:
   - Campo CUSTO API exibe `N/A`
   - Tooltip indica: "Vision AI desabilitado — análise em qualidade reduzida (~75%)"
6. Quando `visionAiUsed` é `undefined` (backend sem a feature):
   - Exibe valor em R$ se `apiCostEstimate` disponível, senão `R$ 0,00` (retrocompatibilidade)
7. Label "CUSTO API" permanece inalterado
8. Testes unitários para os 3 estados: `true`, `false`, `undefined`

## Scope

**IN:**
- `frontend/src/pages/analyzingPageConstantsV2.ts` — adicionar `visionAiUsed?: boolean` em `CompletedSummaryData`
- `frontend/src/pages/AnalyzingPage.vue` — receber `s.vision_ai_used` do SSE e armazenar
- `frontend/src/components/analyzing/CompletedSummary.vue` — distinguir exibição por `visionAiUsed`

**OUT:**
- Não alterar backend (feito em 24.1)
- Não redesenhar o card inteiro — mudança mínima no campo CUSTO API
- Não alterar outros campos do summary
