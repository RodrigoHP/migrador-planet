# Story 9.6: Header/Footer Repetição & Reposicionamento Dinâmico

## Status
Done

## Story
**As a** operador,
**I want** que seções Header e Footer sejam repetidas automaticamente em cada página e que elementos fixos abaixo de conteúdo dinâmico sejam reposicionados automaticamente,
**so that** o template mantenha estrutura consistente em todas as páginas e elementos fixos acompanhem o conteúdo dinâmico.

## Acceptance Criteria
1. Repetição de Header/Footer: seções Header e Footer configuradas como "Repetir em cada página" replicam automaticamente em cada página gerada no Canvas (FR13)
2. SectionInspector: toggle "Repetir em cada página" para Header e Footer, alturas editáveis
3. Layout Engine (de story 9.5) integra repetição de header/footer no cálculo de páginas
4. HTML Generator envolve conteúdo em estrutura de página com header/footer replicados
5. Reposicionamento Dinâmico: elementos fixos abaixo de conteúdo dinâmico (ex: total abaixo de tabela variável) automaticamente reposicionados via função `reposicionarElementoFixo()` no base.js (FR15)
6. Função `reposicionarElementoFixo(el, referenceEl)` gerada no base.js — calcula nova posição baseada no referenceEl
7. Lógica de reposicionamento espelhada no Layout Engine do Canvas
8. Testes cobrem: repetição de header/footer em múltiplas páginas, reposicionamento de elementos fixos
9. `npm run build` passa sem erros
