## Story

**As a** usuario do migrador-planet,
**I want** que os estilos condicionais definidos no editor (cor de texto, cor de fundo, src de imagem/logo) sejam aplicados automaticamente no template exportado em runtime,
**so that** o documento gerado reflita regras visuais dinamicas (ex: cor diferente conforme valor de campo) sem intervencao manual pos-exportacao.

## Acceptance Criteria

1. - [ ] ConditionalStyleSection.vue ja existe — verificar que construtor de regras funciona

4. - [ ] Template exportado aplica estilos condicionais em runtime via `applyConditionalStyle()`
5. - [ ] Preview inline mostrando variacao visual (se nao implementado no existente)

## Dev Notes

### Contexto tecnico

O `baseJsGenerators.ts` ja contem funcoes geradoras que produzem codigo JavaScript ES5 (como strings) para injecao no `base.js` exportado. Exemplos existentes:
- `generateQuebraTabelaFn()` — quebra de tabelas entre paginas
- `generateReposicionarElementoFixoFn()` — reposicionamento de elementos fixos

A nova funcao `generateApplyConditionalStyleFn()` deve seguir o mesmo padrao:
- Retornar string JS (ES5, sem arrow functions, sem const/let)
- Funcao autocontida sem dependencias externas
- Comentario JSDoc no topo da funcao gerada

### Source tree relevante

```
frontend/src/

    __tests__/reposition.spec.ts ← padrao de testes existentes

```

### Padrao do gerador (referencia)

Cada funcao geradora retorna um array de strings joined por `\n`. A funcao gerada deve:
1. Receber parametros simples (elemento, regras, dados)
2. Iterar regras e avaliar condicoes
3. Aplicar propriedades CSS diretamente no elemento
4. Para `src` de imagem: localizar `<img>` dentro do elemento e trocar `src`

### Testing

- **Localizacao:** `frontend/src/stores/__tests__/` para testes do gerador
- **Framework:** Vitest
- **Padrao:** Testar que a string JS gerada eh valida (eval/new Function) e produz resultado correto
- **Cobertura minima:** Cada operador condicional + cada propriedade CSS
- **Testes de integracao:** `frontend/src/composables/useExport.spec.ts` — verificar inclusao no export
