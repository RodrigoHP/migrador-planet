# Story 13.5 — Stage 2: Deep Extraction (Só Representativas)

## Story
**Como** pipeline de migração,
**Quero** extrair dados completos (texto, fontes, imagens, tabelas, elementos visuais) apenas das páginas representativas,
**Para** reduzir o tempo de extração de ~20min (100 páginas) para ~10s (~6 representativas).

## Status
Done

## Context

### Pipeline Atual
28 stages extraem dados de TODAS as páginas. Stages 2-6 + 17-18 fazem: text extraction, reconstruction, font mapping, image extraction, screenshots, grid detection, table detection/structuring.

### Pipeline v2
1 stage (`stage2_deep_extraction.py`) com 9 sub-steps. Processa SÓ `representative_pages` do Stage 1. Adiciona: `span["flags"]` (bold/italic), `span["color"]`, `get_drawings()`, `find_tables()` (PyMuPDF), Jenks Natural Breaks, Quality Check.

## Acceptance Criteria

1. Só processa `representative_pages` (não todas as páginas)
2. **2.1:** `get_text("dict")` + `page.rect` (width/height) + `span["flags"]` (bold=bit4, italic=bit1, mono=bit3)
3. **2.2:** Text Reconstruction com threshold proporcional ao `font_size` + `sub_spans[]` preservando rich text inline
4. **2.3:** Font→CSS com FONT_MAP expandido (~50 fontes) + span flags para bold/italic
5. **2.4:** Image Extraction: filtrar masks, validar bbox, marcar `bbox_valid=False` se bbox=(0,0,0,0)
6. **2.5:** Screenshot: SÓ representativas, `alpha=False` (fundo branco garantido), 150 DPI
7. **2.6:** Grid Detection via Jenks Natural Breaks (`jenkspy`), excluindo header/footer zones
8. **2.7:** Table Detection via PyMuPDF `find_tables()` (ruling lines + clustering built-in), multi-tabela por página
9. **2.8:** Table Structuring: cells com bbox individual, merge multi-page (% page height, não hardcoded), multi-row header com `header_row_count`
10. **2.9:** Extraction Quality Check (5 validações): text_blocks não vazios, encoding OK, sem duplicatas, tabelas válidas, imagens com bbox
11. `get_drawings()` → `drawn_elements[]` (type, bbox, orientation, fill_color, stroke_color, width)
12. `span["color"]` → `color` obrigatório em TextBlock (default 0 = preto)
13. Output conforme contrato 3.2 (enriched_documents + extraction_warnings)
14. ~10s para ~6 representativas
15. PyMuPDF ≥ 1.23.0 verificado no startup
