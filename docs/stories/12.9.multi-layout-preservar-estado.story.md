# Story 12.9 — Feat: Multi-layout — preservar estado por layout ao alternar

## Story
**Como** usuário do editor com documento multi-layout,
**Quero** que ao alternar entre layouts, cada um preserve seu próprio estado de seleção e canvas,
**Para** trabalhar em vários layouts sem perder configurações.

## Status
Done

## Context

### Problema
Quando um documento tem múltiplos layout types (ex: "capa" e "corpo"), alternar entre eles via dropdown não preserva:
- Elemento selecionado no inspector
- Posição do scroll do canvas
- Zoom level
- Campos selecionados no FieldNavigator

### Root Cause

**`frontend/src/stores/layout.ts`**
```typescript
function setActiveLayout(id: string) {
  this.activeLayoutId = id  // ← Apenas muda o ID
  // NÃO salva estado do layout anterior
  // NÃO restaura estado do novo layout
}
```

### Solução

```typescript
// layout.ts — Estrutura de estado por layout:
interface LayoutState {
  selectedNodeId: string | null
  canvasScrollX: number
  canvasScrollY: number
  zoomLevel: number
  selectedFieldId: string | null
}

// Adicionar ao store:
layoutStates: Map<string, LayoutState> = new Map()

function setActiveLayout(newId: string) {
  // 1. Salvar estado atual
  const currentId = this.activeLayoutId
  if (currentId) {
    this.layoutStates.set(currentId, {
      selectedNodeId: inspectorStore.selectedNode?.id ?? null,
      canvasScrollX: editorStore.canvasScrollX,
      canvasScrollY: editorStore.canvasScrollY,
      zoomLevel: editorStore.zoomLevel,
      selectedFieldId: mappingStore.selectedFieldId,
    })
  }

  // 2. Mudar layout
  this.activeLayoutId = newId

  // 3. Restaurar estado salvo (ou defaults)
  const saved = this.layoutStates.get(newId)
  if (saved) {
    if (saved.selectedNodeId)
      inspectorStore.selectNodeById(saved.selectedNodeId)
    editorStore.setScroll(saved.canvasScrollX, saved.canvasScrollY)
    editorStore.setZoom(saved.zoomLevel)
    if (saved.selectedFieldId)
      mappingStore.selectField(saved.selectedFieldId)
  } else {
    // Defaults ao entrar em layout pela primeira vez
    inspectorStore.clearSelection()
    editorStore.setScroll(0, 0)
    // Manter zoom atual
  }
}
```

## Acceptance Criteria

1. **AC1 — Preservação:** Selecionar elemento em Layout A, trocar para Layout B, voltar para A → elemento ainda selecionado
2. **AC2 — Scroll:** Scroll position preservada por layout
3. **AC3 — Campos:** Campo selecionado no FieldNavigator preservado por layout
4. **AC4 — Primeiro acesso:** Acessar layout pela primeira vez: seleção limpa, scroll no topo
5. **AC5 — Single layout:** Com documento de 1 layout, comportamento inalterado
6. **AC6 — Testes:** Testa save/restore de estado entre 2 layouts
