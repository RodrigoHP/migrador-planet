# Story 14.5 — Alignment Tools: Ferramentas de Alinhamento Visual

## Story
**Como** usuário do editor visual,
**Quero** ferramentas de alinhamento (horizontal, vertical e distribuição) que aparecem ao selecionar 2+ elementos,
**Para** posicionar campos com precisão — como alinhar colunas "Data Emissão | Número do Documento | Espécie" horizontalmente com espaçamento uniforme.

## Status
Done

## Context

### Problema
Ao posicionar elementos no canvas (drag & drop, story 12.7), o usuário precisa alinhar múltiplos campos manualmente pixel a pixel. Não existe ferramenta de alinhamento em lote — o que torna impossível criar layouts profissionais com colunas alinhadas e espaçamento uniforme.

### Funcionalidade Necessária

#### 1. Alinhamento Horizontal (3 operações)
- **Align Left:** Todos os elementos recebem `x = min(x)` dos selecionados
- **Align Center (H):** Todos os elementos centralizam em `avgCenterX = avg(x + width/2)`
- **Align Right:** Todos os elementos recebem `x = max(x + width) - width`

#### 2. Alinhamento Vertical (3 operações)
- **Align Top:** Todos os elementos recebem `y = min(y)` dos selecionados
- **Align Middle (V):** Todos os elementos centralizam em `avgCenterY = avg(y + height/2)`
- **Align Bottom:** Todos os elementos recebem `y = max(y + height) - height`

#### 3. Distribuição Uniforme (2 operações)
- **Distribute Horizontally:** Espaçamento uniforme entre elementos (ordenados por x)
- **Distribute Vertically:** Espaçamento uniforme entre elementos (ordenados por y)

#### 4. Toolbar Contextual
Toolbar aparece acima da seleção quando `multiSelection.size >= 2`. Contém 8 botões com ícones. Desaparece ao desselecionar.

### Exemplo Concreto
3 campos de um boleto: "Data Emissão" (x=100, y=50), "Número do Documento" (x=300, y=55), "Espécie" (x=520, y=48).
- **Align Top:** Todos recebem y=48
- **Distribute Horizontally:** Espaçamento uniforme entre os 3 campos

## Acceptance Criteria

1. **AC1 — Align Left/Center/Right:** Com 3+ elementos selecionados, ao clicar "Align Left", todos se movem para x = min(x) dos selecionados. "Align Center" centraliza no ponto médio horizontal. "Align Right" alinha pela borda direita
2. **AC2 — Align Top/Middle/Bottom:** Com 3+ elementos selecionados, ao clicar "Align Top", todos se movem para y = min(y). "Align Middle" centraliza verticalmente. "Align Bottom" alinha pela borda inferior
3. **AC3 — Distribute Horizontally:** Com 3+ elementos, "Distribute H" calcula espaçamento uniforme entre o primeiro e último elemento (ordenados por x). Espaço entre cada par é igual
4. **AC4 — Distribute Vertically:** Idem para eixo Y (ordenados por y)
5. **AC5 — Toolbar Contextual:** Toolbar aparece flutuante acima da seleção quando `multiSelection.size >= 2`. Contém 8 botões (6 align + 2 distribute). Desaparece ao limpar seleção
6. **AC6 — Undo Support:** Cada operação de alinhamento é atômica para undo — um Ctrl+Z desfaz toda a operação (não elemento a elemento)
7. **AC7 — Distribute mínimo 3:** Botões de Distribute ficam desabilitados quando há apenas 2 elementos selecionados (alinhamento funciona com 2+, distribuição precisa de 3+)
8. **AC8 — Testes:** Unitários para todas as 8 funções de alinhamento + teste de toolbar visibility toggle
9. **AC9 — Acessibilidade Toolbar:** AlignmentToolbar acessível via teclado — Tab navega entre botões, Enter/Space aciona ação. Container tem `role="toolbar"` com `aria-label="Ferramentas de alinhamento"`. Cada botão tem `aria-label` descritivo (ex: "Alinhar à esquerda"). Botões de Distribute disabled têm `aria-disabled="true"` e `title="Selecione 3+ elementos"`. Focus indicator visível (outline 2px)

## Dev Notes

### Algoritmo de Distribuição Horizontal
```typescript
function distributeH(boxes: Map<string, BoundingBox>): Map<string, { dx: number; dy: number }> {
  const sorted = [...boxes.entries()].sort((a, b) => a[1].x - b[1].x)
  if (sorted.length < 3) return new Map()

  const first = sorted[0]![1]
  const last = sorted[sorted.length - 1]![1]
  const totalWidth = sorted.reduce((sum, [, b]) => sum + b.width, 0)
  const totalSpace = (last.x + last.width) - first.x - totalWidth
  const gap = totalSpace / (sorted.length - 1)

  const deltas = new Map<string, { dx: number; dy: number }>()
  let currentX = first.x + first.width + gap

  for (let i = 1; i < sorted.length - 1; i++) {
    const [id, box] = sorted[i]!
    deltas.set(id, { dx: currentX - box.x, dy: 0 })
    currentX += box.width + gap
  }

  return deltas
}
```
