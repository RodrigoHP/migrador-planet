# Story 41.13: BarcodeInspector — atualizar display de código gerado

## Status
Done

## Story
**As a** operador,
**I want** ver o código gerado correto no BarcodeInspector após a unificação JsBarcode (Story 41.9),
**so that** a referência exibida no Inspector reflita o formato real do template e não induza a erro.

## Context

Story 41.9 mudou o formato de geração de barcodes:

| | Antes | Depois |
|-|-------|--------|
| HTML (stage5) | `<svg id="barcode-1"></svg>` | `<div id="barcode-1" data-type="barcode" data-format="CODE128" data-value="...">` |
| base.js | `JsBarcode("#barcode-1", ko.unwrap(data.campo), {...})` | igual — sem mudança |

`BarcodeInspector.vue` ainda exibe o formato antigo (`<svg>`), tornando a referência incorreta para o operador.

## Acceptance Criteria

- [x] AC1: Seção "código gerado" do `BarcodeInspector.vue` exibe o novo formato HTML:
  ```html
  <div id="{nodeId}"
       data-type="barcode"
       data-format="{format}"
       data-value="{previewValue}">
  </div>
  ```
- [x] AC2: Seção base.js permanece igual (sem mudança — `JsBarcode(...)` call correto)
- [x] AC3: `BarcodeInspector.spec.ts` — teste do display atualizado para verificar o novo formato

## Scope

**IN:**
- `BarcodeInspector.vue` — computed `generatedHtml`, seção HTML do display
- `BarcodeInspector.spec.ts` — atualizar snapshot/assertion do display

**OUT:**
- Lógica de geração real (`barcodeCodeGen.ts`) — não alterar
- `stage5_template_generation.py` — não alterar
- `useExport.ts` — não alterar

## Dev Notes

### BarcodeInspector.vue — computed generatedHtml

```typescript
// ANTES
const generatedHtml = computed(() => {
  const htmlTag = `<svg id="${barcodeId.value}"></svg>`
  const jsInit = `JsBarcode("#${barcodeId.value}", ko.unwrap(data.${field}), {...})`
  return `<!-- HTML -->\n${htmlTag}\n\n<!-- base.js -->\n${jsInit}`
})

// DEPOIS
const generatedHtml = computed(() => {
  const field = localField.value || 'fieldName'
  const format = localFormat.value
  const lineWidth = localLineWidth.value
  const height = localHeight.value
  const displayValue = localDisplayValue.value

  const htmlTag =
    `<div id="${barcodeId.value}"\n` +
    `     data-type="barcode"\n` +
    `     data-format="${format}"\n` +
    `     data-value="">\n` +
    `</div>`

  const jsInit =
    `JsBarcode("#${barcodeId.value}", ko.unwrap(data.${field}), ` +
    `{ format: "${format}", lineColor: "#000", width: ${lineWidth}, height: ${height}, displayValue: ${displayValue} })`

  return `<!-- HTML -->\n${htmlTag}\n\n<!-- base.js -->\n${jsInit}`
})
```
