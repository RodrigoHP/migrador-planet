# Story 12.8 — Feat: Template — seleção automática e badge dinâmico

## Story
**Como** usuário do editor,
**Quero** que o sistema sugira ou selecione automaticamente um template baseado no documento analisado,
**Para** não precisar configurar manualmente o ponto de partida.

## Status
Done

## Context

### Problema
O badge no topo esquerdo sempre mostra "Sem template" mesmo após análise bem-sucedida do PDF. Não existe lógica que selecione ou sugira um template baseado no tipo de documento detectado.

### O que é um "Template" aqui?
- Template = layout base HTML/CSS pré-definido para um tipo de documento
- Exemplos: `boleto-bancario.html`, `nota-fiscal.html`, `relatorio-financeiro.html`
- Hoje: nenhum template existe; o pipeline gera HTML do zero

### Solução de Curto Prazo (Esta Story)
Não criar sistema completo de templates. Objetivo:
1. Detectar tipo de documento durante o pipeline
2. Exibir o tipo detectado no badge (em vez de "Sem template")
3. Preparar estrutura para futuro sistema de templates

### Solução

#### Backend — Detectar tipo de documento

Stage 22 (Vision Self-Check / Semantic Analysis) já identifica o tipo geral. Adicionar `document_type` ao result_json:

```python
# pipeline_result.py
def _get_document_type(context):
    """Extrai tipo de documento do contexto de análise semântica."""
    # Verificar stage 22 (vision) ou stage 19 (semantic)
    semantic_result = context.get("semantic_analysis") or {}
    doc_type = semantic_result.get("document_type") or "desconhecido"

    # Fallback: análise heurística do texto
    if doc_type == "desconhecido":
        all_text = _get_all_text(context)
        if any(kw in all_text.lower() for kw in ["boleto", "cobrança", "vencimento", "beneficiário"]):
            doc_type = "boleto-bancario"
        elif any(kw in all_text.lower() for kw in ["nota fiscal", "nfe", "cnpj do emitente"]):
            doc_type = "nota-fiscal"
        elif any(kw in all_text.lower() for kw in ["recibo", "comprovante"]):
            doc_type = "recibo"

    return doc_type

# result_json["document_type"] = _get_document_type(context)
```
