# Story 14.13 — Visibility↔multiDocStore Sync + AutoFix Limit Env Var (Gap B + Gap C)

## Story
**Como** operador de templates,
**Quero** que ao mudar visibilidade de uma seção (Always → Conditional) o multiDocStore seja notificado automaticamente, e que o limite de AutoFix seja configurável via variável de ambiente,
**Para** que DiffViewer e VariationMatrix reflitam mudanças de visibilidade em tempo real, e que o limite de AutoFix possa ser ajustado por ambiente sem recompilação.

## Status
Done

## Context

### Gap B — Visibility↔multiDocStore Sync (MEDIA)

**Problema:** Quando o operador muda a visibilidade de uma seção (Always → Conditional) no `VisibilityControl.vue`, o `multiDocStore` NÃO é notificado. O `DiffViewer` e a `VariationMatrix` não atualizam, criando inconsistência entre o estado visual e o estado de variações do documento.

**Fluxo quebrado:**
```
VisibilityControl (templateStore) ←→ multiDocStore (variações)  ← NÃO CONECTADO
```

**Fluxo esperado:**
```
VisibilityControl altera mode → watcher detecta → multiDocStore.addDetection() → DiffViewer/VariationMatrix atualizam
```

### Gap C — AutoFix Limit Hardcoded (BAIXA) — EXCLUSIVE OWNER

**Problema:** `SESSION_RUN_LIMIT = 3` está hardcoded no `autoFixStore.ts`. Deveria ser configurável via `VITE_AUTOFIX_LIMIT`.

**Ownership:** Story 14.13 é a ÚNICA responsável por implementar Gap C (autofix execution limit/guard). Nenhuma outra story (incluindo 14.11) implementa esta correção.

### Arquivos Existentes
- `frontend/src/molecules/VisibilityControl.vue` — toggling de modo de visibilidade (Always/Conditional)
- `frontend/src/stores/multiDocStore.ts` — `addDetection()`, variações, integração com DiffViewer
- `frontend/src/stores/autoFixStore.ts` — `SESSION_RUN_LIMIT = 3`
- `frontend/src/organisms/DiffViewer.vue` — exibe variações do documento
- Stack: Vue 3, TypeScript, Pinia, Vitest

## Acceptance Criteria

1. **Watcher de visibilidade:** `VisibilityControl.vue` dispara `multiDocStore.addDetection()` ao mudar mode para `conditional`
2. **Payload correto:** Detection inclui `type: 'optional'`, `description` com label do nó, `confidence: 1.0`
3. **DiffViewer atualiza:** Após mudança de visibilidade, `DiffViewer.vue` mostra a nova variação em < 500ms
4. **VariationMatrix atualiza:** A matriz reflete a nova seção condicional
5. **Bidirecional:** Se operador volta de Conditional → Always, a detection é removida/atualizada no multiDocStore
6. **AutoFix limit env var:** `SESSION_RUN_LIMIT` lê de `import.meta.env.VITE_AUTOFIX_LIMIT` com fallback para `5`
7. **Env var validação:** Se `VITE_AUTOFIX_LIMIT` contém valor não-numérico, usa fallback `5` sem erro
8. **Testes unitários:** >= 90% cobertura nos watchers novos e na lógica de env var
9. **Sem regressão:** Testes existentes de VisibilityControl, multiDocStore e autoFixStore continuam passando

## Dev Notes

### Implementação do Watcher (Gap B)

```typescript
// VisibilityControl.vue — onModeChange
watch(() => props.visibility?.mode, (newMode, oldMode) => {
  if (newMode === 'conditional' && oldMode !== 'conditional') {
    const multiDocStore = useMultiDocStore()
    multiDocStore.addDetection({
      type: 'optional',
      description: `Seção "${nodeLabel}" marcada como condicional pelo operador`,
      confidence: 1.0,
    })
  }
  if (newMode === 'always' && oldMode === 'conditional') {
    const multiDocStore = useMultiDocStore()
    // remover detection correspondente
    multiDocStore.removeDetectionByLabel(nodeLabel)
  }
})
```

### Implementação do Env Var (Gap C)

```typescript
// autoFixStore.ts
const raw = import.meta.env.VITE_AUTOFIX_LIMIT ?? '5'
const parsed = parseInt(raw, 10)
const SESSION_RUN_LIMIT = isNaN(parsed) ? 5 : parsed
```
