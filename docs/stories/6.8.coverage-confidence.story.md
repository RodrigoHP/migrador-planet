# Story 6.8: Coverage + Confidence Popovers e Overlays Visuais

## Status
Draft

## Story
**As a** operador,
**I want** clicar nos badges Confiança e Cobertura no toolbar para ver detalhamentos em popovers, e ativar o Modo Cobertura para ver overlays visuais no Canvas e no PDF,
**so that** eu compreenda a qualidade da análise automática.

## Acceptance Criteria
1. Badge Confiança: clique abre popover com 5 fatores (barras de progresso + %): Estabilidade de Layout, Detecção de Âncoras, Qualidade do Grid, Variabilidade de Campos, Concordância da Visão
2. Badge Cobertura: clique abre popover com breakdown: Campos mapeados N/M, Tabelas N/M, Imagens N/M, Gráficos N/M
3. Ambos os popovers exibem nível de threshold: ✅ (≥95%), ⚠️ (80-95%), 🔴 (<80%)
4. Popovers fecham ao clicar fora
5. Badges atualizam por Layout Type — trocar layout atualiza ambos os badges
6. Toggle Modo Cobertura: quando ativo, Canvas exibe overlays — 🟩 verde (binding definido), 🟥 vermelho (sem binding), 🟨 amarelo (não confirmado), 🟪 roxo (tabela), 🟧 laranja tracejado (seção opcional), 📊 laranja sólido (gráfico)
7. Toggle Modo Cobertura: quando ativo, PDF Reference exibe overlays — 🟦 azul (bloco de texto), 🟩 verde (mapeado), 🟥 vermelho (não mapeado), 🟨 amarelo (não confirmado), 🟪 roxo (tabela), 📊 laranja (gráfico)
8. Overlays lidos de `coverageStore` overlay data
9. `npm run build` passa

### Thresholds de Confiança e Cobertura
```typescript
function getThresholdIcon(value: number): string {
  if (value >= 95) return '✅'
  if (value >= 80) return '⚠️'
  return '🔴'
}

function getThresholdColor(value: number): string {
  if (value >= 95) return 'text-green-500'
  if (value >= 80) return 'text-yellow-500'
  return 'text-red-500'
}
```
