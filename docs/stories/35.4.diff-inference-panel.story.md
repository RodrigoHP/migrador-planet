## Story

As a template operator, I want to see a results panel below the diff panels with inference items I can confirm or reject, so that I can apply or dismiss detected differences.

- [x] Botao Confirmar → `diffStore.confirmInference(id)` → aplica no templateStore
- [x] Botao Rejeitar → `diffStore.rejectInference(id)` → remove da lista
- [x] Contagem de inferencias pendentes visivel no header
