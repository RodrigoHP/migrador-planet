# Story 30.5 — ConsolePanel: warnings de backend em tempo real

## Story
**Como** operador revisando um template após processamento,
**Quero** ver os warnings gerados pelo backend (tabela ambígua, baixa confiança) no painel de console,
**Para** identificar e corrigir problemas de extração sem precisar verificar logs externos.

## Status
Done

## Business Value
O `ConsolePanel.vue` já exibe campos não mapeados. Esta story conecta-o aos
`backendWarnings` do `confidenceStore`, adicionando visibilidade de problemas
detectados pelo pipeline de extração.

**Estimativa:** 2 story points (M)

## Scope

**IN:**
- `BackendWarning` interface em `confidence.types.ts`
- `backendWarnings` state + `setBackendWarnings` + `clearBackendWarnings` em `confidenceStore.ts`
- `ConsolePanel.vue`: warnings merged (local + backend), badge de categoria no item
- `ConsolePanel.spec.ts`: testes de integração com backend warnings

**OUT:**
- Fetch de warnings via endpoint separado
- Filtros por categoria (Story 30.8)
- Exportação CSV/JSON (Story 30.8)

## Acceptance Criteria

- [x] **AC1:** `confidenceStore.setBackendWarnings([...])` armazena warnings e os expõe via `backendWarnings` computed
- [x] **AC2:** `ConsolePanel.vue` exibe warnings do backend concatenados com warnings locais
- [x] **AC3:** Warning de backend com `nodeId` → clique seleciona o nó no canvas (mesmo comportamento local)
- [x] **AC4:** Warning sem `nodeId` → exibido sem ação de clique (não-clicável)
- [x] **AC5:** `clearBackendWarnings()` limpa a lista — painel volta a mostrar apenas warnings locais
- [x] **AC6:** Categoria do warning exibida como badge (`table_inconsistent`, `low_confidence`, `missing_binding`)
