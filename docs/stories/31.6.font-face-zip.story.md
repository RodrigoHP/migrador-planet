# Story 31.6 — Gerar @font-face e incluir fontes no ZIP

## Story
**Como** operador usando o editor de templates,
**Quero** que fontes customizadas do catálogo sejam incluídas no ZIP,
**Para** que o template renderize com as fontes corretas offline.

## Status
Done

## Acceptance Criteria

- [ ] AC1: CSS no ZIP contém @font-face para fontes do catálogo usadas no template
- [ ] AC2: Arquivos de fonte são incluídos em template/fonts/ no ZIP
- [ ] AC3: Fontes do sistema (Arial, Helvetica) não geram @font-face

## Scope

**IN:**
- Detectar fontes customizadas no CSS (.f-* classes)
- Buscar fontes no IDB (useBibliotecas)
- Gerar @font-face e incluir arquivos no ZIP

**OUT:**
- Fontes do sistema operacional

## Tasks

- [ ] Task 1: Extrair nomes de fontes do CSS (.f-{name} classes)
- [ ] Task 2: Buscar fontes correspondentes no IDB
- [ ] Task 3: Gerar @font-face rules e incluir no CSS
- [ ] Task 4: Adicionar font files ao ZIP

## Dev Notes
stage5 gera `.f-{safe_class} { font-family: '{clean_name}', sans-serif; }`.
No export, detectar essas classes, buscar no IDB via useBibliotecas,
gerar @font-face com url(fonts/{filename}), incluir os binários no ZIP.

Fontes padrão (Arial, Helvetica, Times, Courier) são ignoradas.
