# Story 9.8: Font Cascade, Barcode Detection & SVG Inline

## Status
Draft

## Story
**As a** operador,
**I want** que o sistema lide com fontes não-padrão (cascade fallback com IA), detecte códigos de barra (com binding JsBarcode), e ofereça SVG inline para imagens vetoriais,
**so that** a tipografia, os códigos de barra e os vetores do PDF original sejam adequadamente reproduzidos no template HTML.

## Acceptance Criteria

### Font Cascade (FR27)
1. Quando fonte não-padrão detectada → (1) verificar catálogo Bibliotecas, (2) IA identifica e sugere alternativas públicas, (3) oferecer upload manual; ElementInspector mostra: nome da fonte detectada, fonte fallback, botão de upload quando não encontrada
2. Molécula FontWarning: aparece no ElementInspector quando fonte não encontrada — mostra nome da fonte + fallback atual + botão "Upload fonte"
3. Endpoint backend `POST /api/font-identify`: recebe nome da fonte, retorna sugestões de alternativas via IA (OpenRouter)

### Barcode Detection (FR31)
4. Elementos de código de barras no PDF detectados pelo pipeline → aparecem como nós de barcode na StructureTree; Inspector mostra binding para campo de dados; gera `<svg id="barcode">` + inicialização JsBarcode no base.js
5. Molécula BarcodeInspector permite selecionar formato (CODE128, EAN, etc) e campo associado
6. JsBarcode CDN adicionado: `https://cdn.jsdelivr.net/jsbarcode/`

### SVG Inline (FR32)
7. Imagens vetoriais detectadas no PDF → opção de incorporar como SVG inline no index.html ao invés de tag `<img>`; toggle no ImageInspector: "Incorporar como SVG inline"
8. Ao ativar o SVG Inline, o template gerado deve conter a tag `<svg>` com os paths exatos renderizados

### Geral
9. `npm run build` passa sem erros
