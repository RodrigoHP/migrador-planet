# Story 6.3: StructureTree Auto-Populated — Árvore Hierárquica do Documento

## Status
Draft

## Story
**As a** operador,
**I want** ver a árvore hierárquica de estrutura do documento (Document > Header > Flow > Footer > elementos) auto-populada a partir da análise do pipeline, com ícones de tipo e indicadores de binding,
**so that** eu compreenda a estrutura detectada do meu documento.

## Acceptance Criteria
1. Organism StructureTree renderiza a árvore a partir de `templateStore.documentTree`
2. Nós exibem: ícone de tipo (📄 Document, 📦 Seção, 🔤 Texto, 📋 Tabela, 📊 Gráfico, 🖼 Imagem), nome e binding (ex.: `→ {{cliente}}`)
3. Elementos opcionais marcados com badge ⚠
4. Árvore é expansível/colapsável (clique no pai expande/colapsa filhos)
5. Clicar em um nó atualiza `inspectorStore.selectedNode` e `editorStore.selectedElementId`
6. Nó selecionado é destacado visualmente
7. Cada Layout Type tem sua própria árvore — trocar Layout Type no toolbar atualiza a árvore
8. Árvore suporta profundidade mínima de 5 níveis (Document > Section > Container > Table > Row > Cell)
9. Seções vazias exibem texto placeholder
10. Árvore com 200+ nós mantém performance aceitável: scroll suave, expand/collapse sem lag perceptível (<100ms); considerar virtualização se necessário
11. `npm run build` passa

### Wireframe da Árvore
```
📄 Document
├─ 📦 Header
│  ├─ 🖼 Logo
│  └─ 🔤 Cliente → {{cliente}}
├─ 📦 Flow
│  ├─ 🔤 Título → {{titulo}}
│  ├─ 📋 Transações → {{transacoes[]}}
│  │  ├─ 🔤 Data → {{data}}
│  │  ├─ 🔤 Descrição → {{descricao}}
│  │  └─ 🔤 Valor → {{valor}}
│  └─ 📊 Gráfico Mensal → {{grafico_mensal}} ⚠
└─ 📦 Footer
   └─ 🔤 Página → {{pagina}}
```

### Dados do Nó (de templateStore)
```typescript
interface TreeNode {
  id: string;
  type: NodeType;
  name: string;
  binding?: string;
  isOptional: boolean;
  children: TreeNode[];
  properties: Record<string, any>;
  visibility: 'always' | 'conditional' | 'hidden';
}
```

### Componente Recursivo Vue 3
```vue
<!-- StructureTreeNode.vue -->
<template>
  <div :style="{ paddingLeft: depth * 16 + 'px' }">
    <span @click="toggle">{{ hasChildren ? (isExpanded ? '▼' : '▶') : '·' }}</span>
    <span>{{ icon }} {{ node.name }}</span>
    <span v-if="node.binding"> → {{ '{{' + node.binding + '}}' }}</span>
    <span v-if="node.isOptional">⚠</span>
  </div>
  <template v-if="isExpanded">
    <StructureTreeNode v-for="child in node.children" :key="child.id" :node="child" :depth="depth + 1" />
  </template>
</template>
```
