# Story 39.4 — Snap lines durante resize

**Epic:** 39 — Canvas UX Polish
**Status:** Done
**Gap:** I12

**Estimativa:** 2 pontos
**Executor:** @dev

## Descrição

Snap lines visuais aparecem durante drag mas não durante resize. Ao redimensionar um elemento, o snap to grid funciona internamente mas sem feedback visual (linhas guia).

## Acceptance Criteria

- [ ] `activeSnapLines` retorna linhas quando `isResizing` (não só `isDragging`)
- [ ] `updateResize()` calcula snap lines baseado no bounding box atual
- [ ] Linhas visuais aparecem durante resize
- [ ] Snap to grid funciona durante resize com feedback visual
