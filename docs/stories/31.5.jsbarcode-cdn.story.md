# Story 31.5 — Injetar JsBarcode CDN no index.html gerado

## Story
**Como** operador usando o editor de templates,
**Quero** que o index.html inclua o script JsBarcode quando houver barcodes,
**Para** que os códigos de barras renderizem corretamente no template standalone.

## Status
Done

## Acceptance Criteria

- [ ] AC1: index.html contém script tag JsBarcode CDN quando barcodes estão presentes
- [ ] AC2: Script não é incluído quando não há barcodes no template
- [ ] AC3: Script é adicionado antes do base.js

## Scope

**IN:**
- Detectar barcodes no HTML e injetar script CDN

**OUT:**
- Gerar barcodes server-side

## Tasks

- [ ] Task 1: Implementar detecção de barcodes no HTML (data-type="barcode")
- [ ] Task 2: Injetar script tag CDN no HTML durante export
- [ ] Task 3: Testes

## Dev Notes
Implementação: no processamento do HTML durante export (useExport),
detectar `data-type="barcode"` e injetar:
`<script src="https://cdn.jsdelivr.net/npm/jsbarcode@3/dist/JsBarcode.all.min.js"></script>`

Isso já será tratado junto com Story 31.3 (CDN com fallback).
