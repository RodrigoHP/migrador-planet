# Story 11.9 — TTL com limpeza de arquivos do disco

## Story
**Como** operador do sistema,
**Quero** que os arquivos temporários dos jobs sejam removidos do disco após o TTL expirar,
**Para** evitar acúmulo indefinido de PDFs e schemas em `/tmp/jobs/`.

## Status
Done

## Context
O audit identificou que `analyze.py` tem TTL de 1 hora para evicção de jobs **em memória**:

```python
# analyze.py
_JOB_TTL_SECONDS = 3600  # Remove de _pipeline_jobs após 1h
def _evict_stale_jobs() -> None: ...
```

Mas a evicção remove apenas o estado em memória — os arquivos em `/tmp/jobs/{job_id}/` (PDF, XSD, data) **permanecem no disco indefinidamente**. Em ambiente de produção com uso contínuo, isso causa vazamento de espaço em disco.

## Acceptance Criteria

1. **Limpeza de disco** — Quando um job é eviccionado da memória (após TTL), seus arquivos em `/tmp/jobs/{job_id}/` são removidos.
2. **Limpeza de jobs órfãos** — Jobs em disco sem estado em memória (ex: após restart do servidor) são limpos se o diretório tiver mais de 24h de modificação.
3. **Segurança** — A limpeza valida que o path está dentro de `TMP_BASE` (path traversal prevention) antes de fazer `shutil.rmtree()`.
4. **Logs** — Cada limpeza registra `job_id`, tamanho liberado e timestamp no log do servidor.
5. **Testes** — `_evict_stale_jobs()` testado para verificar que arquivos são removidos junto com estado em memória.

## Tasks

## Dev Notes

### Implementação segura
```python
import shutil

def _evict_stale_jobs() -> None:
    cutoff = time.monotonic() - _JOB_TTL_SECONDS
    stale = [
        jid for jid, state in _pipeline_jobs.items()
        if state.get("created_at", 0) < cutoff
        and state.get("status") not in ("pending", "running")
    ]
    for jid in stale:
        del _pipeline_jobs[jid]
        # Limpeza de disco — com verificação de segurança
        job_dir = TMP_BASE / jid
        if job_dir.exists():
            resolved = job_dir.resolve()
            if str(resolved).startswith(str(TMP_BASE.resolve())):
                shutil.rmtree(resolved)
                logger.info(f"Evicted job {jid} — disk cleaned")
```

### FastAPI lifespan para cleanup de órfãos
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    _cleanup_orphaned_dirs()  # Na inicialização
    yield
```
