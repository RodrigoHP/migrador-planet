## Dev Notes

### Running E2E Tests Locally

```bash
# From frontend/ directory:

# Run all E2E smoke tests (headless, starts dev server automatically)
npm run test:e2e

# Run with browser visible (useful for debugging)
npm run test:e2e:headed

# Run with Playwright UI (interactive test runner)
npm run test:e2e:ui
```

**Prerequisites:**
- Playwright browsers installed: `npx playwright install chromium`
- No running backend needed: all API calls are mocked via `api-mocks.fixture.ts`
- Dev server starts automatically via `webServer` config in `playwright.config.ts`

### Architecture

- **Page Object Model (POM):** Each page has a class in `e2e/pages/` with typed locators
- **Fixtures:** Auth injection (`auth.fixture.ts`) and API mocking (`api-mocks.fixture.ts`)
- **No external dependencies:** All backend calls are intercepted with `page.route()`, making tests fully deterministic
- **CI:** Runs in headless Chromium with 2 retries, GitHub reporter, artifact upload
