# Story 19.8 — Engine Integration Tests

## Story
**Como** mantenedor do framework AIOS,
**Quero** um test harness que valide o engine em um projeto clean — bootstrap, config, SDC start, step execution, complete,
**Para** que a portabilidade do engine seja verificavel automaticamente e regressoes sejam detectadas antes de release.

## Status
Done

## Context

### Problema

Nao existe forma automatizada de verificar que o engine funciona em um projeto novo. A unica validacao hoje eh manual: copiar arquivos, rodar, ver se funciona. Isso torna impossivel garantir que mudancas no engine nao quebram a portabilidade.

### Design

#### Test Harness

Script/task que executa a sequencia completa em um diretorio temporario:

```
TEST: Engine Portability Smoke Test

1. CREATE temp directory (clean project)
2. INIT: Run aiox-init (19.4) com --tier core
3. VERIFY: Estrutura criada (.aios/, .aios-core/, .claude/)
4. CONFIG: Verificar engine-config.yaml valido (19.2)
5. CONTEXT: Verificar project-context.yaml gerado ou template
6. START: Iniciar SDC workflow com story mock
7. STEP: Executar pelo menos 1 step com output valido
8. COMPLETE: Workflow termina sem erro (ou com expected failure)
9. STATE: Verificar state file persistido corretamente
10. CLEANUP: Remover temp directory
```

#### Verificacoes por step

| Step | Verifica |
|------|----------|
| Init | .aios/ exists, engine-config.yaml valid |
| Config | All required fields present, defaults correct |
| Context | project-context.yaml parseable |
| SDC Start | Workflow loaded, state initialized |
| Step Execution | Step prompt generated, output parsed |
| Complete | Final status captured, execution_log written |
| State | State file valid YAML, contains expected fields |

#### Exit codes

```
0 — All tests passed
1 — Bootstrap failure
2 — Config validation failure
3 — Workflow execution failure
4 — State persistence failure
```
