# Story 23.7 — Handoff RCA→SDC: Gerar Artifacts Reais

## Story
**Como** agente @sm recebendo backlog de uma investigacao,
**Quero** um handoff artifact real gerado na Fase 8,
**Para** que achados colaterais nao se percam entre RCA e desenvolvimento.

## Status
Done

## Context

### Problema
Diretorio `.aios/handoffs/` nao existe. Nenhum handoff RCA→SDC foi gerado apesar de ambas RCAs terem achados colaterais. Instrucoes v6.0 dizem "gerar artifact" mas nao dao trigger claro nem template executavel.

### Design
1. Criar `.aios/handoffs/.gitkeep`
2. Na Fase 8, adicionar step explicito com trigger:
```
SE achados_colaterais > 0 OU backlog_items > 0:
  Criar arquivo: .aios/handoffs/handoff-rca-to-sdc-{date}.yaml
  
  Conteudo:
  ---
  from_agent: "@qa"
  to_agent: "@sm"
  investigation_id: "rca-{date}-{slug}"
  date: "{date}"
  consumed: false
  backlog_items:
    - title: "{titulo do achado}"
      priority: high | medium | low
      context: "{resumo em 1-2 linhas}"
      source_finding: "F-{N}"
      suggested_epic: null
  ---
  
  Log: "Handoff gerado: .aios/handoffs/handoff-rca-to-sdc-{date}.yaml"
  
SE achados_colaterais == 0:
  Log: "Sem achados colaterais — handoff nao necessario"
```
