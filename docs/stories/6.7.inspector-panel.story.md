# Story 6.7: InspectorPanel (Display Mode) — Painel Contextual de Propriedades por Nível

## Status
Draft

## Story
**As a** operador,
**I want** ver um painel inspetor contextual que exibe propriedades baseadas no nível do nó selecionado (Page, Section, Component, Element),
**so that** eu compreenda as propriedades detectadas de cada parte do documento.

## Acceptance Criteria
1. Organism InspectorPanel renderiza no painel direito
2. Router alterna entre 4 componentes de inspetor baseado em `inspectorStore.level`:
   - Nível 1 (Page): PageInspector — tamanho, orientação, margens, alturas header/footer, grid, colunas detectadas
   - Nível 2 (Section): SectionInspector — tipo (Header/Flow/Footer), altura, background, padding, repetição por página, visibilidade
   - Nível 3 (Component): ComponentInspector — alterna entre TableInspector, ChartInspector, ContainerInspector, ImageInspector baseado no tipo do nó
   - Nível 4 (Element): ElementInspector — posição X/Y, tamanho, tipografia (fonte, tamanho, peso, cor, line-height), binding, tipo de campo, visibilidade
3. Todas as propriedades exibidas como labels read-only com valores (edição vem no Epic 7)
4. Quando nenhum nó selecionado, exibir PageInspector (nível Document)
5. Título do inspetor exibe: "Inspetor de {nível}: {node.name}"
6. Propriedades populadas a partir das propriedades do nó no templateStore
7. Propriedade visibilidade exibe estado atual: "Sempre visível", "Condicional" ou "Escondido"
8. Tipo de campo exibe tipo detectado: Texto, Número, Moeda (BRL), Data, CPF, CNPJ, Percentual, Telefone, Personalizado
9. `npm run build` passa

## Dev Notes

### Propriedades por Nível

**Nível 1 — Page:**
- Tamanho: A4 (210×297mm) / Letter (216×279mm) / Custom
- Orientação: Retrato / Paisagem
- Margens: topo, base, esquerda, direita (mm)
- Header height, Footer height (px)
- Área de conteúdo: calculada (page_height - header - footer - margins)
- Grid: toggle + tamanho (px)
- Colunas detectadas: quantidade + posições

**Nível 2 — Section:**
- Tipo: Header / Flow / Footer
- Altura (px), Cor de fundo, Imagem de fundo
- Padding: 4 lados (px)
- Repetir por página: checkbox
- Bloquear seção: checkbox
- Visibilidade: "Sempre visível" / "Condicional" / "Escondido"

**Nível 3 — Table:**
- Nome, Fonte de dados (dropdown)
- Colunas: campo / largura / alinhamento (tabela read-only)
- Altura da linha, Padding
- Paginação: quebra / repetir header / min linhas
- Âncora, Manter junto, Visibilidade, Camada, Bloqueio

**Nível 3 — Chart:**
- Nome, Confiança (%), Tipo (barra/linha/pizza/rosca/área)
- Data binding: labels + datasets
- Dimensões: largura × altura
- Estilo: legenda/grid/animação/labels de eixo
- Preview mini, Âncora, Manter junto, Visibilidade

**Nível 3 — Image:**
- Dimensões: largura × altura, Escala
- Alinhamento, Fonte (URL)
- Botões: Substituir / Download (placeholder)

**Nível 4 — Element:**
- Posição: X, Y (px)
- Dimensões: W, H (px)
- Fonte: família, tamanho, peso, cor, line-height, espaçamento
- Tipo de campo: Texto, Número, Moeda (BRL), Data, CPF, CNPJ, Percentual, Telefone, Personalizado
- Binding, Âncora, Visibilidade, Camada, Bloqueio
