# Story 7.6: Monaco Editor Tab

## Status
Draft

## Story
**As a** operador,
**I want** um editor de código multi-arquivo (Monaco) com explorador de arquivos e sincronização bidirecional com os stores de estrutura,
**so that** eu possa fazer edições avançadas em HTML/CSS/JS que sejam refletidas no editor visual e vice-versa.

## Acceptance Criteria
1. Painel central aba "Código" exibe Monaco Editor com abas de arquivos: index.html, style.css, base.js, exemplo.js (FR24)
2. Painel esquerdo adiciona terceira aba [Arquivos] quando aba Código está ativa — exibe árvore: Template > index.html, css > style.css, js > base.js + exemplo.js, assets > images + fonts
3. Clicar em arquivo no explorador abre na aba do editor
4. Syntax highlighting para HTML, CSS, JavaScript
5. Auto-indentação, números de linha, busca (Ctrl+F)
6. Warnings estruturais: marcadores `SEÇÃO ESTRUTURAL` em seções header/footer/flow
7. Detecção de erros inline: HTML inválido, bindings fora do XSD, erros de sintaxe
8. Sincronização bidirecional: editar código → parse → atualizar templateStore → re-renderizar Canvas; editar em tree/inspector → regenerar código → atualizar Monaco
9. Source of truth: sempre templateStore (Pinia stores), nunca o texto HTML
10. Seleção bidirecional: clicar em linha no código → selecionar nó no Tree; selecionar nó no Tree → scroll código até seção correspondente
11. Validação ao salvar: rejeitar se sintaxe ou estrutura inválida
12. Regras MVP: permitido editar arquivos existentes | proibido criar/deletar/renomear arquivos
13. Arquivo exemplo.js é read-only no editor Monaco (gerado pela Story 8.1); alterações em dados de teste apenas via painel Dados de Teste (Story 8.3)
14. Resolução de conflito bidirecional: edições no Monaco aplicam debounce de 500ms antes de parse; se templateStore muda durante o debounce (via Inspector/Tree), a edição do Monaco é preservada em buffer com toast "Alteração externa detectada — revisar código"
15. `npm run build` passa sem erros

## Dev Notes
- Monaco Editor package: @monaco-editor/vue ou monaco-editor com setup customizado
- MonacoTabs.vue já existe — adaptar para multi-arquivo com explorador de arquivos
- FileExplorer organism (baixa complexidade): tree view dos arquivos do pacote template
- Geração de código a partir dos stores: templateStore → HTML generator → string index.html; templateStore → CSS generator → string style.css; etc.
- Parsing de código de volta para stores: HTML parser extrai estrutura → atualiza nós do templateStore
- Fluxo sync Visual→Code: alteração templateStore → regenerar todas strings de código → Monaco atualiza
- Fluxo sync Code→Visual: edição Monaco → parse HTML → diff com templateStore → aplicar alterações → Canvas re-renderiza
- Warning markers: Monaco decorations API para adicionar ícones em linhas específicas
- Detecção de erros: usar validadores built-in do Monaco + validador customizado para bindings Knockout vs XSD
- Stack: Vue 3 + TypeScript + Pinia + Monaco Editor + Tailwind CSS
