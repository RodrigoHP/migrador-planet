# Story 36.4 — Formato save migra para .zip com assets

- **Epic:** 36
- **Complexity:** L

## Story

As a template operator, I want to save my project as a .zip file that includes assets, and be able to open both legacy .json and new .zip formats, so that my project files are portable and include all assets.

## Acceptance Criteria

- [x] Save uses JSZip to create `{templateName}.projeto.zip`
- [x] ZIP contains: `project.json` (serialized state) + `assets/` (images base64 or blobs)
- [x] Open project accepts both .json (legacy v2.0) and .zip (v3.0)
- [x] When opening .zip, assets restored in AssetGallery
- [x] ZIP size reasonable (< 10MB for typical project)

## Tasks

- [ ] Modify onSave in TopToolbar.vue to use JSZip
- [ ] Add onOpen handler that accepts .json and .zip
- [ ] Add asset extraction and restoration logic
- [ ] Add unit tests

## Scope

**IN:** TopToolbar save/open, JSZip packaging, format detection
**OUT:** Backend changes, export flow (already uses JSZip)
