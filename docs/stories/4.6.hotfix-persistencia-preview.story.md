# Story 4.6: Hotfix — Persistência de Fidelidade e URL de Preview

## Status

Ready

## Story

**As a** operador da ferramenta,
**I want** que ao restaurar um projeto salvo os dados de fidelidade sejam preservados e que o botão "Abrir Preview" funcione corretamente em ambientes de produção,
**so that** o fluxo de retomada de projeto não perca informações visuais importantes e o preview seja acessível independente da configuração de URL do backend.

## Acceptance Criteria

1. `ProjectFile` inclui `fidelityScore`, `fidelityComment` e `iaSuggestions` na seção `generation`
2. `useProject.save()` serializa `fidelityScore`, `fidelityComment` e `iaSuggestions` do `generationStore` no arquivo `.json`
3. `useProject.load()` restaura `fidelityScore`, `fidelityComment` e `iaSuggestions` no `generationStore` após carregar o arquivo
4. Após restore de projeto salvo no step 4 (Geração), `FidelityScore` exibe o score correto e `isFidelityLow` retorna o valor correto
5. `openPreview()` em `GeracaoPage.vue` usa `${API_BASE}/api/preview/${id}` — com `API_BASE` prefixando o path
6. Nenhuma regressão no fluxo de save/load de projeto

## Dev Notes

### Bug B1.6-a — Fidelidade não persistida

`ProjectFile.generation` atual não inclui `fidelityScore`, `fidelityComment`, `iaSuggestions`. Após restore esses campos ficam `null`/`[]` no store, causando:
- `FidelityScore` atom não renderiza (condição `v-if="fidelityScore !== null"`)
- `isFidelityLow` getter retorna `false` (score null → condição `score !== null && score < 70` = false)
- `IASuggestionList` usa fallback hardcoded `defaultSuggestion` em vez das sugestões reais da IA

### Bug B1.5-a — `openPreview()` sem `API_BASE`

```typescript
// GeracaoPage.vue função openPreview():
// ATUAL — funciona em dev (VITE_API_URL=''), quebra em produção
window.open(`/api/preview/${generation.previewJobId}`, '_blank')

// CORRETO — robusto para qualquer ambiente
window.open(`${API_BASE}/api/preview/${generation.previewJobId}`, '_blank')
```

`API_BASE` já está declarado no script da GeracaoPage (`const API_BASE = import.meta.env.VITE_API_URL ?? ''`), apenas não é usado na função `openPreview`.
