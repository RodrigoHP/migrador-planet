## Context

### Problema
A Fase 2 nunca executou em nenhum dos 2 RCAs. O agente nao sabe exatamente O QUE fazer — as instrucoes sao genericas ("buscar patterns similares"). Resultado: fase inteira ignorada.

### Design
Reescrever Fase 2 com instrucoes executaveis:

**Step 1 — Query Registry:**
```
Ler docs/qa/rca-knowledge/investigations.yaml
Para cada investigacao existente, calcular match score:
```

**Step 2 — Scoring Formula (worked example):**
```
Match Score = Sum of:
  - Error message substring match: +30 pts
  - 2+ file overlap com affected_files: +25 pts  
  - 2+ tag overlap (mesma categoria): +20 pts por categoria
  - Mesmo root_cause_category: +15 pts
  - Mesmo affected_layer: +10 pts
  Max: 100 pts
```

**Step 3 — Worked Example:**
```
Query: "'list' has no attribute 'get'" em Stage 5
vs rca-2026-03-29-analyzing-page:
  - Error message: "'list' object has no attribute 'get'" → substring match +30
  - Files: stage5 overlap → +25
  - Tags: type_error overlap → +20
  - root_cause: data_contract → +15
  = Score: 90/100 → RELATED (50-90%) ou DUPLICATE (>90%)
```

**Step 4 — Output Template (obrigatorio):**
```yaml
## Fase 2 — Pattern Matching Results
| RCA Existente | Match Score | Classificacao | SOP Disponivel |
|---|---|---|---|
| rca-2026-03-29-... | 90/100 | RELATED | sop-missing-isinstance-guard.yaml |

**Decision:** [FAST-TRACK / CONTINUE / DUPLICATE]
**Confidence Score:** [0-100 calculado pela formula]
```

**Step 5 — Fast-Track Criteria:**
- Score >= 80 E SOP existe E SOP.effectiveness_rate > 50%: oferecer fast-track
- Score >= 90: verificar se DUPLICATE (parar e referenciar)
- Score < 50: NOVO, continuar investigacao completa
