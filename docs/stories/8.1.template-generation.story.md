# Story 8.1: Geração de Template (index.html, style.css, base.js, exemplo.js)

## Status
Draft

## Story
**As a** sistema backend,
**I want** gerar arquivos de template prontos para produção (index.html, style.css, base.js, exemplo.js) a partir do estado do template store,
**so that** a saída seja um pacote de template completo e autocontido.

## Acceptance Criteria
1. **AC1** — Endpoint POST /api/generate aceita JSON do estado do template vindo dos stores do frontend (FR16, FR17, FR18, FR19)
2. **AC2** — Gera `index.html` com: `<body data-bind="with: {RootKey}">`, bindings Knockout (`data-bind="text:"`, `data-bind="html:"`), placeholder `var data = ##TEMPLATE_DATA##;`, seções estruturais (header/flow/footer como divs) (FR16)
3. **AC3** — Gera `css/style.css` com: dimensões da página em polegadas (A4: 8.27in × 11.69in), estilos de fonte da extração, posicionamento de layout (CSS Grid onde detectado, absolute caso contrário), estilos de impressão responsivos (FR17)
4. **AC4** — Gera `js/base.js` com: inicialização `ko.applyBindings()`, funções de formatação (formatCPF, formatDate, formatCurrency, etc.), funções de paginação (quebrarTabelaEntrePaginas, criarNovaPagina), computed observables para strings de formato, funções de estilo condicional (FR18)
5. **AC5** — Gera `js/exemplo.js` com: estrutura de dados JSON correspondente ao XSD, valores de exemplo sintéticos, todos os campos obrigatórios populados (FR19)
6. **AC6** — Todos os arquivos gerados são sintaticamente válidos (HTML valida, CSS parseia, JS executa sem erros)
7. **AC7** — Referências a bibliotecas compartilhadas usam caminhos relativos: `../Bibliotecas/js/knockout-3.4.2.js`, `../Bibliotecas/css/`
8. **AC8** — Template é autocontido: abrir index.html com exemplo.js renderiza corretamente no browser
9. **AC9** — HTML gerado inclui marcadores de page break (`page-break-before: always`) conforme cálculo do Layout Engine, garantindo paginação idêntica no Canvas e no motor PDF
10. **AC10** — Todos os arquivos são gerados com encoding UTF-8 (sem BOM)
11. **AC11** — Testes cobrem: validação de estrutura HTML, geração CSS, sintaxe JS, integridade de bindings KO

## Dev Notes
- **FR16**: index.html com `data-bind="with: {ChaveRaizJSON}"`, placeholder `##TEMPLATE_DATA##`
- **FR17**: style.css com dimensões de página em polegadas, A4 default 8.27in × 11.69in
- **FR18**: base.js com `ko.applyBindings`, funções de formatação, lógica de paginação
- **FR19**: exemplo.js com estrutura JSON derivada do XSD
- Knockout.js 3.4.2 é a versão alvo
- knockout.mapping.js deve ser compatível
- Caminhos de bibliotecas compartilhadas: `../Bibliotecas/js/` e `../Bibliotecas/css/`
- CDN permitido: JsBarcode via `https://cdn.jsdelivr.net/jsbarcode/`
- Pasta de fontes: `fonts/` (padrão) ou `fontes/` (variante legada aceita)
- Funções de paginação no base.js reproduzem a mesma lógica do Layout Engine (editor) — garante que o motor PDF renderiza o mesmo resultado que o Canvas
- Backend usa FastAPI com Jinja2 para templating dos arquivos de saída
- Geração pode usar `backend/services/template_generator.py` como service layer
