# Story 6.6: PDFReference Tab — Visualizador do PDF Original com Navegação

## Status
Draft

## Story
**As a** operador,
**I want** ver o PDF original renderizado em uma aba com seletor de documento e navegação de página,
**so that** eu possa consultar o documento original enquanto reviso o template auto-gerado.

## Acceptance Criteria
1. Organism PDFReference renderiza na aba "PDF" do painel central
2. PDF renderizado via PDF.js 5.x
3. Dropdown seletor de documento: lista todos os PDFs enviados (de `sessionStore.uploadedPdfs`)
4. Navegação de página: página atual / total de páginas, botões prev/next
5. Indicador de cluster: "Página representativa de N páginas" (de layoutStore)
6. Visão default: página representativa do Layout Type ativo
7. Controles de zoom: independentes do zoom do Canvas [- 100% +]
8. `npm run build` passa

## Dev Notes

### PDF.js 5.x
```typescript
import * as pdfjs from 'pdfjs-dist'
import pdfjsWorker from 'pdfjs-dist/build/pdf.worker.mjs?url'

pdfjs.GlobalWorkerOptions.workerSrc = pdfjsWorker

// Carregar PDF
const loadingTask = pdfjs.getDocument(url)
const pdfDoc = await loadingTask.promise

// Renderizar página
const page = await pdfDoc.getPage(pageNum)
const viewport = page.getViewport({ scale: zoomLevel / 100 })
const context = canvas.getContext('2d')
await page.render({ canvasContext: context, viewport }).promise
```

```typescript
interface UploadedPdf {
  name: string;        // nome do arquivo

  pageCount: number;   // total de páginas
}
```

### Layout Type e Página Representativa
```typescript
interface LayoutType {
  id: string;
  name: string;
  representativePage: number;  // página que melhor representa este layout
  clusterPageCount: number;    // quantas páginas pertencem a este cluster
  pages: number[];             // lista de páginas neste cluster
}
```
