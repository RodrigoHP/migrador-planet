# Story 15.7 — GitHub Actions CI (pytest + vitest)

## Story

**Como** equipe de desenvolvimento,
**Quero** que testes rodem automaticamente em cada PR,
**Para** prevenir regressões antes do merge e complementar o auto-deploy do Vercel/Railway.

## Status

Draft

## Context

### Problema

`.github/workflows/` está vazio. Nenhum teste roda automaticamente. PRs podem ser mergeados com testes quebrados. Vercel e Railway fazem auto-deploy on push mas **não rodam testes**. TD-03 parcial.

### Estado Atual

- **Backend:** `pytest` configurado, 34 test files, `conftest.py` presente
- **Frontend:** `vitest` configurado, 106 test files, `npm run test` funciona
- **CI/CD:** Zero — nenhum workflow

### Scope — IN vs OUT

**IN SCOPE:**
- Criar `.github/workflows/ci.yml`
- Job backend: Python 3.11, install requirements, `pytest`
- Job frontend: Node 20, install deps, `npm run typecheck`, `npm run test`
- Jobs em paralelo
- Branch protection rule para bloquear merge se CI falha
- Otimização: cache de pip e npm

**OUT OF SCOPE:**
- Deploy via GitHub Actions (Vercel + Railway fazem auto-deploy)
- spaCy model download no CI (testes que precisam de spaCy devem ter skip/mock)
- E2E tests (Playwright — deferred)
- Code coverage reports
- Lint checks (podem ser adicionados depois)

## Acceptance Criteria

- [ ] `.github/workflows/ci.yml` criado
- [ ] Trigger: `pull_request` para branch `main`
- [ ] Job `test-backend`: Python 3.11, `pip install -r backend/requirements.txt`, `cd backend && pytest`
- [ ] Job `test-frontend`: Node 20, `cd frontend && npm ci`, `npm run typecheck`, `npm run test`
- [ ] Ambos jobs rodam em paralelo (matrix ou jobs separados)
- [ ] Cache: pip cache + npm cache para acelerar builds
- [ ] Testes que dependem de spaCy model têm skip/mock (CI não baixa 50MB model)
- [ ] Tempo total de CI < 5 minutos
- [ ] Branch protection: PR para `main` requer CI passing
- [ ] Badge de status no README (opcional)

## Technical Notes

- **spaCy no CI:** O model `pt_core_news_lg` (~50MB) é pesado para CI. Testes de Stage 3 que usam spaCy devem ter `@pytest.mark.skipif` ou mock. Verificar se já existe.
- **GitHub Actions free tier:** 2000 min/mês (suficiente para ~400 CI runs de 5 min).
- **Cache:** `actions/cache@v4` para `~/.cache/pip` e `node_modules/.cache`.
