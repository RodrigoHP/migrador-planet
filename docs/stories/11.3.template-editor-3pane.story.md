# Story 11.3 — Implementar TemplateEditor.vue completo (3-pane layout)

## Story
**Como** usuário do sistema,
**Quero** que o editor de templates tenha os três painéis funcionais (estrutura/campos à esquerda, canvas ao centro, inspector à direita),
**Para** poder visualizar e editar o template gerado a partir do PDF processado.

## Status
Done

## Context
O audit identificou que `frontend/src/pages/TemplateEditor.vue` tem apenas **24 linhas** e é um stub/placeholder de Story 5.1. A implementação completa estava planejada para Story 5.4 mas o arquivo atual não compõe os componentes existentes (`InspectorPanel`, `HTMLCanvas`, `PDFReference`).

Os organismos individuais já existem e foram implementados nas Stories 6.2–6.8 e 7.x. A TemplateEditor.vue precisa orquestrá-los.

## Acceptance Criteria

1. **Layout 3-pane** — TemplateEditor.vue renderiza: painel esquerdo (tabs: estrutura + campos), centro (HTMLCanvas + PDFReference tabs), direita (InspectorPanel).
2. **Dados carregados** — Após navegar do AnalyzingPage, o editor exibe o canvas com conteúdo (depende de 11.2) e a árvore de estrutura com nós.
3. **Tabs funcionais** — Tabs do centro alternam entre canvas (`activeCenterTab = 'canvas'`) e PDF (`'pdf'`). Tabs da esquerda alternam entre estrutura e campos.
4. **Seleção sincronizada** — Clicar em elemento no canvas atualiza o `inspectorStore.selectedNode`.
5. **Responsividade mínima** — Layout não quebra em telas 1280px+.
6. **Rota guard** — Guard `/editor` verifica `session.analysisCompleted === true`; redireciona para `/` se falso.
7. **Testes** — Componente montado sem erros; tabs alternam corretamente; dados do store aparecem.
