# Story 18.9 — Auto Post-Mortem

## Story
**Como** operador cujo workflow foi abortado,
**Quero** que o engine gere automaticamente um post-mortem estruturado com root cause, recommendations, e ajustes sugeridos para o proximo run,
**Para** nao ter que diagnosticar manualmente por que falhou e saber o que ajustar.

## Status
Draft

## Context

### Problema

Quando um workflow faz ABORT, gera um abort report textual com progresso e steps completados. Mas nao produz:
- Diagnostico da root cause
- Recommendations para proximo run
- Sugestoes de ajuste (timeout, max_loops, prompt)
- Artefato que o proximo run possa consumir automaticamente

### Design

#### Post-mortem artifact: `.aios/post-mortems/{instance-id}-post-mortem.yaml`

```yaml
post_mortem:
  workflow_id: story-development-cycle
  instance_id: "sdc-engine-20260329-..."
  aborted_at: "2026-03-29T..."
  total_duration: "45m"
  steps_completed: 7
  steps_total: 10

  root_cause:
    category: qa_reject_loop       # qa_reject_loop | timeout | budget | parse_failure | state_conflict
    step_id: implement_and_test
    agent: "@dev"
    description: "@dev failing repeatedly on AC #3 (table cell detection) — same issue in all 3 retries"
    failure_chain:
      - attempt: 1
        reason: "Missing is_table_cell flag logic"
      - attempt: 2
        reason: "Flag logic added but not propagated to child elements"
      - attempt: 3
        reason: "Propagation added but breaks existing table rendering"

  recommendations:
    - type: prompt_improvement
      target: implement_and_test
      suggestion: "Add explicit example of table cell detection and propagation in prompt notes"
      confidence: 0.8

    - type: step_decomposition
      target: implement_and_test
      suggestion: "Split into: (1) add flag logic, (2) add propagation, (3) verify rendering"
      confidence: 0.7

    - type: config_adjustment
      parameter: max_loops_per_target
      current: 3
      suggested: 5
      reason: "Pattern shows @dev needs 4-5 iterations for complex ACs"
      confidence: 0.6

  auto_adjustments:
    # Adjustments that CAN be applied automatically in next run
    - parameter: loop_guard.max_loops_per_target.implement_and_test
      value: 5
      reason: "3 retries insuficientes para este step"

  metrics:
    tokens_used: 45000
    estimated_cost: "$2.80"
    retry_count: 3
    time_in_retries: "25m"
    time_wasted_percentage: "56%"

  feeds_intelligence: true  # Flag: dados devem ser incorporados em execution-intelligence.yaml
```

#### Geracao automatica

No fluxo de ABORT do Sequence Advancer:

```
FUNCTION generate_post_mortem(state, abort_reason):
  pm = {
    workflow_id: state.workflow_id,
    instance_id: state.instance_id,
    aborted_at: ISO_NOW(),
    root_cause: analyze_root_cause(state, abort_reason),
    recommendations: generate_recommendations(state, abort_reason),
    auto_adjustments: suggest_adjustments(state, abort_reason),
    metrics: calculate_abort_metrics(state),
    feeds_intelligence: true
  }
  Write to .aios/post-mortems/{instance_id}-post-mortem.yaml
  Log: "📋 Post-mortem gerado: .aios/post-mortems/..."

FUNCTION analyze_root_cause(state, abort_reason):
  # Categorize based on abort_reason and step_results
  IF abort_reason contains "max_loops":
    Analyze retry chain from step_results
    Build failure_chain from sequential attempts
  IF abort_reason contains "timeout":
    Compare elapsed vs configured timeout
  ...

FUNCTION generate_recommendations(state, abort_reason):
  recommendations = []
  IF retry_chain shows same error pattern:
    Add prompt_improvement recommendation
  IF step has >3 ACs and failed:
    Add step_decomposition recommendation
  IF retries exhausted but close to success:
    Add config_adjustment for max_loops
  RETURN recommendations
```

#### Consumo no proximo run

Quando engine inicia um novo workflow do mesmo tipo, verifica se existe post-mortem recente:

```
FUNCTION check_post_mortem(workflow_id):
  pms = glob(".aios/post-mortems/*-post-mortem.yaml")
  recent = filter(p => p.workflow_id == workflow_id AND days_since(p.aborted_at) < 7)
  IF recent:
    Display: "⚠️ Post-mortem disponivel do run anterior (abortado em {date})"
    Display recommendations summary
    IF auto_adjustments:
      Display: "Ajustes automaticos sugeridos: {list}"
      In yolo_continuous: apply auto_adjustments automatically
      In interactive: ask user to confirm
```
