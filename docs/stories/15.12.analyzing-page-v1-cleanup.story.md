# Story 15.12 — Cleanup AnalyzingPage: remover dead code V1 + traduzir labels para PT-BR

## Story

**Como** desenvolvedor do projeto,
**Quero** remover o fallback V1 de `AnalyzingPage.vue` e o arquivo `analyzingPageConstants.ts`, e exibir labels de sub-steps e métricas em PT-BR,
**Para** eliminar dead code frontend que referencia o backend V1 já removido na story 15.9 e proporcionar uma experiência totalmente em português ao usuário.

## Status

Done

## Context

### Problema 1 — Dead code V1 em AnalyzingPage.vue

Com a remoção do backend V1 na story 15.9, todo o bloco de fallback V1 em `frontend/src/pages/AnalyzingPage.vue` tornou-se dead code. O campo `isV2 = ref(false)` inicializa como `false`, fazendo com que o bloco `<div v-if="!isV2" class="v1-fallback">` seja renderizado brevemente ao usuário logo após o upload, antes que qualquer lógica de detecção seja executada — exibindo uma interface V1 que não tem mais backend para suportar.

O arquivo `analyzingPageConstants.ts` contém exclusivamente constantes V1 (`PIPELINE_BLOCKS`, `TOTAL_STAGES`, `getStageIndex`) que não têm uso algum no pipeline V2 ativo. Com a remoção dos elementos V1 de `AnalyzingPage.vue`, esse arquivo torna-se completamente órfão e deve ser deletado.

### Problema 2 — Textos em inglês na tela de progresso

Sub-step labels (ex: `"4.1 XSD Parsing"`, `"3.3 Semantic Classification"`) e chaves de métricas SSE (ex: `total_stages`, `pdf_count`) chegam do backend em inglês e são exibidos diretamente ao usuário sem tradução. Isso cria uma experiência inconsistente em uma interface que é inteiramente em PT-BR.

**Decisão arquitetural (@architect — Opção B — mapeamento no frontend):**
O backend NÃO deve ser alterado. A tradução é responsabilidade do frontend via mapas de lookup em `analyzingPageConstantsV2.ts`.

## Technical Notes

### Extração de chave para SUB_STEP_LABELS

A chave deve ser extraída do valor de `sub_step` via regex `/^(\d+\.\d+)/`. Exemplo: `"4.1 XSD Parsing"` → chave `"4.1"`.

### Padrão de fallback

```ts
function translateSubStep(raw: string): string {
  const match = raw.match(/^(\d+\.\d+)/)
  if (!match) return raw
  const key = match[1]
  const label = SUB_STEP_LABELS[key]
  if (!label) {
    if (import.meta.env.DEV) console.warn(`[AnalyzingPage] SUB_STEP_LABELS missing key: "${key}"`)
    return raw
  }
  return label
}

function translateMetric(key: string): string {
  const label = METRIC_LABELS[key]
  if (!label) {
    if (import.meta.env.DEV) console.warn(`[AnalyzingPage] METRIC_LABELS missing key: "${key}"`)
    return key
  }
  return label
}
```
