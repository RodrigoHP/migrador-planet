## Bugs Identificados

### Bug 1 — CRÍTICO: ValueError no silhouette_score — guarda incompleta em _best_k()
- **Causa:** `sklearn.metrics.silhouette_score` exige `2 <= n_labels <= n_samples - 1`. A guarda em `_best_k()` verifica apenas `len(set(labels)) < 2` (labels insuficientes), mas **não** verifica `n_unique >= len(X)` (labels == samples). Quando KMeans produz um cluster por página (k=N, n_labels==n_samples), o `silhouette_score` lança `ValueError: Number of labels is X. Valid values are 2 to n_samples - 1 (inclusive)`
- **Sintoma:** Tela de análise trava em 29% com "Erro na análise — Pipeline falhou na Page Clustering. Verifique os logs do servidor."
- **Arquivo afetado:** `backend/services/stages/page_clustering.py` — função `_best_k()` linhas 62-77
- **Cenários que disparam o bug:**
  - PDF com 2 páginas: k=2 → n_labels(2) == n_samples(2) → crash
  - PDF com 3 páginas: k=3 → n_labels(3) == n_samples(3) → crash (k=2 funciona mas k=3 crasha antes)
  - PDF com N páginas: qualquer k=N → crash
- **Fix:** Dois ajustes em `_best_k()`:
  1. Early-exit quando `len(X) < 3` (silhouette nunca pode ser computado com < 3 amostras): retornar k=1
  2. Corrigir guarda de `if n_unique < 2` para `if n_unique < 2 or n_unique >= len(X)` (cobre ambas as condições do sklearn)
