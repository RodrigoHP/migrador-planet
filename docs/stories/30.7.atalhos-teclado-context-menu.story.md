# Story 30.7 — Atalhos de teclado para ações do context menu

## Story
**Como** operador editando o canvas,
**Quero** usar `Delete`/`Backspace` para remover o elemento selecionado sem abrir o menu,
**Para** acelerar a edição sem depender do mouse.

## Status
Done

## Business Value
O `useCanvasKeyboard.ts` já tem `Delete` para removeNode (Story 14.7), mas:
1. `Backspace` requer `metaKey` (Cmd+Backspace) — guard desnecessariamente restritivo
2. Nenhum hint visual no `CanvasContextMenu.vue` indica que o atalho existe

Esta story remove a restrição do `Backspace` e adiciona hints `Del` ao lado de "Remover Elemento" no menu.

**Estimativa:** 1 story point (S)

## Scope

**IN:**
- `useCanvasKeyboard.ts`: remover guard `!e.metaKey` do Backspace — `Backspace` sozinho remove como `Delete`
- `CanvasContextMenu.vue`: exibir hint de atalho `Del` ao lado de "Remover Elemento"
- Layout do hint: `<kbd>` tag estilizada no lado direito do item de menu
- Testes: shortcut hint presente no DOM, Backspace dispara removeNode

**OUT:**
- Atalhos para outros itens (Mapear Campo, Converter Tabela, Marcar Estático)
- Configuração de atalhos pelo usuário
- Atalhos fora do foco do canvas

## Context

**Situação atual:**
```typescript
// useCanvasKeyboard.ts
if (e.key === 'Delete' || e.key === 'Backspace') {
  if (e.key === 'Backspace' && !e.metaKey) return // restrição desnecessária
  e.preventDefault()
  templateStore.removeNode(id)
  editorStore.selectElement(null)
  return
}
```

**Após a story:**
```typescript
if (e.key === 'Delete' || e.key === 'Backspace') {
  e.preventDefault()
  templateStore.removeNode(id)
  editorStore.selectElement(null)
  return
}
```

**Hint no menu:**
```html
<button class="canvas-context-menu__item canvas-context-menu__item--danger" @click="$emit('remove')">
  <span>🗑 Remover Elemento</span>
  <kbd class="canvas-context-menu__kbd">Del</kbd>
</button>
```

## Acceptance Criteria

- [x] **AC1:** `Delete` no canvas com elemento selecionado → `removeNode` chamado + elemento desselecionado
- [x] **AC2:** `Backspace` no canvas (sem metaKey) → mesmo comportamento que `Delete`
- [x] **AC3:** `Backspace` dentro de `<input>` ou `<textarea>` → NOT interceptado (guard de input preservado)
- [x] **AC4:** `CanvasContextMenu.vue` exibe `<kbd>Del</kbd>` ao lado de "Remover Elemento"
- [x] **AC5:** Hint `Del` visível e legível no tema dark do canvas
