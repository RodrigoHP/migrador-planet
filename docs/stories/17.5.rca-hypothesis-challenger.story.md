# Story 17.5 — Hypothesis Challenger Agent

## Story
**Como** investigador que encontrou uma causa raiz candidata,
**Quero** que o sistema desafie ativamente cada hipotese com contra-evidencia e analise counterfactual,
**Para** que eu nao aceite a primeira explicacao plausivel como verdade e evite fixes que nao resolvem o problema real.

## Status
Done

## Context

### Problema

Hoje o 5 Whys aceita a primeira hipotese que parece razoavel. Nao ha mecanismo de challenge. Problemas:
- **Confirmation bias**: investigador busca evidencia que confirma, ignora o que contradiz
- **Premature closure**: para de investigar ao encontrar "uma" explicacao
- **Hallucination risk**: LLMs expressam alta confianca mesmo quando errados
- **Single-path thinking**: nao explora hipoteses alternativas

Pesquisas mostram que **multi-agent debate** (GALA, 2025) aumenta accuracy em 42% vs agente unico. A tecnica de **counterfactual analysis** pergunta: "o que teria acontecido se essa causa NAO existisse?"

### Inspiracao

- **GALA** (Agosto 2025): Multi-agent debate com +42% accuracy
- **Counterfactual Analysis** (Judea Pearl): "Sem X, Y teria acontecido?"
- **TruEDebate**: Debate adversarial entre agentes para reduzir hallucination
- **Amazon COE**: "Operator error nunca eh resposta final"

### Design Proposto

**Hypothesis Challenger** — recebe hipoteses do Causal Reasoner e as desafia:

```
Input: causal_graph do Causal Reasoner (nodes + gates + evidence)

Para cada root_cause candidato:

  1. COUNTER-EVIDENCE SEARCH
     "Que evidencia CONTRADIZ esta hipotese?"
     - Buscar no codebase: funcionalidade similar funciona? Por que?
     - Verificar: o bug existia ANTES do change suspeito?
     - Testar: reverter o change (mentalmente) resolveria?

  2. COUNTERFACTUAL ANALYSIS
     "Se esta causa NAO existisse, o bug teria acontecido?"
     - Se sim: causa eh contributing, nao primary
     - Se nao: causa eh likely primary
     - Se incerto: precisa de mais evidencia

  3. ALTERNATIVE HYPOTHESES
     "Que OUTRA explicacao cobriria os mesmos sintomas?"
     - Gerar pelo menos 1 hipotese alternativa
     - Comparar evidencia: qual hipotese tem mais suporte?

  4. CHALLENGE VERDICT
     Para cada hipotese:
     - CONFIRMED: sobreviveu ao challenge, evidencia forte
     - WEAKENED: contra-evidencia parcial, precisa investigar mais
     - REFUTED: contra-evidencia forte, descartar
     - INSUFFICIENT: nem evidencia nem contra-evidencia

Output:
  challenge_results:
    hypotheses:
      - id: commit_abc123
        original_evidence: confirmed
        counter_evidence:
          - "Funcao similar em stage 4 funciona sem guard"
          - "Bug nao existia antes do commit (git bisect confirma)"
        counterfactual: "Sem este commit, bug nao existiria"
        alternative: "Poderia ser race condition, mas timing nao bate"
        verdict: CONFIRMED
        confidence: 0.92

      - id: dep_x_update
        original_evidence: hypothesized
        counter_evidence:
          - "Changelog da dep X nao lista breaking changes"
          - "Outros projetos com mesma versao nao reportam bug"
        counterfactual: "Sem update, bug AINDA existiria (commit abc123 eh suficiente)"
        alternative: null
        verdict: REFUTED
        confidence: 0.15

    final_ranking:
      1: {id: commit_abc123, verdict: CONFIRMED, confidence: 0.92}
      2: {id: no_guard_stage5, verdict: CONFIRMED, confidence: 0.78, type: contributing}
```

### Rules of Challenge

1. **Nunca aceitar "operator error" como causa final** (Amazon COE rule)
2. **Sempre gerar pelo menos 1 hipotese alternativa**
3. **Counterfactual obrigatorio para cada primary candidate**
4. **Evidencia > opiniao**: cada claim deve citar fonte (commit, teste, log)
5. **Hipotese sem evidencia = INSUFFICIENT, nao CONFIRMED**

## Risks

- Challenger pode ser excessivamente agressivo, refutando hipoteses corretas com contra-evidencia fraca ou especulativa. Mitigacao: verdicts requerem evidencia citada; confianca < 0.3 para refutar.
- Counterfactual analysis por LLM eh inerentemente especulativo — nao ha como provar "sem X, Y nao teria acontecido". Mitigacao: tratar counterfactual como sinal, nao como prova; combinar com evidencia direta.
- Geracao de hipoteses alternativas pode produzir explicacoes implausíveis que desperdicam tempo de investigacao. Mitigacao: alternativas devem cobrir os mesmos sintomas para serem consideradas.
