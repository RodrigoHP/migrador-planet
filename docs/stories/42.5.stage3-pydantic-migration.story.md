## Dev Notes

### Hierarquia de nós recomendada

```python
# pipeline_context.py — novos modelos
from typing import Annotated, Literal, Union
from pydantic import Field

class BaseNode(BaseModel):
    model_config = ConfigDict(extra="allow")  # remover em 42.7
    id: str
    type: str
    bbox: BoundingBox | None = None
    visibility: bool = True
    children: list["TreeNodeType"] = []

class FieldNode(BaseNode):
    type: Literal["field"]
    label: str = ""
    value: str = ""
    field_name: str = ""
    confidence: float = 0.0

class BarcodeNode(BaseNode):
    type: Literal["barcode"]
    barcode_format: str = "CODE128"
    barcode_value: str = ""

# ... demais tipos

TreeNodeType = Annotated[
    Union[ZoneNode, SectionNode, FieldNode, LabelNode, ValueNode,
          BarcodeNode, ImageNode, ChartNode, TableNode, ...],
    Field(discriminator="type")
]
```
