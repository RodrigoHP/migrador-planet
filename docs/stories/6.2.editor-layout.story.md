# Story 6.2: EditorLayout 5 Regiões + TopToolbar

## Status
Draft

## Story
**As a** operador,
**I want** ver o editor unificado com 5 regiões (toolbar, painel esquerdo, painel central, inspetor, painel inferior),
**so that** eu tenha todas as ferramentas acessíveis simultaneamente sem navegar entre telas.

## Acceptance Criteria
1. EditorLayout.vue com 5 regiões: toolbar (topo), painel esquerdo (sidebar), painel central (main), inspetor (direita), painel inferior (collapsible)
2. Painel esquerdo tem 2 botões de aba: [Estrutura] [Campos] — conteúdo troca baseado na aba ativa
3. Painel central tem 4 botões de aba: [🖥️ Canvas] [📄 PDF] [</> Código] [🔗 Sincronizar] — conteúdo troca baseado na aba ativa
4. Painéis redimensionáveis via drag handles entre eles
5. TopToolbar exibe: nome do template (de sessionStore), badge Confiança (% + cor de confidenceStore), badge Cobertura (% + cor de coverageStore), seletor Layout Type (dropdown de layoutStore), botões toggle [🗺️ Cobertura] [🔀 Diff] [🧲 Snap] [🔧 Auto Fix] [💾 Salvar] [📦 Exportar]
6. Badges Confiança e Cobertura são clicáveis (popover implementado na 6.8)
7. Seletor Layout Type exibe layout types de layoutStore; oculto quando apenas 1 layout type
8. Botões toggle atualizam estado do editorStore
9. Botões Salvar e Exportar são placeholder (funcionais no Epic 8)
10. Responsivo: largura mínima 1200px, painéis colapsam graciosamente
11. `npm run build` passa

## Dev Notes

### Layout CSS Grid
O EditorLayout usa CSS Grid para posicionar as 5 regiões:
```css
.editor-layout {
  display: grid;
  grid-template-areas:
    "toolbar toolbar toolbar"
    "left-panel center-panel inspector"
    "bottom-panel bottom-panel bottom-panel";
  grid-template-columns: var(--left-panel-width) 1fr var(--inspector-width);
  grid-template-rows: auto 1fr var(--bottom-panel-height);
  height: 100vh;
  min-width: 1200px;
}
```

### Painéis Redimensionáveis
- Usar drag handles com `mousedown`/`mousemove`/`mouseup` events
- Ou considerar biblioteca como `splitpanes` se já estiver no projeto
- Limites: left-panel min 180px max 400px, inspector min 200px max 450px, bottom min 100px max 400px

### Estados no editorStore
- `activeCenterTab`: 'canvas' | 'pdf' | 'code' | 'sync'
- `activeLeftTab`: 'structure' | 'fields'
- Toggle states: `coverageMode`, `diffMode`, `snapEnabled`, `autoFixEnabled`, `showGuides`

### Troca de Layout Type
Quando o operador seleciona um Layout Type diferente no dropdown:
1. `layoutStore.setActiveLayout(layoutId)` é chamado
2. templateStore atualiza a árvore para o layout selecionado
3. coverageStore e confidenceStore atualizam métricas para o layout selecionado
4. Os badges no toolbar refletem os novos valores
