# Story 7.8: Format String Customizado + Tematização Condicional

## Status
Draft

## Story
**As a** operador,
**I want** definir format strings customizados combinando múltiplos campos JSON e regras de aparência condicional,
**so that** o template possa exibir campos concatenados e variações de estilo baseadas em valores dos dados.

## Acceptance Criteria
1. Editor de format string: input de texto com autocomplete para campos (ex: `"{Logradouro}, {Numero} - {Bairro}"`) (FR21)
2. Autocomplete sugere campos XSD conforme operador digita `{`
3. Format string gera função computed em base.js
4. Preview: exibe saída formatada com dados de exemplo
5. Aparência condicional: no Inspector, seção "Estilo Condicional" com regras: SE [campo] [operador] [valor] ENTÃO [propriedade] = [valor] (FR30)
6. Propriedades suportadas para estilo condicional: cor do texto, cor de fundo, imagem, visibilidade
7. Múltiplas regras suportadas por elemento
8. Gerado como computed observables em base.js
9. Caracteres `{` e `}` literais são escapados com `\{` e `\}` no editor de format string
10. Campos não encontrados no XSD são destacados em vermelho no editor de format string com tooltip "Campo não encontrado no XSD"
11. `npm run build` passa sem erros
