# Story 9.1: MultiDoc Analyzer

## Status
Draft

## Story
**As a** operador,
**I want** ver um painel Analisador Multi-Documento mostrando a lista de PDFs (base/variação), uma Matriz de Variação (campo × documento) e detecções automáticas (campos opcionais, seções condicionais, tabelas dinâmicas),
**so that** eu possa entender as diferenças entre documentos e validar as inferências da IA.

## Acceptance Criteria
1. Analisador Multi-Documento aparece entre o painel central e o painel inferior quando múltiplos PDFs foram enviados (FR40)
2. Oculto quando apenas 1 PDF foi enviado
3. Mostra lista de PDFs: cada PDF rotulado como "base" ou "variação" com indicador ✔
4. Matriz de Variação: linhas = campos, colunas = documentos, células = ✔ (presente) ou ✖ (ausente) (FR40)
5. Regras de detecção automática aplicadas e exibidas:
   - ✔ em todos os docs → campo obrigatório
   - ✔ em alguns → campo opcional (gera `<!-- ko if: campo -->`)
   - Campos adjacentes com mesmo padrão → seção opcional (agrupada com `<!-- ko if -->`)
   - ✔ em apenas 1 → seção condicional
   - Contagem variável de linhas em tabelas → layout dinâmico (foreach com contagem variável)
6. Operador pode confirmar/rejeitar cada inferência (FR40)
7. Inferências confirmadas atualizam templateStore (visibilidade, bindings)
8. Painel colapsável (minimizar para apenas a barra de título)
9. `npm run build` passa sem erros
