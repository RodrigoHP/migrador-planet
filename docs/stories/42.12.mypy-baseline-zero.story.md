### Fix padrão para arg-type em tests

```python
# Antes (gera arg-type):
result = MyModel(**some_dict_var)

# Depois (type-safe):
result = MyModel.model_validate(some_dict_var)
```

### Fix padrão para no-any-return

```python
# Antes:
def get_something(data: dict) -> str:
    return data.get("key")  # returns str | None, not str

# Depois:
def get_something(data: dict) -> str | None:
    return data.get("key")
```
