# Story 10.2: Bug — AnalyzingPage

## Status
Done

## Story
**As a** operador,
**I want** que a análise inicie corretamente ao navegar para a página de análise,
**so that** o pipeline processe os documentos enviados sem erros de conexão.

## Acceptance Criteria
1. Ao navegar para `/analyzing` após upload, `POST /api/analyze` é chamado automaticamente com o `job_id` antes de conectar ao SSE
2. `GET /api/analyze/{job_id}/progress` retorna dados válidos (não 404) durante análise
3. O backend carrega `OPENROUTER_API_KEY` do `backend/.env` ao iniciar (já corrigido em 10.1, mas verificar que está funcionando após restart)
4. `pytest` e `npm run build` passam sem erros

## Bugs Identificados

### Bug 5 — CRÍTICO: `AnalyzingPage` nunca chama `POST /api/analyze` antes do SSE
- **Causa:** `onMounted` em `AnalyzingPage.vue` chama `connectSSE(session.jobId)` diretamente, mas `POST /api/analyze` (que inicia o pipeline e registra o job no estado interno) nunca é chamado. Está presente apenas no `handleRetry`.
- **Sintoma:** Todos os `GET /api/analyze/{job_id}/progress` retornam 404 porque o job não existe em `_pipeline_jobs`
- **Arquivo:** `frontend/src/pages/AnalyzingPage.vue` — função `onMounted` (linha ~422) e `handleRetry` (linha ~387)
- **Fix:** Em `onMounted`, antes de `connectSSE(session.jobId)`, adicionar chamada a `POST /api/analyze` com `{ job_id: session.jobId }`. Extrair essa lógica para função `startPipeline(jobId)` reutilizável por `onMounted` e `handleRetry`.

### Bug 6 — ALTO: Backend precisa ser reiniciado para carregar `OPENROUTER_API_KEY`
- **Causa:** O fix de `load_dotenv()` foi mergeado (story 10.1, PR #15), mas o processo do backend em execução não relê o `.env` automaticamente. Operador precisa reiniciar o backend.
- **Sintoma:** `OpenRouter client unavailable: OPENROUTER_API_KEY environment variable is not set`
- **Arquivo:** `backend/main.py` (já corrigido), `backend/.env` (já criado pelo operador)
- **Fix:** Documentar no README/dev notes que o backend deve ser reiniciado após alterar `.env`. Verificar que `load_dotenv()` está na posição correta (já está — linha 1-2 de `main.py`). Adicionar instrução no `backend/.env.example`.
