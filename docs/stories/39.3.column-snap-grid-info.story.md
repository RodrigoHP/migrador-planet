# Story 39.3 — Column Snap: consumir grid_info do pipeline no Canvas

**Epic:** 39 — Canvas UX Polish
**Status:** Draft
**Gap:** I11
**Escopo:** Frontend (wiring pipeline → canvas)
**Estimativa:** 2 pontos
**Executor:** @dev

---

## Descrição

O backend já extrai `column_positions` via Stage 2 (`_jenks_1d` em `stage2_deep_extraction.py`) e Stage 3 propaga para sections. O contract 3.2 inclui `grid_info.column_positions` como array de floats. O frontend já tem a infraestrutura visual pronta (`CanvasGuides.vue` renderiza guias de coluna, `HTMLCanvas.vue` passa `:column-positions` como prop). Porém, `HTMLCanvas.vue:277` está hardcoded `const columnPositions: number[] = []`.

**O gap é puro wiring:** ler `grid_info.column_positions` do pipeline data e alimentar o Canvas + snap engine.

## Questões para @architect

1. **Onde vive o dado no frontend?** O `grid_info` vem por página (cada page tem seu `grid_info`). O `CanvasGuides` é renderizado por página. Opções:
   - A) Acessar via `templateStore` (se `documentTree` já tiver `grid_info` por page)
   - B) Acessar via pipeline response direto (novo campo no `LayoutType` ou `PageData`)
   - C) Computar no `useCanvasInteraction` a partir do `parsed_document`

2. **Coordenadas:** `column_positions` do backend está em pontos PDF (72 dpi). O Canvas usa pixels com zoom. Confirmar se a conversão PDF→Canvas já existe ou precisa ser implementada.
