# Story 7.2: StructureTree Editing

## Status
Draft

## Story
**As a** operador,
**I want** arrastar e soltar nós na StructureTree para reordenar, e usar menu de contexto para adicionar, agrupar, duplicar, remover ou mover elementos,
**so that** eu possa reestruturar o template do documento.

## Acceptance Criteria
1. Drag & drop de nós para reordenar dentro do mesmo pai (ex: mover gráfico acima de tabela no Flow) (FR38)
2. Drag & drop de nós entre seções (ex: mover elemento do Flow para Header)
3. Menu de contexto (clique direito) com opções: "Adicionar elemento", "Agrupar em seção", "Duplicar", "Remover", "Mover para Header/Flow/Footer"
4. "Adicionar elemento" abre submenu: Texto, Tabela, Gráfico, Imagem, Container
5. "Agrupar em seção" envolve elementos selecionados em um novo nó de seção
6. "Duplicar" cria cópia do nó (e filhos) abaixo do original
7. "Remover" deleta nó (com confirmação para nós com filhos)
8. Todas as operações atualizam templateStore → Canvas re-renderiza
9. Suporte a Undo: Ctrl+Z reverte última operação na tree (manter stack de histórico com máximo 20 operações)
10. `npm run build` passa sem erros

## Dev Notes
- Drag & drop: usar HTML5 drag API ou biblioteca Vue (vue-draggable-next)
- Menu de contexto: componente Vue customizado posicionado nas coordenadas do clique direito
- "Agrupar em seção": cria novo nó type="section" envolvendo nós selecionados, útil para visibilidade condicional
- "Mover para Header/Flow/Footer": remove do pai atual, adiciona à seção alvo
- Undo stack: armazenar snapshots do templateStore.documentTree antes de cada operação
- Adicionar elemento cria nó com propriedades padrão (binding vazio, tamanho/posição default)
- Todas as mutações via actions do templateStore: moveNode(), addNode(), removeNode(), duplicateNode(), groupNodes()
- Stack: Vue 3 + TypeScript + Pinia + Tailwind CSS
