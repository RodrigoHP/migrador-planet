# Story 8.6: Gerenciamento de Bibliotecas (Fontes, CSS, JS)

## Status
Draft

## Story
**As a** operador,
**I want** gerenciar o catálogo compartilhado de Bibliotecas (Fontes, CSS, JS) a partir de um modal acessível na página Home,
**so that** eu possa adicionar ou remover recursos compartilhados usados pelos templates.

## Acceptance Criteria
1. **AC1** — Botão "📚 Bibliotecas" na Home abre BibliotecasModal (FR27a)
2. **AC2** — Modal tem 3 abas: Fontes, CSS, JS
3. **AC3** — Cada aba exibe lista: nome do arquivo, tamanho do arquivo, botão remover 🗑️
4. **AC4** — Botão de adicionar contextual por aba com filtro de extensão: Fontes (.ttf, .woff, .woff2, .otf), CSS (.css), JS (.js)
5. **AC5** — Arquivos armazenados em IndexedDB via idb (composable useBibliotecas existente)
6. **AC6** — Aba Fontes: arquivos de fonte usados em `../Bibliotecas/fonts/` (ou `../Bibliotecas/fontes/`)
7. **AC7** — Aba JS: exibe bibliotecas compartilhadas (Chart.min.js, chartjs-plugin-datalabels.min.js, knockout-3.4.2.js, knockout.mapping.js)
8. **AC8** — Remover um arquivo referenciado por um template ativo exibe aviso de confirmação
9. **AC9** — Bibliotecas JS padrão (knockout-3.4.2.js, knockout.mapping.js, Chart.min.js, chartjs-plugin-datalabels.min.js) são marcadas como "sistema" e não podem ser removidas
10. **AC10** — Upload rejeita arquivos maiores que 5MB (fontes) ou 1MB (CSS/JS) com mensagem de erro descritiva
11. **AC11** — `npm run build` passa sem erros
