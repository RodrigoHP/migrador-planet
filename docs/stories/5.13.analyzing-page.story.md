# Story 5.13: AnalyzingPage — Tela de Progresso com 8 Blocos, SSE e Auto-Navegação

## Status
Ready for Review

## Story
**As a** operador da ferramenta,
**I want** ver uma tela dedicada de progresso mostrando os 8 blocos de análise com 27 estágios, barra de progresso, resumo parcial e tempo estimado,
**so that** eu saiba que a análise está progredindo e possa cancelar se necessário.

## Acceptance Criteria
1. Tela mostra título "Analisando documentos..."
2. 8 blocos listados com estágios: completed, in progress (animado), pending
3. Barra de progresso com porcentagem (calculada por estágios completed/total)
4. Resumo parcial atualiza em tempo real: "PDFs: N documentos | Páginas: N | Layouts detectados: N"
5. Tempo estimado exibido e atualizado
6. Botão "Cancelar" chama POST /api/analyze/{job_id}/cancel e navega de volta para /upload
7. Conexão SSE via composable useSSE (já existe)
8. Ao completar pipeline, auto-navega para /editor (sem ação do operador)
9. Em falha do pipeline, mostra mensagem de erro com opção de retry ou voltar
10. Reconexão SSE automática: se conexão cair, tentar reconectar até 3 vezes com backoff (1s, 2s, 4s); se falhar, exibir "Conexão perdida" com botão "Reconectar"
11. `npm run build` passa

## Dev Notes

### Wireframe Referência
- "Estado: Analyzing" — tela dedicada de progresso, NÃO o editor
- Tela intermediária entre Upload e Editor
- Operador não tem ações além de cancelar — apenas observa progresso

### Composable useSSE
- useSSE existente usa /api/progress/{id} — mantido sem alterações
- AnalyzingPage usa EventSource diretamente para /api/analyze/{job_id}/progress (Opção B)
- Evita quebrar código existente e dá controle total sobre reconexão

### Formato de Eventos SSE (da Story 5.4)
```typescript
interface SSEEvent {
  block: number       // 1-8
  stage: number       // 1-27 (global, 1-indexed)
  stage_name: string  // nome do estágio
  status: "running" | "completed" | "failed"
  progress_pct: number // 0-100
  summary: {
    pdf_count?: number
    page_count?: number
    layouts_detected?: number
  }
}
```
