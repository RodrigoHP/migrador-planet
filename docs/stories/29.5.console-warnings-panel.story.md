# Story 29.5 — Console/Warnings Panel

## Story
**Como** operador mapeando campos em um template,
**Quero** ver um painel de avisos em tempo real no editor com problemas detectados (campos não mapeados, inconsistências, erros),
**Para** saber exatamente o que precisa ser corrigido sem ter que procurar manualmente.

## Status
Ready

## Business Value
O operador atualmente não tem feedback sobre o que está errado ou incompleto no template — precisa inspecionar campo por campo na árvore para descobrir o que falta mapear. O painel de console centraliza todos os problemas em um único lugar, reduzindo o tempo de revisão e eliminando mapeamentos esquecidos antes de exportar.

**Estimativa:** 2 story points

## Scope
**IN:**
- Componente `ConsolePanel.vue` com lista de warnings de campos não mapeados
- Nova aba "Console" no bottom panel do editor
- Badge reativo com contador de warnings
- Clique no warning seleciona o nó correspondente na árvore
- Testes do componente

**OUT:**
- Warnings de backend em tempo real (apenas dados já disponíveis nas stores locais)
- Exportação ou filtragem do log de warnings
- Categorias além de "campo não mapeado" (table inconsistente, chart sem dados — MVP)
- Persistência dos warnings entre sessões

## Risks

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| `coverageStore` não tem dados no momento do render inicial | Média | Baixo | `computed` reativo — painel atualiza automaticamente quando store carrega |
| Bottom panel com 3 abas fica apertado em telas menores | Baixa | Baixo | Verificar layout em 1280px antes de entregar |
| Performance com muitos warnings (ex: 200+ campos não mapeados) | Baixa | Baixo | Virtual scroll se necessário — improvável no MVP |

## Context

**Problema (GAP 5):**

O bottom panel do editor tem apenas `TestDataPanel.vue` e `TestReportPanel.vue`. Não existe painel de console/warnings durante a edição. A spec define:

```
Console / Warnings
⚠ Field telefone not mapped
⚠ Table header inconsistent
⚠ Chart data source missing
```

O projeto já tem dados de warnings disponíveis nas stores:
- `coverageStore` — campos não mapeados (binding = null), coverage percentage por seção
- `confidenceStore` — scores de confiança por nó
- `AnalyzingPage.vue` — `pipeline-warnings-banner` existe mas só na tela de progresso

**Abordagem:** Criar `ConsolePanel.vue` que agrega dados já disponíveis nas stores — não requer novos endpoints.

**Referências:**
- `frontend/src/layouts/EditorLayout.vue` — bottom panel (adicionar nova aba)
- `frontend/src/stores/coverageStore.ts` — dados de coverage/binding
- `frontend/src/stores/confidenceStore.ts` — scores de confiança
- `frontend/src/pages/AnalyzingPage.vue` — referência de warnings existentes
- Gap analysis: `docs/architecture/gap-analysis-frontend-v3.md` (GAP 5)

**Dependências:** Nenhuma — independente das outras stories do epic.

## Dev Notes

### ConsolePanel.vue — estrutura básica

```vue
<template>
  <div class="console-panel">
    <div v-if="warnings.length === 0" class="console-panel__empty">
      ✅ Nenhum problema detectado
    </div>
    <ul v-else class="console-panel__list">
      <li
        v-for="warning in warnings"
        :key="warning.nodeId"
        class="console-panel__item console-panel__item--warning"
        @click="selectNode(warning.nodeId)"
      >
        <span class="console-panel__icon">⚠</span>
        <span class="console-panel__message">{{ warning.message }}</span>
      </li>
    </ul>
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue'
import { useCoverageStore } from '@/stores/coverageStore'
import { useEditorStore } from '@/stores/editorStore'
import { useTemplateStore } from '@/stores/templateStore'

const coverageStore = useCoverageStore()
const editorStore = useEditorStore()
const templateStore = useTemplateStore()

interface Warning {
  nodeId: string
  message: string
  severity: 'warning' | 'error'
}

const warnings = computed<Warning[]>(() => {
  const result: Warning[] = []

  // Campos bindáveis sem binding
  const BINDABLE_TYPES = new Set(['text', 'field', 'value', 'likely_dynamic', 'dynamic'])
  templateStore.flatNodes
    .filter(n => BINDABLE_TYPES.has(n.type) && !n.binding)
    .forEach(n => {
      result.push({
        nodeId: n.id,
        message: `Campo "${n.name || n.type}" não mapeado`,
        severity: 'warning'
      })
    })

  return result
})

function selectNode(nodeId: string) {
  editorStore.selectElement(nodeId)
}
</script>
```
