# Story 7.1: Canvas Interaction

## Status
Draft

## Story
**As a** operador,
**I want** clicar em elementos no Canvas para selecioná-los, arrastar para mover, redimensionar via handles e usar alinhamento magnético (snap),
**so that** eu possa ajustar visualmente o layout do template.

## Acceptance Criteria
1. Clicar em elemento no Canvas seleciona-o: destaca no StructureTree + abre Inspector (FR25)
2. Elemento selecionado mostra borda de seleção (azul) com 8 handles de redimensionamento
3. Arrastar elemento selecionado para mover: atualiza posição no templateStore, re-renderiza Canvas
4. Redimensionar via handles: atualiza tamanho no templateStore, re-renderiza Canvas
5. Alinhamento magnético (snap): ao arrastar/redimensionar, elemento encaixa em linhas de grid, guias de coluna, bordas de outros elementos (toggle via botão Snap na toolbar)
6. Seleção hierárquica: ao clicar em elemento aninhado (texto dentro de célula dentro de tabela), popup aparece para escolher nível: Texto > Célula > Linha > Tabela
7. Seleção sincroniza bidireccionalmente: selecionar no Canvas destaca no Tree; selecionar no Tree destaca no Canvas
8. Canvas NÃO permite criar novos elementos desenhando — novos elementos apenas via Tree ou Bibliotecas
9. Multi-seleção: Shift+Click seleciona range de elementos, Ctrl+Click adiciona/remove elemento individual da seleção; elementos multi-selecionados exibem borda de seleção e podem ser movidos/redimensionados em grupo
10. Operações de mover e redimensionar integram com undo stack da Story 7.2 (cada operação cria snapshot no histórico)
11. `npm run build` passa sem erros

## Dev Notes
- O Canvas renderiza em iframe — interação requer comunicação postMessage entre editor e iframe
- Alternativa: usar overlay Konva.js sobre o iframe para handles de seleção/arrasto/redimensionamento
- Snap lines: linhas-guia verticais e horizontais que aparecem quando borda do elemento alinha com outro elemento ou grid
- Composable `useCanvas`: gerencia selectionState, dragState, resizeState, cálculos de snap
- Atualizações de posição: modificar propriedades do nó no templateStore (x, y, width, height) → trigger regeneração HTML → iframe re-renderiza
- Popup de seleção hierárquica: menu flutuante pequeno na posição do clique listando cadeia de pais
- Stack: Vue 3 + TypeScript + Pinia + Konva.js + Tailwind CSS
