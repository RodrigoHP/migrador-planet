## Story

Como operador do editor de templates,
quero editar X, Y, Largura e Altura diretamente no ElementInspector,
para que eu possa posicionar elementos com precisão numérica.

## Acceptance Criteria

- [x] Campos X, Y, Largura, Altura são inputs editáveis (não read-only)
- [x] Editar valor → `templateStore.updateNodeProperty()` + `patchNodeGeometry()`
- [x] Canvas re-renderiza na posição/tamanho novos
- [x] Validação: valores numéricos positivos, limites da página

## Tasks

- [x] Substituir InspectorField read-only por InspectorInput editável
- [x] Implementar onGeometryChange com patchNodeGeometry
- [x] Importar useGenerationStore no ElementInspector

## Scope

**IN:** ElementInspector position/size inputs, patchNodeGeometry integration
**OUT:** Drag/resize canvas interaction (already implemented)

## Dev Notes

- InspectorInput already has number validation with min/max
