### SYS-009 + UX-008 Console Cleanup
- All console.warn in production code guarded with `import.meta.env.DEV` (tree-shaken in prod builds)
- ImageInspector.vue catch block changed from console.warn to console.error (allowed by ESLint rule)
- useAnalyzingStateMachine.ts already had DEV guards — left as-is
- Backend print() statements only in test files (benchmarks) — left as-is per scope

### FE-009 CSS Approach
- Convention: dynamic `:style` bindings for computed values (progress bars, positions, grid areas) are acceptable Vue patterns
- Static inline styles (hardcoded colors) migrated to scoped CSS classes
- InitializingState.vue: replaced `style="color: #64748b"` with BEM modifier classes
- EditorLayout.vue: `style="grid-area: ..."` retained — structural grid placement tied to template

### CSS Convention (documented)
- **Default:** Scoped `<style scoped>` with BEM naming for component-specific styles
- **Dynamic:** Vue `:style` bindings for computed/reactive values (widths, positions, colors from data)
- **Grid areas:** Static inline `style="grid-area: ..."` acceptable for CSS Grid layout templates
- **Tailwind:** Available but not primary — used sparingly for utility overrides
- **Never:** Hardcoded color/spacing values in static inline styles — use scoped CSS classes
