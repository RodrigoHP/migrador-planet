# Story 42.1 — CI Quality Gates (mypy + ruff no GitHub Actions)

## Status: InProgress

## Descricao

Adicionar `ruff check` e `mypy` como gates obrigatórios no pipeline CI do GitHub Actions. Atualmente ambos rodam apenas via pre-commit hook local — PRs podem ser mergeados sem passar por essas verificações se o hook for ignorado.

## Debitos Enderecados

| ID | Debito | Severidade | Esforco |
|----|--------|-----------|---------|
| SYS-003 (AC7 de 40.3) | ruff/mypy configurados localmente mas sem gate no CI | MEDIUM | 3h |

## Acceptance Criteria

- [ ] GitHub Actions workflow executa `python -m ruff check backend/` em todo PR
- [ ] GitHub Actions workflow executa `python -m mypy backend/` em todo PR
- [ ] PRs com erros ruff ou mypy **não podem ser mergeados** (branch protection)
- [ ] Baseline de erros mypy documentado — novos erros bloqueiam, erros pré-existentes permitidos via `# type: ignore` ou baseline file
- [ ] Frontend: `npx eslint` e `npx prettier --check` também no CI (se não existir ainda)
- [ ] Workflow não adiciona mais de 3 min ao tempo total de CI

## Escopo

### IN
- `.github/workflows/ci.yml` (criar ou atualizar)
- Job Python: ruff check + mypy
- Job Frontend: eslint + prettier check
- Configuração de branch protection para required status checks

### OUT
- Corrigir erros mypy existentes (baseline permitido)
- Alterações em pyproject.toml (já configurado)
- Testes de integração no CI (já existem ou são separados)

## Dev Notes

### Baseline mypy

O assessment menciona ~34 erros mypy pré-existentes. Estratégia recomendada:
```bash
# Gerar baseline
mypy backend/ --ignore-missing-imports > .mypy-baseline.txt
# No CI: falhar apenas em erros NOVOS (não no baseline)
```

Ou usar `# type: ignore` nos arquivos com erros pré-existentes e garantir que novos arquivos sejam tipados.

### Workflow sugerido

```yaml
# .github/workflows/ci.yml
name: CI
on: [pull_request]
jobs:
  backend-quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.11' }
      - run: pip install ruff mypy
      - run: python -m ruff check backend/
      - run: python -m mypy backend/ --ignore-missing-imports

  frontend-quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: cd frontend && npm ci
      - run: cd frontend && npx eslint src/
      - run: cd frontend && npx prettier --check src/
```
