## Dev Notes

### Architecture Decision: Gradual Typing via Wrapper + Models

The pipeline context is a mutable `dict[str, Any]` passed through 5 stages, each adding keys progressively. A full migration to Pydantic-only would require changing every stage function signature simultaneously -- too risky and too large a blast radius.

**Approach chosen:**
1. **Pydantic models** define the *contract* for each stage's input/output (Cluster, EnrichedPage, FieldMappingEntry, etc.)
2. **PipelineContext** wrapper provides typed property access over the existing dict, with full dict-interface backward compat
3. **Orchestrator** uses PipelineContext for initialization; stages continue using `dict[str, Any]` signatures but gain typed models for validation
4. **`model_config = {"extra": "allow"}`** on data models ensures forward compatibility (new keys don't break validation)

This is the "typed overlay" pattern -- types are available for new code and validation, while existing code continues to work unchanged. Stages can adopt typed access incrementally.

### Models Defined (20 Pydantic models)

- **Shared:** PageReference, ClusterConfidence, PipelineWarning, PdfDocument
- **Stage 1:** Cluster, Stage1Output
- **Stage 2:** TextBlock, ImageInfo, TableInfo, FontInfo, GridInfo, EnrichedPage, EnrichedDocument, ExtractionWarning, Stage2Output
- **Stage 3:** BlockClassification, ClusterIntelligence, DocumentTreeNode, LayoutTypeInfo, Stage3Output
- **Stage 4:** FieldMappingEntry, ConfidenceScoreEntry, ValidationResult, Stage4Output
- **Stage 5:** TemplateDraft, Stage5Result, PipelineResult
- **Infrastructure:** StageDefinition, SubProgressEvent, PipelineContext

### mypy Validation

`mypy models/pipeline_context.py` passes with 0 errors. All `cast()` calls on PipelineContext getters ensure type safety at the wrapper boundary. Pre-existing mypy errors in stage files are unrelated to this change.

### AC-2 Partial Fulfillment Note

AC-2 ("Dict[str, Any] substituido em todas as 123 ocorrencias") is marked incomplete because the approach is gradual: models are *defined* and *available*, but stages still use `dict[str, Any]` signatures internally. Replacing all 123 occurrences would require modifying every stage file simultaneously, which contradicts the risk mitigation strategy. The typed overlay enables incremental adoption per-stage in future stories.
