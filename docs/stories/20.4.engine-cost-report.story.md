# Story 20.4 — Cost Report no Final Report

## Story
**Como** operador que revisou a execucao de um workflow,
**Quero** que o final report inclua uma secao detalhada de custo com breakdown por step, por agent, total, e comparacao estimado vs real,
**Para** que eu tenha visibilidade completa de quanto cada execucao custou e onde otimizar.

## Status
Draft

## Context

### Problema

O final report atualmente nao inclui informacoes de custo. Com o cost accumulator (20.3) mantendo dados granulares, o report precisa apresentar esses dados de forma legivel e util para decisoes.

### Design

#### Nova Secao no Final Report: Cost Breakdown

```markdown
## Cost Breakdown

### Total
- **Total Cost:** $1.43 USD
- **Total Input Tokens:** 65,500
- **Total Output Tokens:** 13,700
- **Estimated Steps:** 0 of 3

### Per Step
| Step | Agent | Model | Input Tokens | Output Tokens | Cost (USD) | Estimated? |
|------|-------|-------|-------------|--------------|-----------|-----------|
| implement | @dev | opus-4 | 45,000 | 8,200 | $1.29 | No |
| qa_gate | @qa | sonnet-4 | 8,000 | 2,100 | $0.06 | No |
| validate | @dev | sonnet-4 | 12,500 | 3,400 | $0.09 | No |

### Per Agent
| Agent | Steps | Total Cost (USD) | % of Total |
|-------|-------|-----------------|-----------|
| @dev | 2 | $1.38 | 96.1% |
| @qa | 1 | $0.06 | 3.9% |

### Estimated vs Real
- **Real data:** 3 steps (100%)
- **Estimated data:** 0 steps (0%)
- **Confidence:** HIGH (all data from real token counts)
```

#### Confidence Levels

```
IF estimated_steps_count == 0: "HIGH" (all real)
IF estimated_steps_count / total_steps <= 0.3: "MEDIUM" (mostly real)
ELSE: "LOW" (mostly estimated)
```
