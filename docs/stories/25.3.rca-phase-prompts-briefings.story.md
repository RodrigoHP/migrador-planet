# Story 25.3 — Phase Prompts: 10 Briefings Autossuficientes

## Story
**Como** subagent recebendo uma tarefa,
**Quero** um briefing completo e autossuficiente,
**Para** executar a fase sem depender de contexto anterior.

## Status
Draft

## Context

### Problema
Subagents isolados nao tem contexto das fases anteriores. Cada um recebe APENAS um briefing. Se o briefing for incompleto, o resultado sera ruim. Os briefings devem conter: contexto do bug, dados relevantes das fases anteriores, instrucoes completas da metodologia, formato de output.

### Design
Criar 9 briefing templates (Fases 0-6, 8-9):

Cada template tem:
1. **System prompt:** Papel do agente e objetivo da fase
2. **Contexto do bug:** Bug report original (sempre presente)
3. **Dados anteriores:** Outputs estruturados das fases ja executadas
4. **Instrucoes:** Metodologia da fase (copiada do v7.0, nao simplificada)
5. **Worked examples:** Quando relevante (Pattern Match, Dedup)
6. **Output format:** Schema YAML exato conforme phase contracts
7. **Constraints:** "Retorne APENAS o output. Nao inclua explicacoes."

Templates inseridos no investigate.md como secoes referenciadas pelo orquestrador.

## Acceptance Criteria
- [ ] 9 briefing templates (Fases 0-6, 8-9)
- [ ] Cada template eh autossuficiente (subagent entende tudo)
- [ ] Instrucoes da metodologia v7.0 preservadas integralmente
- [ ] Output format alinhado com phase contracts (25.1)
- [ ] Worked examples incluidos onde v7.0 ja os tem
- [ ] Templates testados mentalmente: "se eu so tivesse este texto, conseguiria executar a fase?"

## Scope
**IN:** investigate.md (templates de briefing)
**OUT:** Geracao dinamica de briefings
