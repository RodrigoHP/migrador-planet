# Story 15.20 — Fix Stage 5 crash: list sem isinstance guard

## Story
**Como** operador que executa o pipeline,
**Quero** que o Stage 5 (Geração do Template) seja resiliente quando nós da árvore de documento ou elementos de `drawn_elements` são listas em vez de dicts,
**Para** que o pipeline não quebre com `'list' object has no attribute 'get'` na fase final.

## Status
InProgress

## Context

### FIX-PIPELINE-009: Stage 5 chama `.get()` em objetos que podem ser listas

O Stage 5 (`stage5_template_generation.py`) faz travessia recursiva da árvore de documento (`document_trees`) e itera sobre `drawn_elements` e `visual_analysis` do contexto. Em múltiplos pontos, `.get()` é chamado sem verificar se o objeto é realmente um dict, causando crash quando o dado é uma lista.

**Erro observado:**
```
'list' object has no attribute 'get'
```

**Estágio:** Stage 5 — Geração do Template

**Causa raiz:** O mesmo padrão sistêmico dos fixes anteriores (15.18/15.18 PR #40/#41) — objetos que deveriam ser dicts podem ser listas em casos edge, e `.get()` é chamado sem guard `isinstance`.

### Locais afetados identificados por @qa

| `_generate_table_html` | linha ~330 | `child` de `children` pode ser lista |
| `_generate_table_html` | linha ~334 | `cell_node` pode ser lista |
| `_add_table_container_overlays` | linha ~801 | `node`/`child` pode ser lista quando chamada recursiva |
