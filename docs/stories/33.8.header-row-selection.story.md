# 33.8 — Seleção de header row no TableInspector

- **ID:** 33.8
- **Title:** Seleção de header row no TableInspector
- **Type:** feature
- **Status:** Done
- **Priority:** P2
- **Epic:** 33
- **Complexity:** S

## Story

Como operador do editor de templates,
quero selecionar quantas linhas compõem o cabeçalho da tabela,
para que "Repetir cabeçalho" use as linhas corretas.

## Acceptance Criteria

- [x] Controle para marcar qual(is) linha(s) compõem o `<thead>` estático
- [x] Padrão: primeira linha = header
- [x] Alteração reflete na geração do HTML (`_generate_table_html`)
- [x] "Repetir cabeçalho" funciona com a linha selecionada

## Tasks

- [x] Adicionar InspectorInput para header_row_count (condicional a repeat_header)
- [x] Adicionar computed headerRowCount e maxHeaderRows
- [x] Valor persiste em node.properties.header_row_count

## Scope

**IN:** Header row count selector, property persistence
**OUT:** Backend HTML generation changes (backend uses header_row_count from properties)

## Dev Notes

- Control only visible when repeat_header is enabled
- maxHeaderRows limited to number of child rows
