# Story 42.8 — Frontend TypeScript Alignment + OpenAPI Codegen

## Status: Draft

## Descricao

Alinhar os tipos TypeScript do frontend com os modelos Pydantic finalizados no backend (após story 42.7). Opcionalmente, implementar geração automática de tipos via OpenAPI para eliminar drift manual permanentemente.

## Debitos Enderecados

| ID | Debito | Severidade | Esforco |
|----|--------|-----------|---------|
| FE-frontend-drift | Tipos TypeScript em `pipeline.types.ts` divergem dos modelos Pydantic backend | MEDIUM | 7h |

## Dev Notes

### Decisão sobre OpenAPI Codegen

**Verificar no início da story:** O backend já tem `GET /openapi.json` disponível (FastAPI nativo).

```bash
# Testar geração
cd frontend
npx openapi-typescript http://localhost:8000/openapi.json --output src/types/generated/pipeline-api.ts
```

Se o output for limpo e cobrir os tipos necessários → implementar no CI. Se gerar tipos muito genéricos → fazer fix manual e deixar codegen como melhoria futura.

### CI step de codegen (se aprovado)

```yaml
# .github/workflows/ci.yml
- name: Generate TypeScript types from OpenAPI
  run: |
    cd backend && uvicorn main:app --host 0.0.0.0 --port 8000 &
    sleep 3
    cd frontend && npx openapi-typescript http://localhost:8000/openapi.json \
      --output src/types/generated/pipeline-api.ts
    git diff --exit-code src/types/generated/  # falha se tipos mudaram sem atualizar
```
