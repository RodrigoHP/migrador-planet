# Story 48.10 — Stage 1: Ensemble Voting Signals — pHash + Font Jaccard + Struct Distance

## Status: Done

## Descrição

Implementar os 3 sinais calibrados (48.9) no Stage 1 para substituir a fórmula atual
`0.8 * geometry + 0.2 * density` por ensemble voting estrutura-puro.

O spike 48.7 confirmou: a fórmula atual agrupa 3 instâncias do mesmo template em 3
clusters separados. Os thresholds calibrados no 48.9 permitem detectar corretamente
"mesmo template" vs "templates distintos" usando sinais invariantes a conteúdo dinâmico.

## Notas Técnicas

**Thresholds calibrados (48.9):**
```python
T_phash  = 16   # hamming distance <= 16 → SAME signal
T_font   = 0.47 # Jaccard similarity >= 0.47 → SAME signal
T_struct = 0.65 # edit distance <= 0.65 → SAME signal
```

**Scores ensemble → similarity float:**
```python
ENSEMBLE_SCORES = {3: 0.95, 2: 0.85, 1: 0.40, 0: 0.10}
```

**Fallback quando phash/font_sig ausentes:**
Se `pi.phash is None` ou `pi.font_sig is None`, sinal é ignorado e voting é feito apenas
com os sinais disponíveis. Com 0 sinais disponíveis → volta para `geometry_similarity`.

**Masked pHash — regra de mascaramento:**
Mascarar APENAS blocos de texto (type=0). Blocos de imagem (logos, barcodes) SÃO
incluídos na thumbnail — são parte da identidade visual do template.

**Performance:** `_extract_blocks` já abre o PDF uma vez. Adicionar pHash e font_sig
nesse momento não abre PDFs extras. Impacto estimado: +50-100ms por página.
