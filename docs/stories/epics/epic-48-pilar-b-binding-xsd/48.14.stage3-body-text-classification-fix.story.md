## Descrição

O Stage 3.1 (`multi_example_analysis.py`) usa `likely_dynamic` como fallback para campos sem evidência suficiente. Parágrafos de cartas corporativas que variam ligeiramente entre clientes (nome do cliente embutido no texto corrido) caem nesse fallback e chegam ao Stage 4 como candidatos para binding XSD.

O LLM mapeia esses parágrafos para caminhos XSD reais, "roubando" 7 paths que deveriam ir para campos estruturados como TELEFONE, E-MAIL, CEP e Apólice.

**False positives confirmados (E2E run 2026-04-25):**

- `'pessoais e planos contratados'` → mapeado para `Bairro`
- `'JARDIM PAIQUERE, VALINHOS, SP'` → mapeado para `CEP`
- `'Conforme seu pedido, apresentamos'` → mapeado para `ClienteTelefone`
- `'(demais localidades) e 0800 771 5472'` → mapeado para `NomeCliente`
- `'de contato disponíveis no site'` → mapeado para `DataUltAltHistRelacionamento`

**Root cause:** `rca-2026-04-25-scalar-coverage-residual-53pct`, RC-A, evidence E1_confirmed.

## Notas de Implementação

**Abordagem recomendada (v1 — simples):**

Heurística em duas etapas após a classificação multi-example:

**Etapa 1 — Ratio de stopwords (spaCy):**
```python
from spaCy import load
nlp = load("pt_core_news_sm")

def is_body_text(text: str, threshold: float = 0.5) -> bool:
    doc = nlp(text)
    tokens = [t for t in doc if not t.is_punct and not t.is_space]
    if len(tokens) < 3:
        return False
    stopword_ratio = sum(1 for t in tokens if t.is_stop) / len(tokens)
    return stopword_ratio > threshold
```

**Etapa 2 — Ausência de padrão estruturado:**
Se `is_body_text` passa E o campo não bate nenhum padrão de campo estruturado (regex: telefone, e-mail, CPF, CNPJ, data, valor monetário, CEP, número de certificado/apólice), classificar como `static_body_text`.

**Integração:**
```python
# Após _classify_fields_multi_example():
for field in likely_dynamic_fields:
    if is_body_text(field.value_text) and not matches_structured_pattern(field.value_text):
        field.classification = "static_body_text"
        field.send_to_stage4 = False
```
