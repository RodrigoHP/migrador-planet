# Story 48.5 — Stage 4: List Binding — Seção Repetida → XSD maxOccurs > 1

## Status: Done

## Descrição

Com o Stage 3 produzindo nós `repeated_section` no document tree (48.4), o Stage 4 precisa processar esses nós de forma diferente dos campos escalares: em vez de `campo → xsd_field_path`, gera `seção repetida → XSD nó com maxOccurs > 1`.

**Antes (scalar binding):**
```json
{"field": "nome_segurado_1", "xsd_field_path": "SubGrupo.Segurados.Segurado.Nome"}
{"field": "nome_segurado_2", "xsd_field_path": "SubGrupo.Segurados.Segurado.Nome"}  // duplicado!
```

**Depois (list binding):**
```json
{
  "section": "segurado_row",
  "binding_type": "list",
  "xsd_list_path": "SubGrupo.Segurados.Segurado[]",
  "xsd_max_occurs": "unbounded",
  "item_fields": [
    {"field": "nome", "xsd_field_path": "SubGrupo.Segurados.Segurado.Nome"},
    {"field": "cpf", "xsd_field_path": "SubGrupo.Segurados.Segurado.CPF"},
    {"field": "plano", "type": "static", "value": "Previdência VG"}
  ]
}
```

## Acceptance Criteria

- [x] **AC1:** Stage 4 detecta nós `type: "repeated_section"` no document tree e gera `ListBinding` em vez de N `FieldMappingEntry` individuais
- [x] **AC2:** `ListBinding` inclui: `xsd_list_path` (nó XSD com `maxOccurs > 1`), `xsd_max_occurs`, `item_fields[]` (binding dos campos dentro de uma instância do item)
- [x] **AC3:** XSD parsing (Step 4.1) já extrai `maxOccurs` — verificar se `xsd_integration.py` lê e expõe esse atributo. Adicionar se ausente.
- [x] **AC4:** Gemini Flash (Step 4.5) recebe prompt adaptado para lista: "Este bloco repete N vezes. Identifique o nó XSD com maxOccurs > 1 que corresponde à lista, e mapeie cada campo do item para o campo XSD filho."
- [x] **AC5:** `context["field_mappings"]` inclui as `ListBinding` junto com as `FieldMappingEntry` escalares — sem quebrar o contrato existente para campos escalares
- [x] **AC6:** Testes de integração `@pytest.mark.integration` cobrem: repeated_section com XSD com maxOccurs → ListBinding gerado corretamente

**Novo Step 4.5b — list binding prompt:**

```
Você está mapeando uma seção que se repete {N} vezes neste documento.
A seção tem os seguintes campos por item: {item_template.fields}

No XSD abaixo, identifique:
1. O elemento que representa a lista (maxOccurs="unbounded" ou > 1)
2. Para cada campo do item, o elemento filho correspondente

XSD candidatos (já filtrados por seção): {xsd_candidates}

Retorne JSON: {"list_path": "...", "item_fields": [{"field": "...", "xsd_path": "..."}]}
```

**Pydantic model:**
```python
class ListBinding(BaseModel):
    section_id: str
    xsd_list_path: str          # ex: "SubGrupo.Segurados.Segurado"
    xsd_max_occurs: str         # "unbounded" | "N"
    item_fields: list[FieldMappingEntry]
    confidence: float
    list_item_count: int        # N instâncias detectadas no PDF
```
