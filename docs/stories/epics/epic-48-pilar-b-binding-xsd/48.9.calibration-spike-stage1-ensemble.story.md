# Story 48.9 — SPIKE: Calibração Empírica dos Thresholds Stage 1 Ensemble Voting

## Status: Done

## Descrição

Determinar empiricamente os thresholds ótimos para os 4 sinais do algoritmo Multi-Signal Ensemble Voting que substituirá o clustering atual do Stage 1.

O spike 48.7 confirmou que o Stage 1 atual falha ao agrupar 3 instâncias do mesmo template (PosicaoConsolidada) — cada PDF virou um cluster separado. A causa raiz: o algoritmo pesa conteúdo (valores que mudam) sobre estrutura (layout que é constante).

A solução arquitetada usa 4 sinais independentes com voting majoritário. Este spike calibra os limites numéricos de cada sinal usando os 36 PDFs reais disponíveis em `backend/tests/fixtures/samples/`.

## Acceptance Criteria

- [ ] **AC1:** Script `backend/scripts/spike_48_calibration.py` roda sem erros contra todos os tipos em `backend/tests/fixtures/samples/` (boleto, apolice, dirf, relatorio)
- [ ] **AC2:** Para cada sinal, script produz distribuição de scores para pares SAME (mesmo template) vs DIFF (templates distintos) com separação clara (gap ≥ 0.1)
- [ ] **AC3:** Thresholds ótimos identificados e justificados:
  - `T_phash` (distância Hamming máxima para same) — inteiro em [0, 64]
  - `T_font` (similaridade Jaccard mínima para same) — float em [0.0, 1.0]
  - `T_struct` (distância de edição normalizada máxima para same) — float em [0.0, 1.0]
  - `T_markdown` (hash match = bool) — sem threshold numérico, confirmar viabilidade do sinal
- [ ] **AC4:** Relatório `docs/reports/epic-48/calibration-thresholds.json` com: thresholds recomendados, precision/recall esperados por threshold, distribuição de scores
- [ ] **AC5:** `docs/reports/epic-48/calibration-summary.md` com interpretação — qual sinal é mais discriminativo, qual tem mais sobreposição SAME/DIFF, recomendações para implementação

**Sinal 1 — pHash Masked Thumbnail:**
```python
def masked_thumbnail(page, size=128):
    pix = page.get_pixmap(matrix=fitz.Matrix(size/page.rect.width, size/page.rect.height))
    img = Image.frombytes("RGB", [pix.width, pix.height], pix.samples)
    draw = ImageDraw.Draw(img)
    for block in page.get_text("blocks"):
        if int(block[6]) == 0:  # texto
            x0, y0, x1, y1 = [c * size / page.rect.width for c in block[:4]]
            draw.rectangle([x0, y0, x1, y1], fill=(200, 200, 200))
    return imagehash.phash(img.convert("L"))
```

**Sinal 2 — Font Jaccard:**
```python
def font_signature(page):
    sig = set()
    for block in page.get_text("dict")["blocks"]:
        for line in block.get("lines", []):
            for span in line.get("spans", []):
                y_bucket = round(span["origin"][1] / page.rect.height * 10) / 10
                size_bucket = round(span["size"] * 2) / 2
                sig.add((y_bucket, span["font"], size_bucket))
    return frozenset(sig)
```

**Sinal 3 — Structural Edit Distance:**
```python
def layout_sequence(page):
    blocks = page.get_text("blocks")
    return [(round(b[0], -1), round(b[1], -1), round(b[2]-b[0], -1)) for b in blocks if int(b[6]) == 0]
```
