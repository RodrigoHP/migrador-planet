# Story 48.6 — Stage 5: Loop Rendering — `<repeat data-list="...">` no Template HTML

## Status: Ready

## Descrição

Com o Stage 4 produzindo `ListBinding` (48.5), o Stage 5 precisa renderizar seções repetidas como loops no template HTML em vez de campos estáticos duplicados.

**Antes (renderização escalar incorreta):**
```html
<div class="segurado-row">
  <span data-field="SubGrupo.Segurados.Segurado.Nome">JOAO DA SILVA</span>
  <span data-field="SubGrupo.Segurados.Segurado.CPF">123.456.789-00</span>
</div>
<div class="segurado-row">  <!-- duplicado — ERRADO -->
  <span data-field="SubGrupo.Segurados.Segurado.Nome">MARIA SANTOS</span>
  ...
</div>
```

**Depois (loop rendering correto):**
```html
<repeat data-list="SubGrupo.Segurados.Segurado[]" data-count="12">
  <div class="segurado-row">
    <span data-field="Nome">{{Nome}}</span>
    <span data-field="CPF">{{CPF}}</span>
    <span class="static">Previdência VG</span>
  </div>
</repeat>
```

## Notas de Implementação

**Estrutura do `<repeat>`:**

```html
<!-- Atributos:
  data-list="XSD.Path.Elemento[]"  → path XSD da lista (com [] para indicar array)
  data-count="N"                    → número de instâncias detectadas no PDF de exemplo
  style="..."                       → bbox da envelope que engloba todas as instâncias
-->
<repeat data-list="SubGrupo.Segurados.Segurado[]" data-count="12"
        style="position:absolute; top:200px; left:50px; width:495px; height:450px">
  <div class="repeat-item" style="height:37.5px">  <!-- height = envelope_height / N -->
    <span class="dynamic" data-field="Nome" style="...">{{Nome}}</span>
    <span class="dynamic" data-field="CPF" style="...">{{CPF}}</span>
    <span class="static" style="...">Previdência VG</span>
  </div>
</repeat>
```

**CSS para loop:**
```css
repeat { display: block; overflow: visible; }
.repeat-item { position: relative; box-sizing: border-box; }
```

**Coverage score:**
```python
# coverage_overlay.py
list_score = min(list_binding_count / max_expected_lists, 1.0) * 25  # 25% do score para listas
```
