# Story 48.3 — SPIKE: Ground Truth — Dynamic/Static + Repeated Sections por Tipo

## Status: Done

## Descrição

Antes de qualquer implementação, estabelecer o **ground truth completo** para validação:

1. **Campos escalares:** quais campos mudam entre instâncias (dynamic) vs. são constantes (static/label) — igual ao planejado originalmente.
2. **Seções repetidas:** dentro de um único PDF, quais blocos/seções aparecem N vezes na mesma página (ex.: lista de segurados, movimentações de extrato, itens de boleto parcelado).

Este spike alimenta duas stories downstream:
- **48.4** — usa a lista de seções repetidas como referência para implementar a detecção no Stage 3
- **48.7** — usa o ground truth completo para medir accuracy do pipeline

## Escopo

### IN
- Script PyMuPDF para dois tipos de análise:
  1. **Cross-instance** (3+ PDFs): blocos na mesma bbox → compara texto → dynamic vs static

## Método (Intra-page repeated sections)

```python
# Detectar seções repetidas dentro de uma página
def detect_repeated_sections(page_blocks: list[dict]) -> list[dict]:
    """
    Agrupa blocos por similaridade de estrutura (largura, posição x, número de spans).
    Grupos com N≥2 ocorrências em posições y progressivas → seção repetida.
    """
    groups = defaultdict(list)
    for block in page_blocks:
        if block.get("type") != 0:  # só texto
            continue
        # Fingerprint estrutural: largura arredondada + posição x + n_spans
        width_bucket = round(block["bbox"][2] - block["bbox"][0], -1)  # múltiplo de 10
        x0_bucket = round(block["bbox"][0], -1)
        n_spans = sum(len(line["spans"]) for line in block.get("lines", []))
        key = (width_bucket, x0_bucket, n_spans)
        groups[key].append(block)
    
    repeated = []
    for key, blocks in groups.items():
        if len(blocks) >= 2:
            repeated.append({
                "fingerprint": key,
                "occurrences": len(blocks),
                "bboxes": [b["bbox"] for b in blocks],
                "sample_texts": [b["lines"][0]["spans"][0]["text"] for b in blocks if b.get("lines")],
            })
    return repeated
```
