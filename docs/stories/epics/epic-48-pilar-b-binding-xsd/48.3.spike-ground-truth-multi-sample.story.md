# Story 48.3 — SPIKE: Ground Truth Multi-Sample — Comparar Blocos Entre Instâncias do Mesmo Template

## Status: Ready

## Descrição

Antes de validar o pipeline com input multi-sample (48.4), é necessário estabelecer o **ground truth** — quais campos do template realmente mudam entre instâncias (dinâmicos) vs. quais são sempre iguais (estáticos/labels).

Este spike usa PyMuPDF para comparar blocos de texto entre 3+ PDFs do mesmo template e produzir um ground truth auditável para comparação com o output do pipeline.

**PDFs necessários (pré-requisito do usuário):**
- 3+ instâncias do mesmo template por tipo, ex.:
  - 3 `BoletoCorporate` de meses diferentes
  - 3 `PosicaoConsolidada` de datas diferentes
  - 2 tipos como mínimo para validação cruzada

## Acceptance Criteria

- [x] **AC1:** Script `backend/scripts/spike_48_ground_truth_multisample.py` analisa 3+ PDFs do mesmo template e produz relatório JSON com campos classificados como `dynamic` (muda entre instâncias) vs `static` (idêntico em todas)
- [x] **AC2:** Relatório inclui lista de campos dinâmicos esperados (ex.: `data_vencimento`, `valor_boleto`, `codigo_barras` para boleto) com exemplos de valores de cada instância
- [x] **AC3:** Script compatível com todos os tipos: boleto, relatório, DIRF, certificado
- [x] **AC4:** Output salvo em `docs/reports/epic-48/ground-truth-multisample-{tipo}.json`
- [x] **AC5:** Relatório incluído em `docs/reports/epic-48/multisample-analysis.md` com interpretação manual dos campos dinâmicos identificados

## Escopo

### IN
- Script PyMuPDF que compara blocos de texto posição-a-posição entre PDFs
- Lógica de alinhamento espacial: blocos na mesma bbox (~5pt tolerância) entre instâncias são comparados
- Campos onde texto muda → `dynamic_ground_truth`; campos onde texto é idêntico → `static_ground_truth`
- Suporte a multi-página (comparar página N de instância A com página N de instância B)

### OUT
- Mudanças no pipeline
- Validação via Railway API (isso é 48.4)
- Correções baseadas nos resultados

## Método

```python
# Algoritmo de comparação multi-sample
for page_num in range(max_pages):
    for instancia_a, instancia_b, instancia_c in zip(pdfs):
        blocks_a = get_blocks(instancia_a, page_num)
        blocks_b = get_blocks(instancia_b, page_num)
        blocks_c = get_blocks(instancia_c, page_num)
        
        for block_a in blocks_a:
            matching_b = find_block_at_same_bbox(block_a.bbox, blocks_b, tolerance=5.0)
            matching_c = find_block_at_same_bbox(block_a.bbox, blocks_c, tolerance=5.0)
            
            if matching_b and matching_c:
                texts = {block_a.text, matching_b.text, matching_c.text}
                if len(texts) > 1:  # texto diferente entre instâncias
                    ground_truth[block_a.bbox] = "dynamic"
                else:
                    ground_truth[block_a.bbox] = "static"
```
