# Story 43.5 — PIL Pixel Sampling Per-Row para Background de Células Raster

## Status: InReview

## Descrição

`sample_table_colors()` atual retorna uma única cor de header background. Para tabelas com linhas alternadas (ex: cinza/branco/cinza), precisamos de `row_bg_colors: list[str]` — uma cor por linha.

Temos `row_heights_pct` da `_parse_html_table()` e o crop PNG da tabela. Com isso calculamos os y-boundaries de cada row e amostramos o pixel central de cada uma.

## Acceptance Criteria

- [ ] **AC1**: `sample_table_colors(image_path, row_heights_pct)` retorna `row_bg_colors: list[str]` (hex) com uma entrada por row
- [ ] **AC2**: Linha branca (#FFFFFF ±30) e linha cinza (#CCCCCC ±30) detectadas corretamente em imagem de teste sintética
- [ ] **AC3**: Para boleto atual (todas brancas): `row_bg_colors = ["#FFFFFF", "#FFFFFF", "#FFFFFF"]`
- [ ] **AC4**: `header_bg_color` permanece separado (cor da primeira row, que é o header)
- [ ] **AC5**: Fallback: se `row_heights_pct` não informado, comportamento atual (uma cor)

## Dev Notes

```python
def sample_table_colors(image_path, row_heights_pct=None, header_height_frac=0.12):
    img = Image.open(image_path).convert("RGB")
    w, h = img.size
    
    row_bg_colors = []
    if row_heights_pct:
        y = 0
        for pct in row_heights_pct:
            row_h = int(h * pct)
            cy = y + row_h // 2  # centro vertical da row
            strip = img.crop((10, cy - 2, w - 10, cy + 2))
            pixels = list(strip.getdata())
            r = int(statistics.median(p[0] for p in pixels))
            g = int(statistics.median(p[1] for p in pixels))
            b = int(statistics.median(p[2] for p in pixels))
            row_bg_colors.append(f"#{r:02X}{g:02X}{b:02X}")
            y += row_h
```
