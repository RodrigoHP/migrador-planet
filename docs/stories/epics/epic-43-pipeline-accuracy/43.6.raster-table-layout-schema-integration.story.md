# Story 43.6 — Integrar Layout Schema (col_widths, row_bg_colors, font) no Template HTML de Tabelas Raster

## Status: Draft

## Descrição

Stories 43.2-43.5 produzem os dados de layout. Esta story integra tudo no schema final que o pipeline entrega para o template HTML:

- `col_widths_pct` via HTML colspan (mistral-ocr-pdf)
- `row_bg_colors[]` via PIL per-row sampling (43.5)
- `font_family / font_size / font_weight / text_color` via PyMuPDF `get_text('dict')`
- `border_color` via PIL edge sampling
- `bbox` da tabela na página via PyMuPDF `get_image_bbox()`

## Schema Alvo

```python
{
    "type": "raster_table",
    "source": "mistral_ocr_pdf",
    "bbox": [x0, y0, x1, y1],          # posição exata na página (PyMuPDF)
    "headers": ["Col1", "Col2", ...],
    "rows": [["v1", "v2"], ...],
    "layout": {
        "col_widths_pct": [0.25, 0.25, 0.25, 0.25],
        "row_heights_pct": [0.33, 0.33, 0.33],
    },
    "style": {
        "font_family": "Arial",         # PyMuPDF (exato)
        "font_size_pt": 8.0,            # PyMuPDF (exato)
        "font_weight": "bold|normal",   # PyMuPDF flags (exato)
        "text_color": "#000000",        # PyMuPDF (exato)
        "header_bg_color": "#FFFFFF",   # PIL sampling
        "row_bg_colors": ["#FFFFFF", "#CCCCCC", "#FFFFFF"],  # PIL per-row (43.5)
        "border_color": "#000000",      # PIL sampling
        "border_width_pt": 1.0,         # heurístico
    }
}
```

### Font dominante de uma região

```python
def extract_dominant_font(page, bbox):
    spans = [
        span
        for b in page.get_text('dict')['blocks']
        for line in b.get('lines', [])
        for span in line.get('spans', [])
        if _bbox_overlaps(span['bbox'], bbox)
    ]
    if not spans:
        return {}
    # moda de font_family
    from collections import Counter
    font = Counter(s['font'] for s in spans).most_common(1)[0][0]
    size = statistics.median(s['size'] for s in spans)
    bold = any('BOLD' in s['font'].upper() or s['flags'] == 20 for s in spans)
    color = Counter(s['color'] for s in spans).most_common(1)[0][0]
    r=(color>>16)&0xFF; g=(color>>8)&0xFF; b=color&0xFF
    return {
        "font_family": font.split('_')[0].split('[')[0],  # "Arial"
        "font_size_pt": round(size, 1),
        "font_weight": "bold" if bold else "normal",
        "text_color": f"#{r:02X}{g:02X}{b:02X}",
    }
```
