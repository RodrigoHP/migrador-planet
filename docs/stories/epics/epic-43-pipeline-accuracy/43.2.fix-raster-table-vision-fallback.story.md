# Story 43.2 — Fix Raster Table Extraction: Vision API Fallback para Tabelas JPEG

## Status: InReview

## Descrição

A tabela de parcelas do boleto Corporate.Boleto.Convenio.pdf é um JPEG 2174×1337 pixels embutido na página. `page.find_tables()` retorna 0 (PyMuPDF requer texto vetorial ou ruling lines para detecção). O fallback existente em `section_utils.py` (`_build_visual_table_from_blocks`) tenta agrupar text blocks na região, mas retorna `None` quando não há blocks no bbox — que é exatamente o caso de tabelas raster.

**Impacto medido (job f6fd4a39, boleto Corporate.Boleto.Convenio.pdf):**
- Tabelas extraídas: **0/1 = 0%** (expected: 1 tabela de parcelas com ~15 colunas XSD)
- GPT-4o Visual detectou corretamente `table_area` no JSON de visual_analysis

**Comportamento atual:**
1. Stage 2.7: `_detect_tables(page)` → `page.find_tables()` → `[]` (raster, sem ruling lines vetoriais)
2. Stage 3.2: GPT-4o detecta `type: "table_area"` no visual_analysis com bbox correto
3. `_assign_visual_elements_to_sections`: encontra `table_area` → chama `_build_visual_table_from_blocks`
4. `_build_visual_table_from_blocks`: `in_region = []` (zero text blocks no bbox) → retorna `None`
5. Nenhuma tabela adicionada ao documento. Stage 4+ nunca vê a tabela.

**Campos XSD que dependem da tabela (perdidos):**
- `BOLETO.PARCELAS.PARCELA.DATA_VENCIMENTO`
- `BOLETO.PARCELAS.PARCELA.VALOR`
- `BOLETO.PARCELAS.PARCELA.NUMERO`
- `BOLETO.PARCELAS.PARCELA.STATUS`
- (e outros ~10 campos na estrutura PARCELA)

## Dev Notes

### Contexto Técnico

**Infraestrutura Vision já existente:**
A `visual_analysis.py` (Stage 3.2) já usa `chat_with_vision` e tem o padrão de custo. O mesmo vision_client disponível no `context` pode ser reutilizado.

**Ponto de intervenção — `section_utils.py` linha 515-522:**
```python
if not already_covered:
    all_blocks = []
    for z in zones:
        for s in z.get("sections", []):
            all_blocks.extend(s.get("blocks", []))
    synthetic = _build_visual_table_from_blocks(all_blocks, rbbox)
    if synthetic:
        section.setdefault("tables", []).append(synthetic)
    # ← AQUI: se synthetic is None, chamada Vision API necessária
```

**Desafio de threading async:**
`_assign_visual_elements_to_sections` é função síncrona. A chamada Vision API é async. 

**Opção A (recomendada):** Marcar raster tables como pendentes na primeira passagem síncrona, resolver em passagem async separada no `tree_builder.py` após `_assign_visual_elements_to_sections`:
```python
# section_utils.py — marcar pendência:
if not synthetic:
    section.setdefault("_pending_raster_tables", []).append({
        "bbox": rbbox,
        "page_key": page_key,
        "description": region.get("description", ""),
    })

# tree_builder.py — resolver pendências:
async def _resolve_raster_tables(zones, screenshot_path, vision_client, context):
    """Chamada Vision API para tabelas raster pendentes."""
    for zone in zones:
        for section in zone.get("sections", []):
            for pending in section.pop("_pending_raster_tables", []):
                table = await _extract_raster_table(
                    pending["bbox"], screenshot_path, vision_client
                )
                if table:
                    section.setdefault("tables", []).append(table)
```

**Opção B:** Tornar `_assign_visual_elements_to_sections` async, passar screenshot_path e vision_client como parâmetros.

**Opção C (mais simples):** Executar a chamada Vision API diretamente na `visual_analysis.py` (Stage 3.2) quando um `table_area` for detectado — neste ponto, temos screenshot_path, vision_client, e conhecemos o bbox. Injetar a tabela extraída no `visual_analysis` result como `"extracted_table"` dentro do region dict, para que `_assign_visual_elements_to_sections` possa consumi-la sem async.

### Prompt para Extração de Tabela Raster
```
You are a table extractor. Extract ALL data from the table in this image.

Return ONLY valid JSON in this exact format:
{
  "headers": ["Col1", "Col2", "Col3"],
  "rows": [
    ["val1", "val2", "val3"],
    ["val4", "val5", "val6"]
  ]
}

Rules:
- Include all rows, including total/summary rows
- Use empty string "" for empty cells
- Preserve original text exactly (dates, numbers, names)
- If no clear header row, use positional headers: ["Col1", "Col2", ...]
```
