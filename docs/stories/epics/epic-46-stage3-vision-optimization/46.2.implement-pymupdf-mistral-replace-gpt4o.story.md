# Story 46.2 — Eliminar GPT-4o Vision: PyMuPDF + Mistral incondicional

## Status: Done

## Descrição

A spike 46.1 revelou que o GPT-4o Vision pode ser eliminado do Stage 3.2 usando um caminho diferente do hipotetizado: **PyMuPDF** (já disponível no projeto) fornece bbox exato das imagens raster sem custo de API, enquanto **Mistral chamado incondicionalmente** já detecta e extrai tabelas raster sem precisar do GPT-4o como trigger.

Implementar as modificações em `visual_analysis.py` para eliminar a dependência do GPT-4o Vision.

## Referências Técnicas

- **Relatório spike:** `docs/reports/epic-46-vision-optimization/46.1-mistral-bbox-spike.md`
- **Código alvo:** `backend/services/stages/stage3_structural/visual_analysis.py`
- **Funções alvo:** `_run_3_2`, `_extract_raster_table_mistral`

## Acceptance Criteria

### AC1 — Mistral chamado incondicionalmente por página

Remover o gate `if region.type == "table_area"` que condiciona a chamada Mistral ao resultado do GPT-4o.
Mistral deve ser chamado para cada página representativa, independente do GPT-4o.

**Critério:** `_run_3_2` não chama `_call_gpt4o_vision` em nenhum branch do código.

### AC2 — Bbox de tabela raster via PyMuPDF

Para cada tabela retornada em `tables[]` pelo Mistral, localizar a imagem raster correspondente via PyMuPDF (`page.get_images()` + `page.get_image_bbox()`).

**Critério:** `table["bbox"]` em `_extract_raster_table_mistral` vem de PyMuPDF, não de GPT-4o. Bbox preciso dentro de ≤2 pts da imagem real.

### AC3 — Zone detection via extract_header/extract_footer

Usar `extract_header=True` e `extract_footer=True` do Mistral para detectar zonas header/footer, substituindo a análise GPT-4o de zonas.

**Critério:** `stage3_result.header_zone` e `footer_zone` populados a partir do texto do Mistral header/footer. Footer `"#"` tratado como ausente.

### AC4 — Fallback para Mistral sem tabela detectada

Quando `tables[]` retorna vazio (página sem tabela raster), o pipeline continua sem erro. Tabela vetorial ainda é processada via pdfplumber.

**Critério:** teste com PDF sem tabela raster não gera erro; `table_area` fica `None`.

### AC5 — Testes unitários cobrem os novos paths

Testes `@pytest.mark.unit` para:
- `_extract_raster_table_mistral` usando PyMuPDF mock
- `_run_3_2` sem chamada GPT-4o
- Tratamento de footer `"#"` vs footer real

**Critério:** `make test` passa sem regressões.

## Valor de Negócio

Elimina $0.01/cluster (GPT-4o Vision) + ~8s latência. Bônus: bbox PyMuPDF é mais preciso que GPT-4o (erro de ~100 pts → 0 pts), melhorando fidelidade do template.

## Riscos

def _extract_raster_table_mistral(self, pdf_path, page_index, mistral_pages_data):
    import fitz
    doc = fitz.open(pdf_path)
    page = doc[page_index]
    raster_bboxes = [
        list(page.get_image_bbox(img))
        for img in page.get_images(full=True)
    ]
    doc.close()

### Heurística para descartar imagens pequenas (logos/barcodes)

```python
MIN_TABLE_AREA_PTS = 100 * 50  # 100x50 pontos PDF mínimo

def _is_likely_table_image(bbox: list[float]) -> bool:
    w = bbox[2] - bbox[0]
    h = bbox[3] - bbox[1]
    return w * h >= MIN_TABLE_AREA_PTS
```
