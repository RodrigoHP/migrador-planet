# Story 14.6 — Background Color per-Elemento + ColorPicker Enhanced (F6 + M1)

## Story

**Como** operador do editor de templates,
**Quero** configurar `background-color` em qualquer elemento (não apenas seções) e usar um color picker com suporte a opacity (rgba), paleta do documento e cores recentes,
**Para** replicar fielmente elementos com fundo colorido do PDF original (ex: header "RECIBO DO SACADO" com fundo cinza, blocos "Instruções" com fundo diferenciado) sem precisar editar CSS manualmente.

## Status

Done

## Context

### Problema

Atualmente, o `ElementInspector.vue` permite editar cor de **texto** (font color) via `InspectorColorPicker`, mas **não oferece `background-color`**. Apenas o `SectionInspector.vue` tem `background-color`. Isso significa que, para elementos individuais (campos, labels, valores), o operador não consegue definir fundo colorido pelo inspector.

Além disso, o `InspectorColorPicker.vue` usa `<input type="color">` nativo do HTML5, que:
1. **Não suporta alpha/opacity** — só hex RGB (`#rrggbb`), sem RGBA
2. **Não tem paleta do documento** — cores extraídas do PDF não são sugeridas
3. **Não tem cores recentes** — sem histórico das últimas cores usadas
4. **UX limitada** — depende do seletor nativo do OS, sem controle de layout

### Estado Atual do Código

**`frontend/src/organisms/inspectors/ElementInspector.vue`** (linhas 16-26):
```html
<!-- Tipografia -->
<InspectorSection title="Tipografia" :collapsible="true">
  <InspectorField label="Família da Fonte" :value="strValue('font_family')" />
  <InspectorField label="Tamanho" :value="pxValue('font_size')" />
  <InspectorField label="Peso" :value="strValue('font_weight')" />
  <InspectorField
    label="Cor"
    :value="strValue('color')"
    :type="p['color'] ? 'color' : 'text'"
  />
  <!-- SEM background-color aqui -->
</InspectorSection>
```

**`frontend/src/organisms/inspectors/SectionInspector.vue`** (linhas 16-21):
```html
<InspectorColorPicker
  label="Cor de Fundo"
  :model-value="(p['background_color'] as string) || ''"
  @update:model-value="setProp('background_color', $event)"
/>
```
Este é o padrão a seguir para adicionar background-color ao ElementInspector.

**`frontend/src/molecules/InspectorColorPicker.vue`** (completo):
```html
<input type="color" :value="modelValue || '#000000'" @input="onInput" />
<span>{{ modelValue || '—' }}</span>
```
Componente simples: HTML5 color input sem alpha, sem paleta, sem recentes.

**`frontend/src/stores/templateStore.ts`**:
- `updateNodeProperty(nodeId, path, value)` — API existente para persistir propriedades de qualquer nó

### Solução Necessária

**F6 — Background per-elemento:**
1. Adicionar seção "Aparência" ao `ElementInspector.vue` com `InspectorColorPicker` para `background_color`
2. Incluir opções `transparent` e `inherit` como presets rápidos
3. Usar `updateNodeProperty()` do templateStore (padrão existente no SectionInspector)

**M1 — ColorPicker Enhanced:**
1. Refatorar `InspectorColorPicker.vue` para substituir `<input type="color">` por componente custom
2. Adicionar opacity slider (0-100%) que gera valor RGBA
3. Adicionar paleta de cores do documento (extraídas do PDF via `templateStore`)
4. Adicionar presets de cores recentes (últimas 8 usadas, persistidas no `localStorage`)

## Acceptance Criteria

1. **AC1 — Background no ElementInspector:** O `ElementInspector.vue` tem seção "Aparência" com campo `background-color` via `InspectorColorPicker`, seguindo o mesmo padrão do `SectionInspector.vue`
2. **AC2 — Transparent/Inherit:** O color picker oferece botões rápidos "Transparente" (`transparent`) e "Herdar" (`inherit`) que limpam ou definem o valor sem abrir o seletor de cor
3. **AC3 — Opacity Slider:** O `InspectorColorPicker` exibe slider de opacity (0%–100%) que converte o valor para RGBA (ex: `#336699` + 80% → `rgba(51, 102, 153, 0.8)`)
4. **AC4 — Paleta do Documento:** O color picker mostra até 12 cores extraídas do PDF (cores únicas detectadas nos blocos de texto e backgrounds), obtidas via `templateStore.documentTree`
5. **AC5 — Cores Recentes:** As últimas 8 cores usadas são exibidas como swatches clicáveis no color picker e persistidas em `localStorage` (chave: `migrador-planet:recent-colors`)
6. **AC6 — Retrocompatibilidade:** O `SectionInspector.vue`, `ChartInspector.vue` e qualquer outro consumidor de `InspectorColorPicker` continua funcionando sem mudanças — as novas features (opacity, paleta, recentes) são aditivas, incluindo elementos de gráficos que possam ter background-color
7. **AC7 — Canvas Sync:** Ao alterar `background-color` de um elemento no inspector, o canvas reflete a mudança imediatamente via `updateNodeProperty()` + renderização reativa
8. **AC8 — Testes:** Cobertura de testes: InspectorColorPicker (opacity conversion, paleta rendering, recentes persistência), ElementInspector (background-color field renderizado e funcional)
9. **AC9 — Acessibilidade ColorPicker:** Swatches de paleta e recentes tem `role="option"` com `aria-label="Cor #RRGGBB"` dentro de container `role="listbox"`. Opacity slider usa `<input type="range">` nativo com `aria-label="Opacidade"` e `aria-valuetext="${value} porcento"`. Botões Transparent/Inherit tem `aria-label` descritivo. Mudança de cor anunciada via `aria-live="polite"`
