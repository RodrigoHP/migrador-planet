# Story 15.19 — Fix métrica PÁGINAS durante pipeline

## Story
**Como** operador que acompanha o pipeline pela AnalyzingPage,
**Quero** que o card PÁGINAS exiba a contagem de páginas assim que o Stage 1 conclui,
**Para** ter visibilidade do volume processado durante a execução, não apenas no final.

## Status
Done

## Context

### FIX-PIPELINE-008: pageCount só populado no evento pipeline_completed

O card PÁGINAS no rodapé da AnalyzingPage usa `summaryData.pageCount`, que é alimentado pelo campo `page_count` do SSE:

```js
// AnalyzingPage.vue:509
if (s.page_count !== undefined) summaryData.value.pageCount = s.page_count as number
```

O campo `page_count` só existe no evento `pipeline_completed` (emitido ao final do pipeline). Durante a execução, Stages 1 e 2 emitem `pages_processed` no summary, mas esse campo nunca é lido pelo frontend.

**Resultado observado:** PÁGINAS mostra `—` durante todo o pipeline. Só exibe valor no sumário final.

**Exemplo dos eventos SSE:**
- Stage 1 completion: `summary: {"layouts_detected": 2, "pages_processed": 2}` → `pages_processed` ignorado
- Stage 2 completion: `summary: {"pages_processed": 2, "blocks_extracted": 30, "warnings": 0}` → `pages_processed` ignorado
- `pipeline_completed`: `summary: {"layouts_detected": 2, "page_count": 2, "api_cost": 0.025}` → `page_count` lido ✓

## Implementation Notes

**Fix no handler SSE em `AnalyzingPage.vue`:**

```js
// Adicionar após a linha 509:
if (s.page_count !== undefined) summaryData.value.pageCount = s.page_count as number
if (s.pages_processed !== undefined && summaryData.value.pageCount == null) {
  summaryData.value.pageCount = s.pages_processed as number
}
```

**Lógica:** `pages_processed` popula `pageCount` apenas se `page_count` ainda não chegou. Assim:
1. Stage 1 conclui → `pages_processed: 2` → `pageCount = 2` ✓
2. Stage 2 conclui → `pages_processed: 2` → `pageCount` já tem valor, não sobrescreve com dados de stage (poderia ser diferente)
3. `pipeline_completed` → `page_count: 2` → valor final confirma

**Alternativa mais simples** (se pages_processed sempre = page_count):
```js
if (s.page_count !== undefined) summaryData.value.pageCount = s.page_count as number
else if (s.pages_processed !== undefined) summaryData.value.pageCount = s.pages_processed as number
```
