# Story 40.10 — UX Polish & Accessibility

## Status: Done

## Descricao

Polimento visual e melhorias de acessibilidade: substituir emoji icons por lucide-vue-next, adicionar loading indicator no export, unificar design tokens duplicados, e implementar focus indicators customizados. Melhora a consistencia visual e WCAG AA compliance.

## Acceptance Criteria

- [x] Emojis literais no toolbar substituidos por icones lucide-vue-next (Map, ArrowLeftRight, Magnet, Ruler)

- [x] Design tokens definidos em unico local (preferencia: Tailwind config como SSOT)

- [x] Lighthouse accessibility score >= 95

## Dev Notes

- **UX-005**: Replaced 7 emoji icons (toolbar toggles + action buttons) with Lucide SVG icons: Map, ArrowLeftRight, Magnet, Ruler, Wrench, FolderOpen, Save, Package, Loader2. SVGs render identically across all OS.
- **UX-009**: Export button shows animated Loader2 spinner during export (CSS spin animation). Text changes to "Exportando..." while `isExporting` is true.
- **FE-008**: In Tailwind CSS v4, `@theme` in main.css IS the native config method. Removed duplicated colors from `tailwind.config.ts` (which is legacy in v4). `@theme` is now the sole SSOT.
- **A11Y-002**: Global `*:focus-visible` rule with `outline: 2px solid var(--color-primary-600)` + 2px offset. Dark-background variant adds semi-transparent box-shadow ring for extra visibility.
- ToggleButton `icon` prop is now `string | Component` — backward compatible with string fallback.
- All 1898 relevant tests pass. 1 pre-existing failure in InspectorField.spec.ts (unrelated color swatch assertion).
