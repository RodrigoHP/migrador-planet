# Story 5.6: XSD Parsing + Field Tree — Árvore Hierárquica de Campos

## Status
Draft

## Story
**As a** estágio do pipeline,
**I want** parsear o arquivo XSD e construir uma árvore hierárquica de campos com tipos e flags required/optional,
**so that** o motor de matching tenha nomes canônicos de campos para geração de data-bind.

## Acceptance Criteria
1. Parse XSD usando lxml, extrair todos os elementos com: name, type (string/decimal/date/integer/boolean), minOccurs, maxOccurs
2. Construir árvore hierárquica suportando paths aninhados (ex: cliente.endereco.cidade)
3. Detectar arrays: maxOccurs="unbounded" ou maxOccurs > 1 → campo array
4. Detectar opcionais: minOccurs="0" → campo opcional
5. Output: FieldTree com nós contendo { name, path, type, required, is_array, children[] }
6. Suportar complex types e estruturas aninhadas
7. Registrar no orchestrator, emitir SSE progress
8. XSD sintaticamente inválido gera erro bloqueante com mensagem indicando a natureza do erro (ex: "Erro de parse XSD: tag não fechada na linha 42"); pipeline marca estágio como failed
9. Testes cobrem: XSD simples, XSD aninhado, arrays, campos opcionais, complex types, XSD inválido

## Dev Notes

### Biblioteca
- lxml 5.x para parsing XML/XSD
- Instalação: `pip install lxml`

### Nomes Canônicos
- Nomes dos campos XSD tornam-se canônicos no data-bind
- Exemplo: `<xs:element name="nome" type="xs:string"/>` → `data-bind="text: cliente.nome"`
- Paths são dot-separated: `cliente.endereco.cidade`

### Exemplo de Estrutura XSD
```xml
<xs:schema>
  <xs:element name="documento">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="cliente">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="nome" type="xs:string"/>
              <xs:element name="cpf" type="xs:string"/>
              <xs:element name="endereco">
                <xs:complexType>
                  <xs:sequence>
                    <xs:element name="cidade" type="xs:string"/>
                  </xs:sequence>
                </xs:complexType>
              </xs:element>
            </xs:sequence>
          </xs:complexType>
        </xs:element>
        <xs:element name="movimentos" maxOccurs="unbounded">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="data" type="xs:date"/>
              <xs:element name="valor" type="xs:decimal"/>
            </xs:sequence>
          </xs:complexType>
        </xs:element>
      </xs:sequence>
    </xs:complexType>
  </xs:element>
</xs:schema>
```
