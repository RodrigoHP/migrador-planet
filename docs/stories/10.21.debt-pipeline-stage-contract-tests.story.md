# Story 10.21 — Debt: Testes de contrato de dados entre stages do pipeline

## Story
**Como** desenvolvedor do pipeline,
**Quero** ter testes de integração que validem o formato de `document_trees` ao longo dos stages 3→4→5,
**Para** que qualquer regressão no contrato de dados seja detectada automaticamente antes de atingir produção.

## Context
RCA `rca-2026-03-31-stage5-document-trees-contract` identificou que o bug `'list' object has no attribute 'get'` no Stage 5 era causado por um contrato de dados inconsistente: Stage 3 gravava `document_trees` como `List[Dict]` no context compartilhado, mas todos os consumidores esperavam `Dict[str, Dict]`. O fix foi aplicado (Stage 3 agora normaliza para dict), mas não existe nenhum teste que garanta que esse contrato se mantém.

Sem testes, qualquer mudança em `_run_3_4()` ou no código de normalização pode regredir silenciosamente.

## Acceptance Criteria

1. **Contrato Stage 3** — Teste unitário verifica que após `run_stage3()`, `context["document_trees"]` é `dict` (não `list`), com chaves sendo `cluster_id` strings.
2. **Contrato Stage 4** — Teste verifica que `run_stage4()` consome `context["document_trees"]` como dict sem erro e não altera o formato no context.
3. **Contrato Stage 5** — Teste verifica que `run_stage5()` e `_step_5_6_pipeline_result()` consomem `context["document_trees"]` como dict sem erro.
4. **Regressão list→crash** — Teste verifica que se (hipoteticamente) `context["document_trees"]` fosse uma lista ao entrar no Stage 5, o sistema falha com mensagem clara (não silenciosamente).
5. **Todos os testes passam** no CI sem dependências externas (mocks de LLM, storage).

## Scope

**IN:**
- `backend/tests/test_pipeline_stage_contracts.py` (novo arquivo)
- Cobertura de `run_stage3`, `run_stage4`, `run_stage5`, `_step_5_6_pipeline_result`
- Mocks para dependências externas (OpenRouter, StorageGateway, emit_progress)

**OUT:**
- Não modificar código dos stages
- Não criar testes E2E completos do pipeline (escopo separado)
- Não cobrir outros campos do context além de `document_trees`
