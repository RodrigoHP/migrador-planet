# Story 31.2 — Incluir pasta assets/ com imagens no ZIP

## Story
**Como** operador usando o editor de templates,
**Quero** que a pasta assets/ no ZIP contenha as imagens extraídas do PDF,
**Para** que logos e imagens apareçam ao abrir o template offline.

## Status
Done

## Acceptance Criteria

- [x] AC1: ZIP contém template/assets/ com imagens referenciadas no HTML
- [x] AC2: Referências src no HTML apontam para caminhos relativos assets/
- [x] AC3: Imagens do assetService são incluídas no ZIP quando disponíveis

## Scope

**IN:**
- Incluir imagens inline (data URIs do HTML) como arquivos na pasta assets
- Reescrever referências de imagem para caminhos relativos

**OUT:**
- Download de imagens de storage externo

## Tasks

- [x] Task 1: Extrair imagens data URI do HTML e salvar como arquivos no ZIP
- [x] Task 2: Reescrever src de data URI para assets/img-N.ext no HTML
- [x] Task 3: Testes unitários

## Dev Notes
Stage5 gera `<img src="{image_path}">` onde image_path pode ser:
- Um path do storage backend (não acessível offline)
- Um data URI (base64 inline)

Solução: no useExport, extrair data URIs do HTML, salvar como arquivos em assets/,
e reescrever as referências para caminhos relativos.
