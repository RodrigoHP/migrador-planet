# Story 12.7 — Feat: Snap — implementar lógica real de alinhamento no canvas

## Story
**Como** usuário do editor,
**Quero** que ao arrastar um elemento, ele se alinhe automaticamente com a grade e com outros elementos,
**Para** criar layouts organizados com precisão.

## Status
Draft

## Context

### Problema
O botão "Snap" na toolbar tem toggle, mas ativar não tem efeito algum. Arrastar elementos não alinha a nada.

### Root Cause

**`frontend/src/composables/useCanvasInteraction.ts`**

Funções existem mas são stubs:

### Dois Tipos de Snap

#### Tipo 1: Grid Snap
Arredonda para múltiplos de 8px (ou configurável).
```
GRID_SIZE = 8px (padrão)
snapToGrid(47) → 48
snapToGrid(51) → 48
```

#### Tipo 2: Element Snap (Smart Guides)
Alinha com bordas/centros de outros elementos na mesma página.
```
Elemento A: left=100, right=200, center=150, top=50, bottom=70
Elemento B sendo arrastado: se ficar a ≤8px do left/right/center → snap!
Mostra linha guia visual (azul tracejada)
```

### Solução

#### 1. Aplicar grid snap no drag

```typescript
// useCanvasInteraction.ts
function onDrag(nodeId: string, deltaX: number, deltaY: number) {
  const node = templateStore.getNode(nodeId)
  let newX = node.properties.x + deltaX
  let newY = node.properties.y + deltaY

  if (editorStore.snapEnabled) {
    newX = snapToGrid(newX)
    newY = snapToGrid(newY)
  }

  // Preview imediato (sem commit ao store)
  templateStore.previewNodePosition(nodeId, newX, newY)
}

function onDragEnd(nodeId: string, finalX: number, finalY: number) {
  let x = finalX
  let y = finalY

  if (editorStore.snapEnabled) {
    x = snapToGrid(x)
    y = snapToGrid(y)

    // Smart snap
    const snapResult = calcSmartSnap(nodeId, x, y)
    x = snapResult.x
    y = snapResult.y
    activeSnapLines.value = snapResult.lines
  }

  templateStore.updateNodePosition(nodeId, x, y)
  // Limpar snap lines após 500ms
  setTimeout(() => { activeSnapLines.value = [] }, 500)
}
```

#### 2. Smart snap contra vizinhos

```typescript
interface SnapLine {
  orientation: 'horizontal' | 'vertical'
  position: number    // px
  from: number        // início da linha
  to: number          // fim da linha
}

function calcSmartSnap(
  nodeId: string,
  x: number,
  y: number
): { x: number, y: number, lines: SnapLine[] } {
  const THRESHOLD = 8  // px
  const node = templateStore.getNode(nodeId)
  const siblings = templateStore.getSiblingNodes(nodeId)  // mesma página

  const nodeW = node.properties.width ?? 0
  const nodeH = node.properties.height ?? 0

  let finalX = x, finalY = y
  const lines: SnapLine[] = []

  for (const sibling of siblings) {
    const sx = sibling.properties.x ?? 0
    const sy = sibling.properties.y ?? 0
    const sw = sibling.properties.width ?? 0
    const sh = sibling.properties.height ?? 0

    // Snap X: left, right, center
    const snapPoints = [
      { from: sx, to: sx },                // left-to-left
      { from: sx + sw, to: sx + sw },      // right-to-right
      { from: sx, to: sx - nodeW },        // left-to-right
      { from: sx + sw, to: sx + sw + nodeW }, // right-to-left (edge align)
      { from: sx + sw/2 - nodeW/2, to: sx + sw/2 - nodeW/2 }, // center
    ]
    for (const sp of snapPoints) {
      if (Math.abs(x - sp.to) < THRESHOLD) {
        finalX = sp.to
        lines.push({ orientation: 'vertical', position: sp.from, from: 0, to: 1123 })
        break
      }
    }

    // Snap Y (similar): top, bottom, center
    // ... similar logic for Y axis
  }

  return { x: finalX, y: finalY, lines }
}
```

## Acceptance Criteria

1. **AC1 — Grid snap:** Com snap ativo, ao arrastar elemento, ele alinhe a múltiplos de 8px
2. **AC2 — Smart snap:** Com snap ativo, ao arrastar próximo de outro elemento, apareçam linhas guia e o elemento se alinhe
3. **AC3 — Snap lines visuais:** Linhas azuis tracejadas aparecem durante o snap
4. **AC4 — Snap off:** Com snap desativado, arrastar é livre (sem snap)
5. **AC5 — Grid size:** Usuário pode alterar grid size (8, 16, 24px) nas configurações
6. **AC6 — Pré-requisito:** Snap só funciona após Story 12.1 (elementos posicionados)
7. **AC7 — Performance:** Cálculo de snap em <2ms para canvas com 50 elementos
8. **AC8 — Testes:** Unitários para `snapToGrid()` e `calcSmartSnap()`
