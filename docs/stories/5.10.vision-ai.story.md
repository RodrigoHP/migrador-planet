# Story 5.10: Bloco 6: Vision AI — Segmentação Visual e Interpretação via GPT-4o

## Status
Draft

## Story
**As a** bloco do pipeline,
**I want** usar Vision AI (GPT-4o) para analisar screenshots das páginas para segmentação visual e interpretação, com validação self-check,
**so that** o sistema identifique elementos visuais que a extração de texto sozinha não consegue detectar.

## Acceptance Criteria
1. Stage 16 — Visual Segmentation: enviar screenshots para GPT-4o via OpenRouter, identificar regiões (header, body, footer, sidebar, table area, chart area, image area)
2. Stage 17 — Visual Interpretation: para cada região, GPT-4o descreve conteúdo e sugere estrutura (ex: "tabela com 3 colunas", "gráfico de barras", "logo da empresa")
3. Stage 18 — Self-Check: validar consistência entre output do Vision AI e output da extração de texto; reprocessar página se inconsistências significativas
4. Chamadas API via OpenRouter (chave API única, multi-provider)
5. Fallback: se Vision AI falhar ou timeout, continuar pipeline com análise text-only (confiança reduzida)
6. Rate limiting e lógica de retry para chamadas API
7. Todos os estágios registrados no orchestrator, emitindo SSE progress
8. Output enriquece cada página com: visual_regions[], visual_interpretations[], consistency_score
9. Configuração `VISION_AI_ENABLED` (env var, default: true): quando false, bloco Vision AI é inteiramente ignorado (skip) com warning SSE "Vision AI desabilitado via configuração"; pipeline continua com confiança reduzida
10. Custo estimado por job exibido no evento SSE de conclusão do bloco: "Vision AI: {N} chamadas, ~${custo_estimado}"
11. Testes cobrem: integração API (mock), comportamento de fallback, lógica de self-check, modo desabilitado

## Dev Notes

### OpenRouter API
- Compatível com OpenAI SDK — usar pacote `openai` Python com custom base_url
- Modelo: `openai/gpt-4o` para tarefas de visão
- Base URL: `https://openrouter.ai/api/v1`
- Header adicional: `HTTP-Referer` (identificação do app)

### Configuração do Cliente
```python
from openai import AsyncOpenAI

client = AsyncOpenAI(
    api_key=os.environ["OPENROUTER_API_KEY"],
    base_url="https://openrouter.ai/api/v1",
)

response = await client.chat.completions.create(
    model="openai/gpt-4o",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "Analyze this document page..."},
            {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{b64_image}"}}
        ]
    }],
    response_format={"type": "json_object"}
)
```

### Prompt Engineering
- Solicitar output em JSON estruturado
- Incluir contexto: "Este é um documento financeiro/bancário/fiscal"
- Pedir coordenadas de bounding box normalizadas (0-1) ou em pixels
- Pedir classificação de regiões com tipos pré-definidos

### Custo e Performance
- Vision AI é caro — processar APENAS páginas representantes
- Com 3 PDFs e 3 Layout Types: ~3-5 chamadas API
- Timeout por chamada: 30 segundos
- Custo estimado por job: $0.05-0.25
