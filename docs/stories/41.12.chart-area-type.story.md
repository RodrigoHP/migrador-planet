# Story 41.12: ChartInspector — Tipo "Área" como opção independente

## Status
Done

## Story
**As a** operador,
**I want** selecionar "Área" como tipo de gráfico distinto no ChartInspector,
**so that** gráficos de área do PDF sejam mapeados corretamente sem precisar usar "Linha" + checkbox "Barras empilhadas" como workaround.

## Context

### Gap identificado (auditoria `docs/audit/19-charts-barcode-svg.md`, Gap #5)

O PRD (FR26, linha 250) lista "Área" como tipo de gráfico independente. O ChartInspector atual oferece:
- `bar`, `line`, `pie`, `doughnut`, `polarArea` como tipos
- Checkbox "Barras empilhadas" como modifier de `bar`

**"Área" está ausente** como tipo distinto. O operador que quer um gráfico de área precisa selecionar "Linha" e não tem como indicar `fill: true`.

### Mapeamento Chart.js

`area` no ChartInspector → Chart.js `type: 'line'` com `fill: true` nas options.

Não é um tipo nativo do Chart.js — é uma configuração de `line`. Por isso deve ser tratado como tipo lógico no frontend, com mapeamento na geração de código.

## Acceptance Criteria

- [x] AC1: `ChartInspector.vue` exibe "Área" como opção no dropdown de tipo, entre "Linha" e "Pizza"
- [x] AC2: `chartStore.ts` — tipo `ChartType` inclui `'area'`; `resolveType()` mapeia detecção de área com confiança ≥60% para `'area'`
- [x] AC3: `chartCodeGen.ts` — `generateChartJsBlock()` mapeia `type: 'area'` para `type: 'line'` com `fill: true` nas options do Chart.js
- [x] AC4: `ChartPreview.vue` (ou equivalente) renderiza preview de área quando tipo é `'area'`
- [x] AC5: Testes em `chartCodeGen.spec.ts` (ou equivalente) cobrem: tipo `area` gera `type: 'line'` + `fill: true`

## Scope

**IN:**
- `ChartInspector.vue` — adicionar `{ value: 'area', label: 'Área' }` ao dropdown de tipos
- `chartStore.ts` — adicionar `'area'` ao tipo `ChartType`
- `chartCodeGen.ts` — mapeamento `area → line + fill: true`
- Testes para o mapeamento

**OUT:**
- "Área Empilhada" como tipo separado (pode ser feito no futuro com `fill: true` + `stacked: true`)
- Mudanças na detecção de gráficos no stage3 (backend Vision AI)
- Chart canvas placeholder (story 41.11)

## Dev Notes

### chartCodeGen.ts — mapeamento

```typescript
function getChartJsType(type: ChartType): string {
  if (type === 'area') return 'line'
  return type
}

function getChartJsOptions(chart: ChartConfig): object {
  const opts: Record<string, unknown> = { responsive: false }
  if (chart.type === 'area') opts['fill'] = true
  if (chart.stacked) opts['scales'] = { y: { stacked: true } }
  // ... demais options existentes
  return opts
}
```
