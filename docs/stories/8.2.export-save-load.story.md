# Story 8.2: Exportar ZIP + Salvar/Carregar Projeto

## Status
Draft

## Story
**As a** operador,
**I want** exportar o template como arquivo ZIP e salvar/carregar meu projeto como JSON,
**so that** eu possa entregar o template final e retomar o trabalho posteriormente.

## Acceptance Criteria
1. **AC1** — Botão "📦 Exportar" na toolbar: dispara geração de template (8.1), empacota arquivos em ZIP, faz download (FR20)
2. **AC2** — Estrutura do ZIP: `template/` (index.html, css/style.css, js/base.js, js/exemplo.js, assets/)
3. **AC3** — Se existirem datasets de teste, exibe checkbox "Incluir datasets de teste" (default desmarcado) — quando marcado adiciona `test_data/` ao ZIP
4. **AC4** — Botão "💾 Salvar" na toolbar: serializa estado completo do editor em JSON, faz download como arquivo (FR10)
5. **AC5** — JSON de save inclui: estrutura do documento (árvore), mapeamentos de campos, estado do editor (aba ativa, zoom, seleções), mas NÃO PDFs ou assets binários
6. **AC6** — Home → "Abrir Projeto" → file picker para .json → carrega JSON → popula todos os stores → navega para /editor
7. **AC7** — Projeto restaurado vai direto para o Editor (pula Upload e Analyzing)
8. **AC8** — Exportação bloqueada se validação pré-exportação (8.5) encontrar erros bloqueantes — exibe mensagem de erro
9. **AC9** — `npm run build` passa sem erros

## Dev Notes
- **FR20**: download como .zip via botão na toolbar, sem página separada de exportação
- **FR10**: salvar/carregar sessões como JSON
- Geração ZIP: endpoint backend POST /api/export retorna ZIP, ou usar JSZip no frontend
- Shape do JSON de save: `{ version, templateName, documentTree, fieldMappings, editorState, layoutTypes, confidence, coverage }`
- Load: `sessionStore.loadFromSavedProject(json)` → dispatches para todos os stores
- Composable `useExport`: gerencia fluxo de exportação (validar → gerar → empacotar → download)
- Checkbox de datasets: só exibido quando `testDataStore.datasets.length > 0`
- JSON salvo NÃO inclui: PDFs uploaded, screenshots de páginas, resultados intermediários do pipeline
- JSZip pode ser usado no frontend para montar o ZIP sem necessidade de endpoint backend separado
- Considerar usar Blob + URL.createObjectURL para download no browser
