# Story 18.2 — Handoff Consumption

## Story
**Como** operador que executa workflows multi-agente em yolo_continuous,
**Quero** que o engine injete o handoff artifact do agente anterior no prompt do proximo subagente automaticamente,
**Para** que cada agente comece com o contexto do trabalho anterior em vez de comecar do zero.

## Status
Draft

## Context

### Problema

O engine gera handoff artifacts em `.aios/handoffs/` (Story 16.8), mas o Subagent Prompt Builder **nao le** esses artifacts. Eles existem fisicamente mas nao sao consumidos programaticamente.

O agente seguinte recebe apenas os `requires` outputs (dados estruturados), mas nao o contexto qualitativo do handoff (decisoes, summaries, prior_steps).

### Exemplo Concreto

```
@qa (Classification) completa → gera handoff-qa-to-sm-20260329.yaml
  Conteudo: { classification: "regression_bug", strategy: "fast-track", suspects: [...] }

@sm (Create Branch) e spawnado → NAO recebe o handoff
  Recebe apenas: requires outputs (dados crus)
  Nao recebe: decisoes, summaries, contexto qualitativo
```

### Design

#### Nova template variable: `{{HANDOFF_DATA}}`

Adicionar ao `subagent-step-prompt.md`:

```markdown
{{#if HANDOFF_DATA}}
## HANDOFF DO AGENTE ANTERIOR

**De:** @{{HANDOFF_FROM_AGENT}} (step: {{HANDOFF_FROM_STEP}})
**Decisoes/contexto:**
{{HANDOFF_SUMMARY}}

{{#if HANDOFF_PRIOR_STEPS}}
**Steps anteriores do mesmo agente:**
{{HANDOFF_PRIOR_STEPS}}
{{/if}}
{{/if}}
```

#### Injecao no Subagent Prompt Builder

```
FUNCTION inject_handoff(step, state):
  # Procurar handoff mais recente para este agente
  latest_handoff = find_latest_handoff_for_step(step, state)

  IF latest_handoff is null:
    Set {{HANDOFF_DATA}} = ""
    RETURN

  Set {{HANDOFF_DATA}} = true
  Set {{HANDOFF_FROM_AGENT}} = latest_handoff.from_agent
  Set {{HANDOFF_FROM_STEP}} = latest_handoff.step_completed
  Set {{HANDOFF_SUMMARY}} = truncate(latest_handoff.outputs, max_chars=300)
  Set {{HANDOFF_PRIOR_STEPS}} = format_prior_steps(latest_handoff.prior_steps_same_agent)

FUNCTION find_latest_handoff_for_step(step, state):
  # Opcao 1: Ler do state.handoffs_generated (in-memory)
  FOR each handoff_filename in reverse(state.handoffs_generated):
    IF handoff_filename contains "-to-{step.agent}-":
      Read and parse handoff file
      RETURN parsed_handoff

  # Opcao 2: Scan .aios/handoffs/ (para recovery/continue)
  Scan .aios/handoffs/ for files matching "*-to-{step.agent}-*"
  RETURN most recent match or null
```

#### Token budget

Handoff data limitado a **max 300 tokens**:
- From/step info: ~20 tokens
- Summary: max 200 tokens
- Prior steps: max 80 tokens

### Interacao com requires

O handoff complementa (nao substitui) o `requires` chain:
- `requires`: dados estruturados (outputs exatos do step anterior)
- `handoff`: contexto qualitativo (decisoes, summaries, observacoes)

Ambos aparecem no prompt, em secoes separadas.
