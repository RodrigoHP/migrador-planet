# Story 29.6 — Canvas Context Menu (Clique Direito)

## Story
**Como** operador editando elementos diretamente no canvas visual,
**Quero** clicar com o botão direito sobre um elemento para ver um menu de ações rápidas,
**Para** executar operações como mapear campo, converter para tabela ou remover elemento sem precisar navegar para a árvore de estrutura.

## Status
Done

## Business Value
Operadores precisam navegar até a árvore para executar ações em elementos do canvas — mapeamento, remoção, conversão. Com o context menu, estas ações ficam disponíveis com um clique direito no próprio canvas, reduzindo friction e tornando o fluxo de mapeamento mais direto.

**Estimativa:** 2 story points

## Scope
**IN:**
- Handler `contextmenu` no canvas/overlay
- Componente `CanvasContextMenu.vue` com 4 opções: Mapear Campo, Converter para Tabela, Marcar como Texto Estático, Remover Elemento
- "Mapear Campo" abre FieldNavigator com nó pré-selecionado
- "Remover Elemento" e "Marcar como Texto Estático" com implementação real
- Fechar ao clicar fora ou pressionar Escape
- Testes de abertura/fechamento e ações

**OUT:**
- "Converter para Tabela" com implementação completa (apenas registra intenção no MVP — AC3 não requer conversão real)
- Context menu no PDF Reference panel
- Atalhos de teclado para as ações do menu
- Submenu ou ações aninhadas

## Risks

| Risco | Probabilidade | Impacto | Mitigação |
|-------|--------------|---------|-----------|
| Clique direito capturado pelo iframe em vez do overlay | Alta | Alto | Testar primeiro — se for o iframe, usar postMessage para repassar evento ao parent |
| Menu aparece fora da viewport (canto inferior/direito) | Média | Baixo | Ajustar posição com `getBoundingClientRect` para manter dentro da tela |
| Conflito com context menu nativo do browser em alguns elementos | Baixa | Baixo | `event.preventDefault()` no handler resolve |

## Context

**Problema (GAP 6):**

`HTMLCanvas.vue` não tem handler para `contextmenu`. O `StructureTree.vue` já tem um context menu completo (Add, Group, Duplicate, Remove, Move to) — este é o ponto de reuso.

A spec define o menu do canvas com foco em operações de mapeamento:
```
Right click menu:
  Map field
  Convert to table
  Mark as static text
  Remove element
```

**Ponto de atenção:** O canvas usa um `<iframe>` para renderizar o HTML. O clique direito pode ocorrer:
1. **Sobre o overlay** (`CanvasSelectionOverlay.vue`) — fora do iframe, mais fácil
2. **Dentro do iframe** — requer comunicação postMessage do iframe para o parent

Verificar qual cenário é o atual ao implementar.

- `frontend/src/organisms/CanvasSelectionOverlay.vue` — overlay sobre o canvas

## Dev Notes

### Captura do clique direito

**Cenário provável:** O overlay (`CanvasSelectionOverlay.vue`) está posicionado sobre o iframe com `pointer-events: all`. O clique direito deve ser capturado no overlay, não no iframe.

```vue
<!-- CanvasSelectionOverlay.vue ou HTMLCanvas.vue -->
<div
  class="canvas-overlay"
  @contextmenu.prevent="onContextMenu"
>
```

```typescript
const contextMenuState = reactive({
  visible: false,
  x: 0,
  y: 0,
  nodeId: null as string | null
})

function onContextMenu(event: MouseEvent) {
  event.preventDefault()

  // Identificar nó sob o cursor (reutilizar getNodeAtScreenPosition de 29.2)
  const node = getNodeAtScreenPosition(event.clientX, event.clientY)
  if (!node) return // AC5: área vazia, não abrir menu

  contextMenuState.visible = true
  contextMenuState.x = event.clientX
  contextMenuState.y = event.clientY
  contextMenuState.nodeId = node.id

  // Selecionar o nó ao abrir o menu
  editorStore.selectElement(node.id)
}

function closeContextMenu() {
  contextMenuState.visible = false
  contextMenuState.nodeId = null
}
```

### CanvasContextMenu.vue — componente simples

```vue
<template>
  <Teleport to="body">
    <div
      v-if="visible"
      class="canvas-context-menu"
      :style="{ top: `${y}px`, left: `${x}px` }"
      @click.stop
    >
      <button @click="emit('map-field')">🔗 Mapear Campo</button>
      <button @click="emit('convert-table')">📋 Converter para Tabela</button>
      <button @click="emit('mark-static')">🔤 Marcar como Texto Estático</button>
      <hr />
      <button class="canvas-context-menu__danger" @click="emit('remove')">🗑 Remover Elemento</button>
    </div>
  </Teleport>
</template>
```

### Implementação das ações

```typescript
// Map field (AC2)
function handleMapField() {
  if (!contextMenuState.nodeId) return
  editorStore.selectElement(contextMenuState.nodeId)
  editorStore.openPanel('fields') // Abrir aba Campos no LeftPanel
  closeContextMenu()
}

// Remove (AC3)
function handleRemove() {
  if (!contextMenuState.nodeId) return
  templateStore.removeNode(contextMenuState.nodeId)
  closeContextMenu()
}

// Mark static (AC4)
function handleMarkStatic() {
  if (!contextMenuState.nodeId) return
  templateStore.updateNodeProperty(contextMenuState.nodeId, 'type', 'static')
  // Remover binding se existir
  const node = templateStore.getNodeById(contextMenuState.nodeId)
  if (node?.binding) {
    mappingStore.unmapField(contextMenuState.nodeId)
  }
  closeContextMenu()
}
```

### Fechar ao clicar fora (AC6)

```typescript
onMounted(() => {
  document.addEventListener('click', closeContextMenu)
  document.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') closeContextMenu()
  })
})
onUnmounted(() => {
  document.removeEventListener('click', closeContextMenu)
})
```
