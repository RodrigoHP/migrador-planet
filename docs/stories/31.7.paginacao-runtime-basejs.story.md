# Story 31.7 — Funções de paginação runtime no base.js

## Story
**Como** operador usando o editor de templates,
**Quero** que o base.js exportado contenha as funções de paginação,
**Para** que tabelas longas quebrem corretamente entre páginas ao renderizar.

## Status
Done

## Acceptance Criteria

- [x] AC1: base.js exportado contém quebrarTabelaEntrePaginas()
- [x] AC2: base.js exportado contém criarNovaPagina()
- [x] AC3: base.js exportado contém reposicionarElementoFixo()
- [x] AC4: Funções são geradas por baseJsGenerators.ts

## Scope

**IN:**
- Injetar funções de paginação no JS do codeStore antes do export

**OUT:**
- Alterar geração do base.js no pipeline

## Tasks

- [x] Task 1: No useExport, injetar funções de baseJsGenerators no JS
- [x] Task 2: Evitar duplicação se funções já existem
- [x] Task 3: Testes

## Dev Notes
baseJsGenerators.ts já exporta:
- generateQuebraTabelaFn()
- generateCriarNovaPaginaFn()
- generateReposicionarElementoFixoFn()

No useExport, antes de colocar o JS no ZIP, verificar se essas funções
já existem no conteúdo e injetá-las se ausentes.
