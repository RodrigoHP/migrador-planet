# Story 14.3 — Text Alignment + Text Decoration (F3 + F9)

## Story

**Como** operador do editor de templates,
**Quero** controlar alinhamento, decoração e transformação de texto diretamente no inspector,
**Para** poder reproduzir fielmente a formatação do documento original (ex: valores numéricos alinhados à direita, títulos em uppercase bold, texto sublinhado) sem editar CSS manualmente.

## Status

Done

## Context

### Problema

O `ElementInspector.vue` já possui controles de tipografia (font-family, font-size, font-weight, color, line-height, letter-spacing), porém faltam propriedades essenciais para reproduzir a formatação dos documentos Planet Express:

1. **Text Alignment (F3 — CRITICO):** Não há controle de `text-align` nem `vertical-align`. Documentos financeiros exigem alinhamento preciso — valores monetários à direita ("4.978,54"), códigos centralizados ("237"), nomes à esquerda ("Beneficiário")
2. **Text Decoration (F9 — ALTO):** Não há controle de `text-decoration` (underline, line-through), `text-transform` (uppercase, capitalize) nem `font-style` (italic). Documentos usam uppercase para títulos ("RECIBO DO SACADO"), underline para ênfase, italic para instruções

### Estado Atual do Código

**`ElementInspector.vue`** — Seção "Tipografia" (lines 16-36):
- Campos existentes: font_family, font_size, font_weight, color, line_height, letter_spacing
- Missing: text_align, vertical_align, text_decoration, text_transform, font_style
- Usa `InspectorField` (read-only display) — novos controles precisam de inputs editáveis

**`templateStore.ts`:**
- `updateNode(nodeId, patch)` — atualiza propriedades do nó no documentTree
- `pushUndoSnapshot()` — snapshot antes de mutações
- Padrão existente: patch de propriedades → re-render canvas

**`editor.types.ts`:**
- Define types do editor, `TreeNode`, propriedades
- Novas propriedades CSS precisam ser adicionadas ao type system

### Exemplos de Documentos Planet Express

| Elemento | text-align | text-decoration | text-transform | font-style |
|----------|-----------|----------------|---------------|------------|
| "4.978,54" (Valor) | right | none | none | normal |
| "Beneficiário" (Label) | left | none | none | normal |
| "237" (Código Banco) | center | none | none | normal |
| "RECIBO DO SACADO" | center | none | uppercase | normal |
| "Instruções" | left | underline | none | bold italic |

## Acceptance Criteria

1. **AC1 — Text Align Horizontal:** Grupo de 4 botões toggle (left | center | right | justify) com ícones na seção "Tipografia" do ElementInspector. Ao clicar, atualiza `text-align` do nó selecionado e o canvas reflete imediatamente
2. **AC2 — Vertical Align:** Grupo de 3 botões toggle (top | middle | bottom) para `vertical-align`, visível quando o elemento selecionado é célula de tabela (`node.type === 'table-cell'` ou equivalente)
3. **AC3 — Text Decoration:** Botões toggle para underline (U̲), overline, line-through (S̶), com suporte a múltiplos valores simultâneos (ex: underline + line-through). Valor `none` quando nenhum está ativo
4. **AC4 — Text Transform:** Selector ou grupo de botões para uppercase | lowercase | capitalize | none (Aa icon)
5. **AC5 — Font Style:** Toggle button italic (I) complementando o font-weight (B) já existente. Ao ativar, `font-style: italic`; ao desativar, `font-style: normal`
6. **AC6 — Undo Integration:** Todas as mudanças de alinhamento/decoração participam do undo stack (`pushUndoSnapshot()` antes de aplicar)
7. **AC7 — Persistência no Store:** As propriedades são salvas no `templateStore.documentTree` via `updateNode()` e incluídas na geração de HTML/CSS
8. **AC8 — Testes:** Cobertura unitária para cada controle (toggle state, valores CSS gerados, undo) com >= 90% de branches nas novas adições

### Padrões Existentes a Seguir

**Inspector controls pattern:**
- Cada seção do inspector usa `<InspectorSection title="..." :collapsible="true">`
- Campos usam `<InspectorField>` para display read-only ou componentes editáveis (`InspectorInput`, `InspectorSelect`, `InspectorColorPicker`)
- O novo `InspectorButtonGroup` deve seguir o mesmo padrão visual (dark theme, compact, labels em português)

[Source: ElementInspector.vue, InspectorField.vue, InspectorSection.vue]

**Store update pattern (templateStore):**
```typescript
// Padrão para atualizar propriedade de nó:
templateStore.pushUndoSnapshot()
templateStore.updateNode(nodeId, { property_name: newValue })
```

[Source: templateStore.ts]

**Naming conventions:**
- Propriedades CSS usam snake_case no store: `font_family`, `font_size`, `font_weight`, `line_height`, `letter_spacing`
- Novas propriedades devem seguir: `text_align`, `vertical_align`, `text_decoration`, `text_transform`, `font_style`

[Source: ElementInspector.vue lines 17-26, templateStore.ts]
