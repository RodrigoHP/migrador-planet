# Story 7.4: InspectorPanel Editing

## Status
Draft

## Story
**As a** operador,
**I want** editar todas as propriedades no painel Inspector (posição, tamanho, tipografia, binding, configurações de página e seção),
**so that** eu possa ajustar cada aspecto do template com precisão.

## Acceptance Criteria
1. Level 1 (PageInspector): editável — dropdown tamanho de página (A4/Letter/Custom), radio orientação, inputs de margens (mm), inputs de altura header/footer (px), toggle grid + tamanho, lock de colunas (FR39)
2. Level 2 (SectionInspector): editável — input de altura, color picker de fundo, imagem de fundo, inputs de padding (4 lados), checkbox repetir por página, checkbox lock seção, dropdown de visibilidade
3. Level 3 (TableInspector): editável — dropdown data source (arrays do XSD), tabela de colunas (campo/largura/alinhamento editáveis), altura da linha, padding, checkboxes de paginação (quebra/repetir cabeçalho/mínimo de linhas), dropdown de âncora, checkbox manter junto, visibilidade, botões de camada, lock
4. Level 3 (ChartInspector): editável — dropdown tipo de gráfico (Barras/Linhas/Pizza/Rosca/Área/Empilhado), data binding (dropdown labels + datasets com campo/label/cor — populados a partir de arrays e campos numéricos do XSD via mappingStore), inputs de dimensões, toggles de estilo (legenda/grid/animação/labels dos eixos), âncora, manter junto, visibilidade
5. Level 3 (ImageInspector): editável — dimensões, escala, dropdown de alinhamento, botão substituir (file picker), botão download
6. Level 4 (ElementInspector): editável — inputs posição X/Y, inputs tamanho W/H, dropdown família de fonte, tamanho de fonte, peso, color picker, line height, espaçamento, dropdown tipo de campo, input/dropdown de binding, âncora, dropdown de visibilidade, botões de camada, lock
7. Todas as alterações de propriedades atualizam templateStore → Canvas re-renderiza em tempo real
8. Opções de tipo de campo: Texto, Número, Moeda (BRL), Data, CPF, CNPJ, Percentual, Telefone, Personalizado
9. Botão "Remover do template" em todos os níveis (exceto Page) — remove nó da tree
10. Inputs numéricos validados: valores ≥ 0, margens não excedem dimensão da página, largura mínima de coluna (10px), feedback visual imediato para valor inválido (borda vermelha + tooltip)
11. `npm run build` passa sem erros

## Dev Notes
- Cada campo editável mapeia para uma propriedade do nó no templateStore
- Moléculas reutilizáveis: InspectorField (label + input/dropdown/color-picker/checkbox), PositionControl (Label + X + Y), SizeControl (Label + W + H), AnchorSelector (dropdown Topo/Fluxo/Rodapé)
- FontWarning molecule: exibe quando fonte não-padrão detectada — nome da fonte + fallback + botão upload
- Todas as alterações são reativas: editar no inspector → templateStore atualiza → regeneração HTML → Canvas re-renderiza
- Seleção de tipo de campo gera função de formato apropriada em base.js (ex: Moeda → formatCurrency())
- Área de conteúdo auto-calculada: altura da página - header - footer - margens
- Stack: Vue 3 + TypeScript + Pinia + Tailwind CSS
