# Story 9.4: Auto Fix AI

## Status
Draft

## Story
**As a** operador,
**I want** clicar em "🔧 Auto Fix" na toolbar e ter a IA sugerindo correções para divergências detectadas, apresentadas individualmente para eu aceitar ou rejeitar,
**so that** eu possa melhorar rapidamente a qualidade do template.

## Acceptance Criteria
1. Botão "🔧 Auto Fix" na toolbar dispara análise de IA do estado atual do template (FR34)
2. Endpoint backend `POST /api/auto-fix` aceita estado do template, retorna lista de correções sugeridas (FR34)
3. Correções apresentadas uma a uma em modal/painel: descrição do problema, mudança proposta, preview antes/depois (FR34)
4. Operador pode: ✅ Aceitar (aplicar correção), ❌ Rejeitar (pular), ⏭️ Pular (decidir depois)
5. Tipos de correção: normalização de espaçamento, alinhamento de grid, consistência de fonte, bindings faltantes, ajuste de posição (FR34)
6. Após aplicar correções, confiança e cobertura recalculam automaticamente
7. IA usa Claude Sonnet via OpenRouter para análise e sugestões
8. Máximo 20 sugestões por execução (evitar sobrecarregar operador)
9. Limite de 3 execuções de Auto Fix por sessão (evitar custos excessivos de API); após atingir limite, botão desabilitado com tooltip "Limite de Auto Fix atingido nesta sessão"
10. Cada fix aceito cria snapshot no undo stack (Story 7.2); operador pode reverter via Ctrl+Z após aceitar
11. `npm run build` passa sem erros

## Dev Notes
- **FR34**: Auto Fix via toolbar, aceitar/rejeitar individual, recalcular métricas após
- Backend: envia estado do `templateStore` + análise do pipeline → Claude Sonnet analisa divergências → retorna sugestões de correção
- Shape da sugestão: `{ id, type, description, element_id, current_value, suggested_value, confidence }`
- Tipos de fix: `'spacing'` (normalizar gaps), `'alignment'` (snap ao grid), `'font'` (corresponder fonte detectada), `'binding'` (sugerir binding faltante), `'position'` (ajustar para corresponder ao PDF)
- Aplicar fix: atualiza propriedades do nó no `templateStore` → Canvas re-renderiza
- Após todos fixes aplicados/rejeitados: `confidenceStore.recalculate()`, `coverageStore.recalculate()`
- Claude Sonnet via OpenRouter para avaliação analítica
- Limite de 20 sugestões: evita sobrecarga cognitiva do operador
- Dependências: `templateStore`, `confidenceStore`, `coverageStore`, endpoint OpenRouter configurado
