# Epic 26 — Engine Resilience: yolo_continuous Production-Ready

## Epic Goal

Tornar o modo `yolo_continuous` do workflow engine confiável para produção, adicionando resiliência (auto-resume, heartbeat), execução background real, notificações, cost tracking preciso e métricas históricas.

## Contexto

O engine `yolo_continuous` funciona bem dentro de uma sessão Claude Code ativa, mas tem 6 gaps que impedem uso confiável:
- Workflows morrem silenciosamente quando a sessão cai
- Não há monitoramento de saúde do engine
- `run_in_background: true` nos workflows é decorativo
- Sem notificação ao completar em background
- Cost tracking usa heurística imprecisa
- Sem visibilidade histórica de execuções

## Escopo

### IN Scope
- Auto-resume de workflows via hooks do Claude Code
- Heartbeat/watchdog no state file
- Implementação real de `run_in_background` via Agent tool
- Notification file ao completar workflow
- Melhoria do cost tracking
- Métricas históricas agregadas

### OUT of Scope
- Notificações push externas (email, Slack)
- Dashboard visual/web
- Mudanças no core algorithm do Sequence Advancer
- Novos workflows

## Arquivos-Chave
- `.aios-core/development/tasks/run-workflow-engine.md` — engine principal
- `.aios/engine-config.yaml` — configuração
- `.aios-core/development/workflows/story-development-cycle.yaml` — SDC v2.0
- `.aios-core/development/workflows/rca-investigation.yaml` — RCA v8.1
- `.aios-core/data/workflow-state-schema.yaml` — schema do state

## Restrições
- Tudo é pseudocódigo interpretado pelo Claude Code — sem runtime separado
- Hooks do Claude Code são o mecanismo de automação persistente
- Manter compatibilidade com engine-config.yaml e workflows existentes
- Não quebrar SDC e RCA que já usam yolo_continuous

## Risk Assessment
- **Primary Risk:** Hook de auto-resume pode criar loops se state file estiver corrompido
- **Mitigation:** Max resume attempts (3) + validação de state antes de resume
- **Rollback:** Hooks podem ser desativados em settings.json sem afetar engine core

## Definition of Done
- [ ] Workflow yolo_continuous sobrevive a crash de sessão (auto-resume)
- [ ] Engine stale é detectado em < 2x timeout do step
- [ ] RCA workflow roda em background real enquanto user trabalha
- [ ] Completion status acessível via arquivo de notificação
- [ ] Cost estimates dentro de ±30% do real
- [ ] Histórico de execuções consultável em `.aios/engine-metrics.yaml`
