# Story 18.6 — Project Context Injection

## Story
**Como** operador que executa workflows yolo_continuous,
**Quero** que o engine injete automaticamente contexto do projeto (tech stack, patterns, arquitetura) no prompt de todo subagente,
**Para** que cada subagente comece sabendo o contexto do projeto em vez de gastar tempo redescoberta.

## Status
Draft

## Context

### Problema

Cada subagente e spawnado com o prompt do step + agent persona + task. Nenhum recebe contexto do projeto atual — tech stack, padroes de codigo, arquitetura.

O @dev e spawnado e gasta os primeiros ~30s lendo arquivos pra entender "ah, e Vue 3 + Vitest + TypeScript + Supabase". Isso acontece em cada step, de cada story, de cada workflow.

### Design

#### Project context file: `.aios/project-context.yaml`

Arquivo gerado/atualizado automaticamente (ou manualmente):

```yaml
project_context:
  name: migrador-planet
  description: "Plataforma de engenharia reversa de PDFs Planet Express → HTML templates"
  tech_stack:
    frontend: "Vue 3, TypeScript, Pinia, Vite, Vitest"
    backend: "FastAPI, Python, Supabase"
    infra: "Vercel (frontend), Railway (backend), Supabase (DB + Storage + Auth)"
    ai: "OpenRouter (Vision API)"
  patterns:
    frontend: "Composition API, Pinia stores, composables em src/composables/"
    backend: "FastAPI routers em backend/routers/, pipeline em backend/pipeline/"
    testing: "Vitest + @testing-library/vue, specs junto ao fonte"
  architecture:
    type: "SPA frontend + REST API backend"
    key_flows:
      - "Upload PDF → 5-stage pipeline → HTML template"
      - "SSE progress tracking via /api/v1/jobs/{id}/progress"
  conventions:
    commit: "Conventional commits (feat/fix/chore)"
    branch: "feature/{epic}-{description}"
    story_location: "docs/stories/"
  updated_at: "2026-03-30"
```

#### Injecao no prompt

Nova template variable `{{PROJECT_CONTEXT}}` no `subagent-step-prompt.md`:

```markdown
{{#if PROJECT_CONTEXT}}
## PROJECT CONTEXT
{{PROJECT_CONTEXT}}
{{/if}}
```

#### Geracao do context

3 opcoes (em ordem de preferencia):
1. **Manual:** Operador cria/atualiza `.aios/project-context.yaml`
2. **Auto-detect:** Engine gera baseado em package.json, tsconfig, requirements.txt, etc
3. **From CLAUDE.md:** Extrai do CLAUDE.md e regras do projeto

Para esta story, implementar opcao 1 (manual) + opcao 3 (CLAUDE.md fallback). Auto-detect e escopo de story futura.

#### Token budget

Project context limitado a **max 200 tokens**. O YAML e compacto por design.
