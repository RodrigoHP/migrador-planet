# Story 15.10 — Fix: .env.example sem variáveis Supabase do frontend

## Story

**Como** desenvolvedor novo no projeto,
**Quero** encontrar todas as variáveis de ambiente necessárias no `.env.example`,
**Para** conseguir rodar o frontend com autenticação sem precisar caçar as variáveis manualmente.

## Status

Done

## Context

Gap identificado no Epic 15 Gap Report (2026-03-28).

O frontend usa `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` para inicializar o cliente Supabase (`frontend/src/lib/supabase.ts`), mas essas variáveis não estão documentadas no `.env.example`. Novos devs não conseguem rodar o auth sem procurar as variáveis em outro lugar.

## Acceptance Criteria

1. `.env.example` contém entrada para `VITE_SUPABASE_URL` com valor placeholder e comentário explicativo
2. `.env.example` contém entrada para `VITE_SUPABASE_ANON_KEY` com valor placeholder e comentário explicativo
3. Comentário indica onde obter os valores (Supabase Dashboard → Project Settings → API)
4. Entradas agrupadas com as outras variáveis de frontend (prefixo `VITE_`)

## Scope

**IN:** Editar `.env.example` adicionando as 2 variáveis
**OUT:** Nenhuma mudança em código fonte

## Tasks / Subtasks

- [x] Localizar seção VITE_ no `.env.example`
- [x] Adicionar `VITE_SUPABASE_URL` com placeholder e comentário
- [x] Adicionar `VITE_SUPABASE_ANON_KEY` com placeholder e comentário
