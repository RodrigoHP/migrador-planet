# Story 19.7 — Getting Started Guide

## Story
**Como** desenvolvedor que encontra AIOS pela primeira vez,
**Quero** um guia passo-a-passo que cubra init, configuracao, primeiro workflow e primeiro yolo run com exemplos concretos,
**Para** que eu consiga usar o framework produtivamente em menos de 30 minutos.

## Status
Done

## Context

### Problema

Nao existe documentacao de onboarding para novos usuarios. O framework assume conhecimento previo de agents, workflows, engine, e convencoes. Um desenvolvedor novo precisa ler dezenas de arquivos para entender como comecar.

### Design

#### Estrutura do guia

1. **Pre-requisitos** — Claude Code instalado, projeto existente
2. **Quick Start (5 min)** — `aiox init`, verificar estrutura, rodar hello-world
3. **Configuracao (10 min)** — Ajustar engine-config.yaml, project-context.yaml
4. **Primeiro Workflow (10 min)** — Criar story, executar SDC, ver resultado
5. **Primeiro YOLO Run (5 min)** — Executar ciclo completo autonomo
6. **Troubleshooting** — Problemas comuns e solucoes

#### Exemplos por tech stack

Cada secao com exemplos paralelos:
- **Node.js/TypeScript** — React ou Vue project
- **Python** — FastAPI ou Django project

#### Formato

Markdown com code blocks executaveis, outputs esperados, e notas explicativas.
