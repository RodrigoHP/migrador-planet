# Story 22.3: Tech Debt: Garantir children: [] em nós folha do Stage 3

## Status
Draft

## Story
**As a** desenvolvedor backend,
**I want** que todos os nós folha criados pelo Stage 3 incluam `"children": []` explicitamente,
**so that** o contrato de `TreeNode` seja consistente na origem e não dependa de guards defensivos downstream para não quebrar.

## Contexto

Durante a investigação [rca-2026-03-31-editor-redirect-to-home](../qa/investigations/rca-2026-03-31-editor-redirect-to-home.md), identificou-se (Achado F-1) que o Stage 3 cria nós folha (`cell`, `image`, `chart`, `barcode`) sem a chave `children`.

O fix principal foi aplicado no Stage 5 (`_convert_tree_to_css_coords`) e em guards defensivos no frontend (`buildFlatMap`, `applyOptionalVisibility`, `applyTableCellFlags`). Porém, a **origem do contrato inconsistente permanece no Stage 3** — qualquer outro consumidor da árvore que não tenha o mesmo guard defensivo estará exposto ao mesmo bug.

**Linhas afetadas em `stage3_structural_analysis.py`:**
- Linha ~1316: `{"type": "cell", "text": h}` — célula de header sem `children`
- Linha ~1321: `{"type": "cell", "text": str(c)}` — célula de data row sem `children`
- Linha ~1327: `{"type": "image", ...}` — nó image sem `children`
- Linha ~1337: `{"type": "chart", ...}` — nó chart sem `children`
- Linha ~1348: `{"type": "barcode", ...}` — nó barcode sem `children`

## Acceptance Criteria

1. **AC-1:** Todos os dicionários de nós folha criados no Stage 3 incluem `"children": []` explícito — tipos afetados: `cell`, `image`, `chart`, `barcode`
2. **AC-2:** Novo teste de contrato em `test_stage3_structural_analysis.py` valida que **todo nó** retornado pela árvore do Stage 3 possui a chave `children` (recursivo)
3. **AC-3:** O novo teste falha sem o fix aplicado (prova de regressão)
4. **AC-4:** Todos os testes existentes do Stage 3 continuam passando após a mudança
5. **AC-5:** Todos os testes do Stage 5 (`test_stage5_template_generation.py`) continuam passando (nenhuma regressão cross-stage)

## Scope

**IN:**
- `backend/services/stages/stage3_structural_analysis.py` — adicionar `"children": []` nos 5 locais identificados
- `backend/tests/test_stage3_structural_analysis.py` — adicionar `TestTreeNodeChildrenContract` com teste recursivo de contrato

**OUT:**
- Não alterar Stage 5 (`stage5_template_generation.py`) — o fix defensivo lá permanece como defense-in-depth
- Não alterar frontend (`templateStore.ts`, `session.ts`) — guards `?? []` permanecem
- Não alterar outros stages
- Não alterar o schema de `TreeNode` nem tipos TypeScript

**Teste de contrato a adicionar:**

```python
class TestTreeNodeChildrenContract:
    """Valida que todo nó da árvore do Stage 3 possui a chave 'children'."""

    def _assert_all_nodes_have_children(self, node, path="root"):
        assert "children" in node, f"Nó sem 'children' em {path}: {node}"
        for i, child in enumerate(node["children"]):
            self._assert_all_nodes_have_children(child, f"{path}.children[{i}]")

    def test_all_leaf_nodes_have_children_key(self, stage3_result_fixture):
        """Todo nó da árvore deve ter a chave children — incluindo folhas."""
        tree = stage3_result_fixture["document_structure"]
```
