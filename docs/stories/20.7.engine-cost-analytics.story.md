# Story 20.7 — Historical Cost Analytics

## Story
**Como** operador que quer otimizar custos ao longo do tempo,
**Quero** que o *workflow-analytics inclua secao de custo real com tendencias, medias por tipo, agent mais caro, e custo por retry,
**Para** que eu identifique padroes de gasto e oportunidades de economia.

## Status
Draft

## Context

### Problema

O cost report (20.4) mostra custo de uma unica execucao. Para otimizacao, o operador precisa de visao historica — tendencias entre runs, quais tipos de story custam mais, qual agent consome mais budget, e quanto do custo vem de retries vs execucao direta.

### Design

#### Nova Secao no workflow-analytics: Cost Analytics


Os dados vem dos state files salvos em `.aios/workflow-runs/` (ja existente). Cada state file contem cost_tracking (20.3). O analytics le os ultimos N state files e agrega.
