# Story 42.7 — Pydantic Contract Tightening (extra="forbid" + mypy zero)

## Status: Draft

## Descricao

Fechar o contrato Pydantic: trocar `extra="allow"` por `extra="forbid"` em todos os 16 modelos de `pipeline_context.py`, declarar `response_model` no endpoint de resultado, e atingir zero erros mypy. Esta é a story que transforma os modelos de "documentação tipada" em "contratos enforçados".

## Dev Notes

### Processo de migração `extra="allow"` → `extra="forbid"`

```python
# Antes
class EnrichedPage(BaseModel):
    model_config = ConfigDict(extra="allow")

# Depois — só após todos os construction sites auditados
class EnrichedPage(BaseModel):
    model_config = ConfigDict(extra="forbid")
```

**Estratégia:** trocar 1 modelo por vez, rodar `pytest` após cada troca. Se `ValidationError` → identificar qual stage passa o campo extra → adicionar campo ao modelo → prosseguir.
