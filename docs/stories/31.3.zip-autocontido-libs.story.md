# Story 31.3 — Tornar ZIP autocontido — libs via CDN com fallback

## Story
**Como** operador usando o editor de templates,
**Quero** que o index.html do ZIP referencie libs via CDN com fallback local,
**Para** que o template funcione tanto online (CDN) quanto offline (libs locais).

## Status
Done

## Acceptance Criteria

- [ ] AC1: index.html referencia KO via CDN (cdnjs) com fallback para js/libs/knockout.min.js
- [ ] AC2: Chart.js e chartjs-plugin-datalabels via CDN com fallback quando charts existem
- [ ] AC3: JsBarcode via CDN com fallback quando barcodes existem
- [ ] AC4: Referências antigas a ../Bibliotecas/ são substituídas

## Scope

**IN:**
- Reescrever referências de script no HTML do ZIP
- Adicionar fallback script tags

**OUT:**
- Bundlar arquivos .js reais no ZIP (demasiado grande)

## Tasks

- [ ] Task 1: Criar helper para gerar script tags CDN com fallback
- [ ] Task 2: No useExport, reescrever HTML antes de incluir no ZIP
- [ ] Task 3: Testes unitários

## Dev Notes
Estratégia: CDN como primário, sem fallback local físico (seria 500KB+ no ZIP).
Reescrever as referências ../Bibliotecas/js/knockout-3.4.2.js para CDN.

CDNs:
- KO: https://cdnjs.cloudflare.com/ajax/libs/knockout/3.4.2/knockout-min.js
- Chart.js: https://cdn.jsdelivr.net/npm/chart.js@4/dist/chart.umd.min.js
- chartjs-plugin-datalabels: https://cdn.jsdelivr.net/npm/chartjs-plugin-datalabels@2
- JsBarcode: https://cdn.jsdelivr.net/npm/jsbarcode@3/dist/JsBarcode.all.min.js
