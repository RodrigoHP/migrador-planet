# Story 5.2: HomePage v3 — Cards Novo Template e Abrir Projeto com Bibliotecas

## Status
Draft

## Story
**As a** operador da ferramenta,
**I want** que a Home exiba dois cards (Novo Template + Abrir Projeto) com descrições e um botão Bibliotecas,
**so that** eu possa iniciar uma nova migração ou retomar um projeto salvo de forma intuitiva.

## Acceptance Criteria
1. HomePage exibe dois cards: "➕ Novo Template" com texto "Iniciar migração de um novo documento PDF" e botão "Começar →", "📂 Abrir Projeto" com texto "Retomar projeto salvo (.json)" e botão "Carregar arquivo"
2. Header tem botão "📚 Bibliotecas" que abre BibliotecasModal
3. "Começar →" navega para /upload
4. "Carregar arquivo" abre file picker para .json, carrega estado do projeto e navega para /editor
5. Cards estilizados com border, border-radius, padding, gap — interface utilitária
6. `npm run build` passa

## 🤖 CodeRabbit Integration
> **CodeRabbit Integration**: Disabled
> CodeRabbit CLI is not enabled em `core-config.yaml`.
> Quality validation via manual review + QA gate.
