# Table Pagination Rules

Tables are the most common dynamic element.

They may contain from a few rows to hundreds.

## Rules

1. Rows cannot break in the middle.
2. When a page overflow occurs:
   - Move entire row to next page.
3. Table headers repeat on every new page.

## Example

Page 1
Header
Row1
Row2

Page 2
Header
Row3
Row4

## Benefits

- Professional report behavior
- Predictable layout
- Financial document compatibility
