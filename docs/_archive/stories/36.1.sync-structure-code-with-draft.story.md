## Story

As a template operator, I want changes made in the Structure tree to update the Monaco HTML even when the backend provided a templateDraft.html, so that bidirectional sync works in all scenarios.

## Acceptance Criteria

- [x] Remove guard `if (generationStore.templateDraft?.html) return` in the documentTree watch
- [x] Implement selective merge: tree changes patch HTML by data-node-id instead of full regeneration
- [x] Guard `_isSyncing` prevents infinite loop
- [x] Test: edit node name in tree -> HTML in Monaco updates -> Canvas re-renders

## Tasks

- [ ] Modify documentTree watch in codeStore.ts to remove early return
- [ ] Implement patchHtmlFromTree function for selective merge
- [ ] Add _isSyncing guard to prevent code->tree->code loop
- [ ] Add unit tests

## Scope

**IN:** codeStore.ts documentTree watch, selective HTML patching
**OUT:** Backend changes, CSS sync, full HTML regeneration
