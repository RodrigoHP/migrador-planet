# Story 9.3: SyncView

## Status
Done

## Story
**As a** operador,
**I want** uma aba Sync View mostrando Canvas (template) e PDF (original) lado a lado com scroll e seleção sincronizados,
**so that** eu possa comparar o template gerado com o documento original em tempo real.

## Acceptance Criteria
1. Aba "🔗 Sincronizar" no painel central mostra visão dividida: Canvas (esquerda) + PDF (direita) (FR28)
2. Scroll sincronizado: rolar um painel rola o outro automaticamente (FR28)
3. Seleção sincronizada: clicar em elemento no Canvas destaca o bounding box correspondente no PDF (FR28)
4. Âncoras de layout: pontos de referência (títulos, cabeçalhos de tabela, logos) mostrados como marcadores conectando ambos os painéis (FR28)
5. Integra com Coverage Mode: quando ativo, Canvas mostra overlays mapeados/não mapeados, PDF mostra overlays de detecção (FR28)
6. Usa página representativa do Layout Type ativo
7. Zoom independente por painel: cada um tem controles próprios [- 100% +] (FR28)
8. `npm run build` passa sem erros

## Dev Notes
- **FR28**: visão dividida, scroll sincronizado, seleção sincronizada, âncoras, integração com coverage, zoom independente
- **SyncView** organismo (alta complexidade): combina HTMLCanvas + PDFReference em layout split
- **useSync** composable: gerencia scroll sync (mapeia posição de scroll do Canvas para PDF baseado no alinhamento de conteúdo), selection sync (clique no elemento do Canvas → encontra bounding box correspondente no PDF)
- Âncoras: do resultado do pipeline — pontos de referência detectados com coordenadas tanto no Canvas quanto no PDF
- Coverage overlay: reutiliza `CoverageOverlay` da story 6.8 em ambos os painéis
- Layout split: CSS flexbox com split 50/50 e divisor redimensionável
- Desafio de scroll sync: páginas do Canvas podem ter alturas diferentes das páginas do PDF — necessário mapeamento proporcional
- Dependências: `HTMLCanvas` (story 6.5), `PDFReference` (story 6.6), `CoverageOverlay` (story 6.8)
