# Story 34.6 — Busca/filtro no FieldNavigator

- **ID:** 34.6
- **Title:** Busca/filtro no FieldNavigator
- **Type:** feature
- **Status:** Ready
- **Priority:** P2
- **Epic:** 34
- **Complexity:** M

## Story

As a template operator, I want to search/filter fields by name in the FieldNavigator, so that I can quickly find a specific field.

## Acceptance Criteria

- [x] Input de texto no topo do FieldNavigator
- [x] Filtra `fieldNavItems` por nome (case-insensitive, substring match)
- [x] Resultado atualiza em tempo real (debounce 200ms)
- [x] Limpar filtro com botao X ou Escape
- [x] Quando filtro ativo, todos os grupos expandidos

## Tasks

- [x] Add search input to FieldNavigator template
- [x] Add `searchQuery` ref and debounced `debouncedQuery` computed
- [x] Filter fields/xsdOnlyFields based on search query
- [x] Expand all groups when filter is active
- [x] Add clear button and Escape handler
- [x] Update tests

## Scope

**IN:** Search input, filtering logic, auto-expand on filter
**OUT:** Advanced regex search, fuzzy matching

## Dev Notes

- Use simple setTimeout-based debounce (no external dep needed)
- Filter both regular fields and XSD-only fields
