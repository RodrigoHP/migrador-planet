## Story

Como operador do editor de templates,
quero editar a flag "Manter Junto" (keepTogether) nas tabelas via checkbox no Inspector,
para que blocos que devem ficar juntos movam para a próxima página quando não cabem.

## Acceptance Criteria

- [x] Campo "Manter Junto" é checkbox editável (não read-only)
- [x] Valor persiste em `node.properties.keepTogether`
- [x] `calculatePageBreaks()` em `usePagination.ts` honra flag keepTogether
- [x] Bloco com keepTogether=true move inteiro para próxima página quando não cabe

## Tasks

- [x] Substituir InspectorField read-only por InspectorCheckbox
- [x] Adicionar keepTogether ao LayoutElement interface
- [x] Atualizar calculatePageBreaks para honrar keepTogether

## Scope

**IN:** Checkbox UI, keepTogether in pagination
**OUT:** Multi-row keepTogether spanning (future)

- LayoutElement interface extended with optional keepTogether flag
- calculatePageBreaks already had the page break logic; keepTogether reuses the same path
