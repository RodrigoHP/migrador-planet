# Story 23.13 — Anti-Pattern Recurrence: Auto-Incremento

## Story
**Como** sistema de anti-pattern tracking,
**Quero** que recurrence seja incrementado automaticamente,
**Para** que a frequencia real de anti-patterns seja rastreada sem intervencao manual.

## Status
Done

## Context

### Problema
AP-001 tem `Recurrence: 4` mas ninguem sabe quem incrementou — eh manual. Quando audit-patterns encontra instancia ou nova investigacao referencia AP existente, o contador nao eh atualizado automaticamente.

### Design
Adicionar instrucoes em 2 pontos:

**Ponto 1 — Fase 8 do investigate.md, ao registrar anti-pattern:**
```
SE anti-pattern JA EXISTE no registry (mesmo AP-ID):
  1. Abrir docs/qa/known-anti-patterns.md
  2. Encontrar AP-{ID}
  3. Incrementar Recurrence += 1
  4. Adicionar referencia ao RCA atual em "Encontrado em"
  5. Log: "AP-{ID} recurrence atualizado: {old} → {new}"
  
SE anti-pattern eh NOVO:
  1. Criar nova entrada com Recurrence: 1
  2. Verificar se algum AP existente eh supersedido (mesma familia)
```

**Ponto 2 — audit-patterns, ao detectar instancias no codebase:**
```
Para cada match encontrado por search_pattern:
  SE match ja estava contabilizado: ignorar
  SE match eh novo (nao estava em audit anterior):
    Incrementar Recurrence += 1
    Adicionar nota com data e localizacao
```

## Acceptance Criteria
- [ ] Fase 8: auto-incremento quando AP existente referenciado
- [ ] audit-patterns: auto-incremento quando nova instancia detectada
- [ ] Log explicito de incremento (old → new)
- [ ] Nao duplicar contagem (mesmo match nao conta 2x)
