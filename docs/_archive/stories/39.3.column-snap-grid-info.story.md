## Descrição

O backend já extrai `column_positions` via Stage 2 (`_jenks_1d` em `stage2_deep_extraction.py`) e Stage 3 propaga para sections. O contract 3.2 inclui `grid_info.column_positions` como array de floats. O frontend já tem a infraestrutura visual pronta (`CanvasGuides.vue` renderiza guias de coluna, `HTMLCanvas.vue` passa `:column-positions` como prop). Porém, `HTMLCanvas.vue:277` está hardcoded `const columnPositions: number[] = []`.

**O gap é puro wiring:** ler `grid_info.column_positions` do pipeline data e alimentar o Canvas + snap engine.

## Decisões Arquiteturais (@architect — 2026-04-09)

### Q1: Onde vive o dado no frontend?

**Decisão: Opção B — `LayoutType.gridInfo`**

- `grid_info` é metadado por layout type, não por página individual
- `LayoutType` já agrega `documentTree`, `confidence`, `coverage` — padrão consistente
- `session.ts` no `loadPipelineResult()` já parseia `layout_types` — mapear `grid_info` ali
- `HTMLCanvas.vue` acessa `layoutStore.activeLayout` — wiring direto

```typescript
// pipeline.types.ts
export interface GridInfo {
  columns: number
  rows: number
  columnPositions: number[]
  rowPositions: number[]
}

export interface LayoutType {
  // ... existente
  gridInfo?: GridInfo
}
```

### Q2: Conversão de coordenadas

**Decisão: Converter no frontend — `pt * (96/72)`**

- Backend extrai em pontos PDF (72 dpi)
- Canvas renderiza HTML em pixels CSS (96 dpi)
- Fator: `PDF_TO_CSS_SCALE = 96 / 72 = 1.333...`
- Zoom já é aplicado pelo CSS `transform: scale()` do container — sem multiplicação extra

```typescript
// HTMLCanvas.vue
const PDF_TO_CSS_SCALE = 96 / 72
const columnPositions = computed(() => {
  const raw = layoutStore.activeLayout?.gridInfo?.columnPositions ?? []
  return raw.map(pt => Math.round(pt * PDF_TO_CSS_SCALE))
})
```

### Snap Integration

Column positions como snap targets verticais em `calcSnapLines()`:
- Snap left edge do elemento à coluna
- Snap right edge do elemento à coluna
- Usar `SNAP_THRESHOLD` existente (sem novo threshold)
- `columnPositions` acessado via parâmetro ou store dentro do composable
