### Como Mockar Serviços LLM

**GPT-4o Vision (Stage 3 — Visual Analysis):**
- Mockar `openai.ChatCompletion.acreate()` (ou equivalente openrouter)
- Retornar JSON fixo com `html_suggestion`, `visual_regions`, `consistency_score`
- Fixture: `backend/tests/fixtures/mock_gpt4o_vision_response.json`
- Exemplo de mock:
  ```python
  @pytest.fixture
  def mock_gpt4o_vision(monkeypatch):
      async def fake_vision(*args, **kwargs):
          return {"regions": [...], "html_suggestion": "<div>...</div>"}
      monkeypatch.setattr("services.stage3.visual_analysis.call_vision", fake_vision)
  ```

**Gemini Flash Batch (Stage 4 — Field Mapping):**
- Mockar a função de batch LLM call que envia N campos de uma vez
- Retornar mapeamentos pré-definidos (campo → XSD path → confidence)
- Fixture: `backend/tests/fixtures/mock_gemini_batch_response.json`
- Exemplo de mock:
  ```python
  @pytest.fixture
  def mock_gemini_batch(monkeypatch):
      async def fake_batch(*args, **kwargs):
          return [{"field": "nome", "xsd_path": "/sacado/nome", "confidence": 0.98}, ...]
      monkeypatch.setattr("services.stage4.batch_llm.call_batch", fake_batch)
  ```

**Dica:** Para testes de accuracy (Task 6), usar mocks que retornem resultados realistas baseados no ground truth do boleto Bradesco.
