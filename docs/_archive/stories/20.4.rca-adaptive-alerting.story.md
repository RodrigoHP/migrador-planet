# Story 20.4 — Alertas Adaptativos por Recurrence

## Story
**Como** time de qualidade,
**Quero** que alertas proativos sejam disparados baseados em recurrence de anti-patterns (nao apenas contagem de RCAs formais),
**Para** detectar padroes recorrentes mais cedo, especialmente em projetos com pouco historico.

## Status
Draft

## Context

### Problema
A Fase 9 (Meta-Learning) exige 3+ RCAs formais para gerar alertas de padrao recorrente. Mas um anti-pattern pode ter recurrence=4 (4 incidentes previos) com apenas 1 RCA formal. O threshold rigido ignora essa informacao.

### Design
- Fase 9 verifica campo `recurrence` dos anti-patterns alem do count de RCAs
- Threshold adaptativo: alerta se recurrence >= 3 OU RCA count >= 2 para mesmo tag/area
- Para projetos novos (0-2 RCAs), threshold mais baixo

## Acceptance Criteria
- [ ] Fase 9 verifica `recurrence` de anti-patterns alem do count de RCAs
- [ ] Threshold adaptativo: alerta se recurrence >= 3 OU RCA count >= 2 para mesmo tag/area
- [ ] Alerta inclui: anti-pattern ID, recurrence count, sugestao de `*audit-patterns`
- [ ] Para projetos novos (0-2 RCAs), threshold mais baixo para nao ignorar padroes
- [ ] Documentacao atualizada no investigate.md (Fase 9)

## Scope
**IN:** investigate.md (Fase 9), rca-investigation.yaml (step meta_learning)
**OUT:** Notificacoes externas (Slack, email)
