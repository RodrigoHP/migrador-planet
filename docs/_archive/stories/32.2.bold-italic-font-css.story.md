# Story 32.2 — Incluir is_bold/is_italic nas classes de fonte CSS

## Story
**Como** operador usando o editor de templates,
**Quero** que fontes bold e italic sejam refletidas nas classes CSS geradas,
**Para** que titulos e enfases no PDF aparecam corretamente no template HTML.

## Status
Done

## Acceptance Criteria

- [x] AC1: Classes `.f-{font}` incluem `font-weight: bold` quando is_bold=True
- [x] AC2: Classes `.f-{font}` incluem `font-style: italic` quando is_italic=True
- [x] AC3: Fontes com combinacao bold+italic geram classe distinta
- [x] AC4: Testes existentes continuam passando
- [x] AC5: Novos testes verificam presenca de font-weight/font-style no CSS

## Scope

**IN:**
- Modificar `_step_5_2_css_from_extraction` para incluir bold/italic
- Agrupar por font+bold+italic para classes distintas
- Novos testes

**OUT:**
- Alteracoes no frontend
- Suporte a font-weight numerico

## Tasks

- [x] Task 1: Modificar coleta de fontes para incluir is_bold/is_italic
- [x] Task 2: Gerar classes com font-weight/font-style
- [x] Task 3: Escrever testes

## Dev Notes
Agrupar por tupla (font_name, is_bold, is_italic). A classe CSS fica a mesma (.f-{font})
mas com regras adicionais. Para combinacoes diferentes, sufixar com -b, -i, -bi.
