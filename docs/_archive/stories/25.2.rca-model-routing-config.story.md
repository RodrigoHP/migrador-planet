# Story 25.2 — Model Routing Config: Tabela Configuravel

## Story
**Como** usuario configurando o RCA,
**Quero** escolher qual modelo usar por fase via presets,
**Para** balancear custo vs qualidade conforme meu budget.

## Status
Draft

## Context

### Problema
Hoje nao ha configuracao — tudo roda em Opus. Projetos com budget limitado pagam Opus para ler git log. Projetos que querem qualidade maxima nao tem como forcar Opus em todas as fases.

### Design
Adicionar ao workflow YAML:
- `model_routing` com modelo por fase e reason
- `presets`: economy, balanced (default), quality, single (v7.0 legacy)
- Parametro `--preset` no `/investigate`

4 presets:
- **economy:** Haiku onde possivel, Sonnet para analise, Opus so em Fase 4
- **balanced:** Sonnet base, Opus em Fases 4, 6, 8 (default)
- **quality:** Opus em tudo exceto leitura mecanica
- **single:** Zero subagents, comportamento v7.0 exato

## Acceptance Criteria
- [ ] model_routing no workflow YAML com modelo + reason por fase
- [ ] 4 presets definidos (economy, balanced, quality, single)
- [ ] investigate.md aceita --preset como parametro
- [ ] Default: balanced
- [ ] single: fallback para v7.0 sem subagents

## Scope
**IN:** rca-investigation.yaml, investigate.md (parametro)
**OUT:** UI de configuracao
