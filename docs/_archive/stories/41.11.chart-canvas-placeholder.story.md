# Story 41.11: Chart Canvas Placeholder — WYSIWYG de layout para gráficos

## Status
Done

## Story
**As a** operador,
**I want** que áreas de gráfico no Canvas do editor exibam um placeholder visual identificado com o tipo de gráfico,
**so that** eu possa verificar o posicionamento e dimensões dos gráficos sem ver `<canvas>` em branco.

## Context

### Problema

O Canvas iframe não carrega Chart.js — elementos `<canvas>` de gráficos aparecem como **áreas em branco** no editor. O operador não consegue verificar se o gráfico está posicionado corretamente.

### Decisão arquitetural (@architect Aria, 2026-04-09)

Chart.js **não será injetado** no iframe (204KB + 13KB = 217KB por iframe; sem dados reais em contexto de edição → gráfico vazio seria enganoso). A solução correta é um **placeholder CSS** que:
- Preserva posição e dimensões exatas do gráfico
- Identifica o tipo de gráfico visualmente
- Não engana o operador com chart vazio

### Solução

Em `buildPageSrcdoc()` (`useCanvasIframe.ts`), pós-processar o HTML antes de montar o srcdoc:
- Detectar `<canvas>` com atributo de identificação de chart
- Substituir por `<div class="chart-placeholder" data-chart-type="{type}">` com mesmos atributos de estilo
- Injetar CSS de placeholder no `<style>` do srcdoc

## Dev Notes

### Função pura de substituição

```typescript
// useCanvasIframe.ts
import { useTemplateStore } from '@/stores/templateStore'

function replaceChartsWithPlaceholders(html: string, chartNodeIds: Map<string, string>): string {
  // chartNodeIds: Map<nodeId, chartType>
  let result = html
  for (const [nodeId, chartType] of chartNodeIds) {
    // Substituir <canvas id="nodeId" style="..."> por <div placeholder>
    const canvasRegex = new RegExp(
      `<canvas([^>]*id=["']${nodeId}["'][^>]*)>\\s*</canvas>`,
      'gi'
    )
    result = result.replace(canvasRegex, (_, attrs) => {
      return `<div class="chart-placeholder" data-chart-type="${chartType}"${attrs}></div>`
    })
  }
  return result
}
```

### CSS do placeholder (injetado no srcdoc)

```css
.chart-placeholder {
  display: flex;
  align-items: center;
  justify-content: center;
  background: #f0f4ff;
  border: 1px dashed #c7d2fe;
  box-sizing: border-box;
  overflow: hidden;
}
.chart-placeholder::after {
  content: '📊 ' attr(data-chart-type);
  color: #6b7280;
  font-size: 11px;
  font-family: sans-serif;
  pointer-events: none;
}
```

### Integração em buildPageSrcdoc

```typescript
function buildPageSrcdoc(html: string, css: string): string {
  const templateStore = useTemplateStore()
  const chartNodeIds = new Map(
    templateStore.getNodesByType('chart')
      .filter(n => n.visibility !== false)
      .map(n => [n.id, (n.properties['chartType'] as string) || 'chart'])
  )

  const processedHtml = chartNodeIds.size > 0
    ? replaceChartsWithPlaceholders(html, chartNodeIds)
    : html

  const placeholderCss = chartNodeIds.size > 0 ? CHART_PLACEHOLDER_CSS : ''

  return `<!DOCTYPE html><html>
<head>
<meta charset="utf-8">
<style>
* { box-sizing: border-box; margin: 0; padding: 0; }
body { overflow: hidden; }
${css}
${placeholderCss}
</style>
</head>
<body>${processedHtml}
${CANVAS_INTERACTION_SCRIPT}
</body>
</html>`
}
```
