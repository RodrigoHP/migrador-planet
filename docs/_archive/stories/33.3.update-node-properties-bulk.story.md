## Story

Como operador do editor de templates,
quero que edições em múltiplas propriedades via Inspector reflitam imediatamente no Canvas,
para que eu veja o resultado visual de todas as mudanças bulk.

## Acceptance Criteria

- [x] `updateNodeProperties()` (bulk) chama patch correspondente para cada propriedade alterada
- [x] `mutationVersion` incrementado após bulk update
- [x] Canvas re-renderiza após edição bulk via Inspector
- [x] Teste: editar múltiplas propriedades no Inspector → todas refletem no Canvas

## Tasks
