# Story 23.8 — Escalation Assessment: Avaliacao Obrigatoria

## Story
**Como** investigador na Fase 5,
**Quero** que a avaliacao de escalacao seja obrigatoria e nao skipavel,
**Para** que problemas estruturais sejam identificados consistentemente.

## Status
Done

## Context

### Problema
RCA stage5 atinge 4/4 criterios de escalacao mas ninguem avaliou. A avaliacao eh opcional na pratica — o agente simplesmente nao a faz. Criterios codificados existem mas nao sao avaliados em nenhum relatorio.

### Design
Na Fase 5, APOS barrier analysis, adicionar step OBRIGATORIO:

```
## Escalation Assessment (OBRIGATORIO)

Avaliar os 4 criterios. Para cada um, responder YES/NO com evidencia:

| # | Criterio | Resposta | Evidencia |
|---|----------|----------|-----------|
| 1 | Bug afeta 3+ modulos/stages | YES/NO | "{listar modulos}" |
| 2 | Root cause eh design pattern incorreto | YES/NO | "{qual pattern}" |
| 3 | Fix requer mudanca de interface entre componentes | YES/NO | "{qual interface}" |
| 4 | Barrier analysis mostra falha em 4+ camadas | YES/NO | "{contar camadas}" |

**Resultado:** {N}/4 criterios atingidos
**Acao:** 
- 0 criterios: continuar normalmente
- 1+ criterios: GERAR escalation prompt (mesmo em modo YOLO)

Escalation prompt:
> ⚠️ ESCALATION RECOMMENDED
> Criterio(s): {lista}
> Evidencia: {resumo}
> Acao sugerida: escalar para @architect para review de design
```

## Acceptance Criteria
- [ ] Fase 5 tem step obrigatorio de escalation assessment
- [ ] Template com 4 criterios, resposta YES/NO, e evidencia
- [ ] Output mostra contagem de criterios atingidos
- [ ] 1+ criterios = gerar prompt (nao skip)
- [ ] Em modo YOLO: logar mas nao skipar
- [ ] Workflow YAML marcado como mandatory step

## Scope
**IN:** Fase 5 do investigate.md, workflow YAML
**OUT:** Resposta do @architect
