## Dev Notes

- **Focus trap**: Implemented a custom `useFocusTrap` composable instead of using `@vueuse/integrations/useFocusTrap` because the latter requires `@vueuse/integrations` + `focus-trap` packages not installed. The custom implementation is lightweight (~70 lines), zero extra deps, handles Tab wrapping, Shift+Tab, and focus restoration on deactivation.
- **Dirty tracking**: Uses `templateStore.mutationVersion` as the dirty signal. When mutation version diverges from the initial value captured at mount, the global dirty flag activates both `beforeunload` and the router guard.
- **Error handler**: The `app.config.errorHandler` catches errors that escape the ErrorBoundary (e.g., from async operations outside component lifecycle). It dispatches to the toast store for user-visible feedback.
- **Contrast fix**: Changed the CSS variable `--color-neutral-500` from `#737373` (4.48:1 ratio) to `#525252` (7.14:1 ratio on white), exceeding WCAG AA 4.5:1 requirement. All fallback values in 37 files updated.
