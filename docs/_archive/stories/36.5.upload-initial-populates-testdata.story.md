# Story 36.5 — Dados do upload inicial populam testDataStore

- **ID:** 36.5
- **Title:** Dados do upload inicial populam testDataStore
- **Type:** feature
- **Status:** Done
- **Priority:** P2
- **Epic:** 36
- **Complexity:** S

## Story

As a template operator, I want the data file uploaded during the initial analysis to automatically populate the Test Data store, so that I don't need to re-import the same data in the Test Data tab.

## Acceptance Criteria

- [x] In `loadFromPipelineResult()`, if `result.example_data` or `sessionStore.dataFile` exists, calls `testDataStore.addDataset()` automatically
- [x] Dataset added with name "Upload inicial" and status "unvalidated"
- [x] Operator does not need to re-import data in the Test Data tab
- [x] If no data in upload, testDataStore remains empty (no error)
