# 33.5 — Re-render Canvas após mudança de visibility

- **ID:** 33.5
- **Title:** Re-render Canvas após mudança de visibility
- **Type:** bug-fix
- **Status:** Done
- **Priority:** P1
- **Epic:** 33
- **Complexity:** S

## Story

Como operador do editor de templates,
quero que mudanças de visibilidade no VisibilityControl reflitam no Canvas,
para que eu veja elementos aparecerem/desaparecerem conforme configurado.

## Acceptance Criteria

- [x] Corrigir `updateNodeProperty`: detectar `VisibilityConfig` via `value.mode` (não `typeof value === 'boolean'`)
- [x] Mudar visibilidade (sempre/condicional/escondido) no VisibilityControl dispara `patchNodeVisibility()`
- [x] Canvas aplica `display:none` ou remove conforme visibilidade
- [x] Elemento some/aparece no Canvas conforme a visibilidade selecionada

## Tasks

- [x] Corrigir condição em updateNodeProperty para detectar VisibilityConfig
- [x] Tratar mode='hidden' como display:none, mode='always' como visible
- [x] Manter backward-compatibility com boolean visibility
- [x] Aplicar mesma lógica em updateNodeProperties bulk
- [x] Adicionar testes

## Scope

**IN:** VisibilityConfig detection fix, patchNodeVisibility dispatch
**OUT:** Conditional visibility engine (KnockoutJS if bindings)

## Dev Notes

- Bug: VisibilityControl emits {mode:'hidden'} object, not boolean
- Old condition `typeof value === 'boolean'` never matched VisibilityConfig objects
- Fix: check for `value.mode` property first, fallback to boolean
