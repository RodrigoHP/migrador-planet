# Story 26.1 — Engine Auto-Resume via Claude Code Hooks

## Story
**Como** usuário do AIOX,
**Quero** que workflows yolo_continuous sejam automaticamente retomados ao abrir uma nova sessão,
**Para** que workflows nunca fiquem "perdidos" após crash ou timeout de sessão.

## Context

### Problema
Quando uma sessão Claude Code morre (crash, timeout, context window esgotado), o state file persiste em `.aios/{id}-engine-state.yaml` com `status: active`, mas ninguém faz `action: continue` automaticamente. O workflow fica perdido até o user manualmente verificar e retomar.

### Design
Usar o sistema de hooks do Claude Code (`settings.json`) para registrar um hook `PostToolUse` ou `PreToolUse` — ou preferencialmente um hook de inicialização que roda ao abrir sessão. O hook:
1. Scaneia `.aios/*-engine-state.yaml` por arquivos com `status: active`
2. Valida que o state não está corrompido (schema check)
3. Verifica se o heartbeat está stale (depende de 26.2, mas funciona sem)
4. Oferece ao user: "Workflow {name} pendente — resumir? [Y/n]"
5. Se sim (ou se em modo auto), executa `*run-workflow {name} continue --mode=engine`

### Limitação
Hooks do Claude Code executam shell commands, não prompts. O hook precisa apenas detectar e informar — a decisão de resumir pode ser via prompt ao user ou automática em modo yolo.

## Acceptance Criteria
- [x] Hook registrado em `.claude/settings.json` que detecta workflows pendentes
- [x] Detecção filtra apenas `status: active` (ignora completed/aborted/paused)
- [x] Max resume attempts: 3 (persiste contador no state file campo `resume_attempts`)
- [x] Se `resume_attempts >= 3`, marca workflow como `aborted` com reason `max_resume_attempts`
- [x] State validation antes de resume (campos obrigatórios presentes, step_index válido)
- [x] Funciona tanto com SDC quanto RCA workflows
- [x] Não interfere com workflows que estão rodando ativamente (checar heartbeat de 26.2)

### Hook Script (conceitual)
```bash
# .aios-core/scripts/check-pending-workflows.sh
# Scaneia state files e retorna info sobre workflows pendentes
for f in .aios/*-engine-state.yaml; do
  status=$(grep "^status:" "$f" | awk '{print $2}')
  if [ "$status" = "active" ]; then
    echo "PENDING: $f"
  fi
done
```
