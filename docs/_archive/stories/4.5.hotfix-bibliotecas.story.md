# Story 4.5: Hotfix — Endpoint e Integração do Modal Bibliotecas

## Status

Superseded

> ⚠️ Superseded pela reescrita v3 (Epics 5-9). Implementação original substituída.

## Story

**As a** operador da ferramenta,
**I want** que o modal de Bibliotecas carregue corretamente o catálogo de versões e esteja acessível em todas as telas do wizard (a partir do Upload),
**so that** eu possa selecionar versões de bibliotecas em qualquer etapa do fluxo sem receber erros de 404 ou ver o modal permanentemente em estado de carregamento.

## Acceptance Criteria

1. `useBibliotecas.ts` chama `${API_BASE}/api/bibliotecas/catalog` (com prefixo `/api/`) — sem este prefixo a chamada não passa pelo proxy Vite e retorna 404
2. Backend expõe `GET /api/bibliotecas/catalog` retornando lista de bibliotecas com `name`, `versions: string[]` e `activeVersion`
3. Catálogo retorna ao menos as bibliotecas usadas nos templates: Knockout.js (versão ativa: `3.5.1`)
4. `BibliotecasModal` renderiza a lista de bibliotecas com selects de versão ao abrir
5. O botão "Bibliotecas" no `AppHeader` está habilitado (prop `show-bibliotecas="true"`) em todas as páginas a partir de `/upload`: `UploadPage`, `CamposPage`, `LayoutPage`, `GeracaoPage`, `ExportarPage`
6. Clicar "Aplicar" no modal atualiza `layoutStore.bibliotecasVersions` corretamente
7. Nenhuma regressão no fluxo Upload → Campos → Layout → Geração → Exportar

## Dev Notes

### Bug B1.4-a — URL sem prefixo `/api/`

```typescript
// frontend/src/composables/useBibliotecas.ts linha 15
// ERRADO:
const res = await fetch(`${API_BASE}/bibliotecas/catalog`)

// CORRETO:
const res = await fetch(`${API_BASE}/api/bibliotecas/catalog`)
```

### Bug B1.4-b — Endpoint inexistente no backend

```python
# backend/routers/bibliotecas.py (CRIAR)
from fastapi import APIRouter

router = APIRouter()

CATALOG = [
    {

@router.get("/bibliotecas/catalog")
async def get_catalog():
    """Retorna catálogo de bibliotecas disponíveis para bundling no ZIP."""

```

```python
# backend/main.py — adicionar:
```

### Bug B1.4-c — `show-bibliotecas` só em LayoutPage

Cada page que usa `WizardLayout` precisa passar `:show-bibliotecas="true"` e reagir ao evento `@open-bibliotecas`. `ExportarPage` usa `FullWidthLayout` — verificar se este template aceita o evento e tem slot para o header com o botão. Se não aceitar, adaptar `FullWidthLayout` para receber `showBibliotecas` prop.
