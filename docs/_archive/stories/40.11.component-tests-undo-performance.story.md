## Dev Notes

### Undo/Redo Refactor (PERF-002)
- **Approach:** Hybrid command pattern — property-level deltas for frequent ops (moveElement, resizeElement, updateNodeProperty, updateNodeProperties, updatePageProperty, updateCellProperty), generic JSON snapshots for structural ops (addNode, removeNode, moveNode, duplicateNode, groupNodes, convertToTable).
- **Delta commands** store only `{ nodeId, oldProperties, newProperties }` (~100-500 bytes) vs full tree JSON snapshots (~50-200KB for 50+ element docs).
- **Performance:** moveElement + undo on 60-element document completes in < 5ms (budget: 16ms/frame).
- **UNDO_MAX:** Increased from 20 to 200 since deltas are lightweight.
- **Backward compat:** All existing undo/redo behavior preserved. Structural ops still use full snapshot for correctness.
