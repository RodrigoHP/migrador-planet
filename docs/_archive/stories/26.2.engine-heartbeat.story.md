# Story 26.2 — Engine Heartbeat & Stale Detection

## Story
**Como** sistema AIOX,
**Quero** que o engine atualize um heartbeat no state file a cada step,
**Para** que seja possível detectar se um workflow morreu silenciosamente.

## Context

### Problema
Hoje não há como distinguir entre um workflow que está "rodando lentamente" e um que morreu. O `updated_at` no state file só é atualizado quando um step completa. Se o engine morre no meio de um step, o `updated_at` fica congelado e ninguém detecta.

### Design
Adicionar campo `heartbeat_at` ao state file, atualizado:
1. No início de cada step (antes de spawnar subagent)
2. A cada check de loop guard
3. No save_state_with_locking

O hook de auto-resume (26.1) usa o heartbeat para decidir:
- Se `heartbeat_at` < `2 × default_step_timeout` → workflow pode estar rodando, não resume
- Se `heartbeat_at` > `2 × default_step_timeout` → workflow está stale, oferecer resume

## Acceptance Criteria
- [x] Campo `heartbeat_at` (ISO-8601) adicionado ao workflow state schema
- [x] Heartbeat atualizado no início de cada action step no Sequence Advancer
- [x] Heartbeat atualizado em cada `save_state_with_locking` call
- [x] Função `is_workflow_stale(state)` implementada no engine
- [x] Threshold de stale: `2 × resolve_timeout(current_step, workflow, state)` ou `2 × default_step_seconds` se step desconhecido

- [x] Config: `engine-config.yaml` ganha campo `stale_detection.multiplier` (default: 2)

## Technical Notes

### Pseudocódigo

```
# No Sequence Advancer, antes de spawnar subagent (step 9):
state.heartbeat_at = ISO_NOW()
save_state_with_locking(state)

# Em save_state_with_locking:
state.heartbeat_at = ISO_NOW()  # Já existente via updated_at, mas heartbeat é explícito

# Função de detecção:
FUNCTION is_workflow_stale(state_file):
  state = read_yaml(state_file)
  IF state.status != "active": RETURN false
  heartbeat = parse_iso(state.heartbeat_at or state.updated_at)
  timeout = state.current_step_timeout or config.timeouts.default_step_seconds
  threshold = timeout * config.stale_detection.multiplier
  RETURN (NOW() - heartbeat) > threshold
```
