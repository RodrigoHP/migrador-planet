# Story 42.13 — OpenAPI TypeScript Codegen

## Status: Done

## Descricao

Implementar geração automática de tipos TypeScript a partir do schema OpenAPI do backend FastAPI. Esta story endereça os ACs 4 e 5 da Story 42.8 que foram adiados porque os tipos gerados na época eram genéricos demais. Com a migração Pydantic completa (42.4–42.7) e os tipos manuais alinhados (42.8), agora é possível avaliar se o codegen produz tipos suficientemente precisos para substituir `pipeline.types.ts` manual.

## Debitos Enderecados

| ID | Debito | Origem |
|----|--------|--------|
| 42.8-AC4 | `openapi-typescript` não configurado | Adiado em 42.8 |
| 42.8-AC5 | `pipeline.types.ts` manual em vez de gerado | Adiado em 42.8 |

## Acceptance Criteria

- [x] AC1: `openapi-typescript` instalado como devDependency em `frontend/package.json`
- [x] AC2: Script `npm run generate:types` em `frontend/package.json` gera `frontend/src/types/generated/pipeline-api.ts` a partir do schema OpenAPI do backend
- [~] AC3: Tipos gerados NÃO atenderam qualidade — `PipelineResult.field_mappings` usa `{ [key: string]: unknown }[]` (PipelineResult usa `list[dict[str,Any]]` no backend). AC4 adiado conforme risk mitigation do story.
- [~] AC4: ADIADO (condicional em AC3) — pipeline.types.ts manual mantido
- [x] AC5: Step de CI em `.github/workflows/ci.yml` verifica sync dos tipos gerados
- [x] AC6: Zero erros TypeScript (`vue-tsc --noEmit` clean)
- [x] AC7: Zero regressões — falhas pré-existentes confirmadas (11 fail pre-existing)

## Riscos

| Risco | Probabilidade | Mitigacao |
|-------|--------------|-----------|
| Tipos gerados ainda genéricos demais (`unknown`, `any`) | MÉDIA | Avaliar cobertura no início; se < 80% dos campos críticos tipados precisamente, AC4 é condicional e não obrigatório |
| CI step de sync check requer backend rodando | MÉDIA | Usar `--input` com arquivo estático do schema OpenAPI em vez de URL |
| Re-exports quebram imports existentes | BAIXA | Fazer re-exports transparentes; manter nomes iguais |

## Dev Notes

### Verificação inicial (antes de comprometer com substituição)

```bash
# Gerar tipos e avaliar qualidade
cd frontend
npx openapi-typescript ../backend/openapi.json --output src/types/generated/pipeline-api.ts

# Verificar se PipelineResult tem campos tipados precisamente
grep -A 20 "PipelineResult" src/types/generated/pipeline-api.ts
```

**Critério de qualidade:** Se `field_mappings`, `document_structure`, `confidence_scores` aparecerem como `unknown` → AC4 é adiado; manter tipos manuais.

### Gerar schema estático do backend

```bash
cd backend
python -c "
from main import app
import json
print(json.dumps(app.openapi(), indent=2))
" > openapi.json
```

### Script npm

```json
{
  "scripts": {
    "generate:types": "openapi-typescript ../backend/openapi.json --output src/types/generated/pipeline-api.ts"
  }
}
```

### CI step de sync check

```yaml
- name: Check OpenAPI types are in sync
  run: |
    cd frontend && npm run generate:types
    git diff --exit-code src/types/generated/
```
