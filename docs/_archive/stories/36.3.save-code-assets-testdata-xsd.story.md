## Story

As a template operator, I want the Save function to include all my code edits, test datasets, XSD flat paths, and asset references, so that when I reopen the project everything is fully restored.

## Acceptance Criteria

- [x] `SavedProjectV2` expanded with fields: `codeFiles`, `testDatasets`, `xsdFlatPaths`, `assetReferences`
- [x] `codeFiles: { html, css, js }` from `codeStore.fileContents`
- [x] `testDatasets` from `testDataStore.datasets`
- [x] `xsdFlatPaths` from `mappingStore.flatPaths`
- [x] `assetReferences` with names/metadata of assets (no binaries)
- [x] `session.loadFromSavedProject()` restores all new fields
- [x] Test: save -> reopen -> Monaco shows edited code, FieldNavigator has XSD dropdown, testDataStore has datasets
