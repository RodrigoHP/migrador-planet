# Story 26.6 — Métricas Históricas Agregadas

## Story
**Como** usuário do AIOX,
**Quero** um summary agregado de todas as execuções do engine,
**Para** ter visibilidade de quantos workflows rodaram, quanto custaram e qual a taxa de sucesso.

## Context

### Problema
Execuções passadas ficam em state files individuais (`.aios/{id}-engine-state.yaml`), mas não há visão consolidada. Para saber "quantos workflows rodei este mês" ou "qual o custo médio de um RCA", preciso ler manualmente cada state file.

### Design
Criar `.aios/engine-metrics.yaml` atualizado ao final de cada workflow com:
- Contadores totais (runs, completions, aborts)
- Breakdown por workflow_id (SDC, RCA, etc.)
- Custo total estimado
- Duração média
- Taxa de sucesso
- Últimas N execuções (resumo)

### Integração
A função `update_execution_intelligence()` (Story 18.7) já roda ao final de cada workflow. Adicionar chamada a `update_engine_metrics()` no mesmo ponto.

## Acceptance Criteria
- [x] `.aios/engine-metrics.yaml` criado/atualizado ao final de cada workflow
- [x] Campos globais: total_runs, total_completed, total_aborted, total_estimated_cost_usd, avg_duration_minutes
- [x] Breakdown por workflow_id com mesmos campos
- [x] Lista das últimas 20 execuções (instance_id, status, duration, cost, date)
- [x] Comando `*engine-metrics` mostra resumo formatado
- [x] Arquivo criado automaticamente na primeira execução (zero-config)

### Pseudocódigo

```
FUNCTION update_engine_metrics(state):
  metrics_path = ".aios/engine-metrics.yaml"
  IF file_exists(metrics_path):
    metrics = read_yaml(metrics_path)
  ELSE:
    metrics = { version: "1.0", global: {total_runs: 0, ...}, by_workflow: {}, recent_runs: [] }

  # Update global
  metrics.global.total_runs += 1
  IF state.status == "completed": metrics.global.total_completed += 1
  ELSE: metrics.global.total_aborted += 1
  metrics.global.success_rate = metrics.global.total_completed / metrics.global.total_runs
  metrics.global.total_estimated_cost_usd += calculate_estimated_cost(state)

  # Update by_workflow
  wf = metrics.by_workflow[state.workflow_id] or init_workflow_metrics()
  # ... same logic per workflow

  # Add to recent_runs (keep last 20)
  metrics.recent_runs.insert(0, summarize_run(state))
  metrics.recent_runs = metrics.recent_runs[:20]

  metrics.updated_at = ISO_NOW()
  write_yaml(metrics_path, metrics)
```
