# Story 41.6 — UX Polish & Accessibility Extras

## Status: Done

## Descricao

Polimento adicional de UX: skeleton screens durante carregamento do editor, mensagens de erro contextuais no upload, e alt texts em imagens para acessibilidade.

## Debitos Enderecados

| ID | Debito | Severidade | Esforco |
|----|--------|-----------|---------|
| UX-004 | Sem skeleton screens no editor (carregamento sem feedback visual) | MEDIUM | 4h |
| UX-010 | Erros de upload sem mensagem contextual (generico "falhou") | MEDIUM | 2h |
| A11Y-004 | Imagens sem alt text (WCAG 2.1 SC 1.1.1) | MEDIUM | 2h |

## Acceptance Criteria

- [x] Skeleton screens exibidos enquanto editor carrega dados do pipeline
- [x] Skeleton cobre: sidebar, canvas area, inspector panel
- [x] Mensagens de erro no upload sao contextuais: arquivo muito grande, formato invalido, rede offline
- [x] Cada tipo de erro tem mensagem e acao sugerida especifica
- [x] Todas as imagens `<img>` e icones decorativos tem alt text ou aria-hidden
- [x] Lighthouse accessibility score >= 95
- [x] Zero regressoes

## Escopo

### IN
- Componente Skeleton generico (ou uso de biblioteca existente)
- Skeleton states para EditorLayout
- Error mapping para upload failures
- Audit de alt texts em todos os componentes com imagens

### OUT
- Loading states para todas as paginas (apenas editor nesta story)
- Internacionalizacao de mensagens de erro
- Responsive/mobile (excluido do escopo do produto)
