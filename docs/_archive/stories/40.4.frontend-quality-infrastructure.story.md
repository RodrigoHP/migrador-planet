## Dev Notes

### SYS-003 (ESLint + Prettier)
- ESLint flat config format with Vue 3 recommended + TypeScript recommended + Prettier integration
- `no-useless-escape` and `no-useless-assignment` set to `warn` (intentional patterns in codebase)
- `eslint .` passes with 0 errors, 91 warnings (mostly `any` in test files)
- Prettier configured with singleQuote, no semi, printWidth 100

### SYS-013 (Pre-commit hooks)
- Husky installed at project root (git root, not frontend/)
- lint-staged in root `package.json` covers both frontend (`eslint --fix` + `prettier --write`) and backend (`ruff check --fix` + `ruff format`)
- Pre-commit hook runs `npx lint-staged`

### SYS-010 (TypeScript `any` removal)
- Source files: 23 `any` → 0 `any` (100% elimination in non-test code)
- Test files: 43 `any` remaining (all `as any` for partial mock objects — standard test pattern)
- Total: well under target of <20 in source code
- Key replacements: pdfjs-dist types, monaco-editor types, chart.js types, `unknown` for catches

### SEC-004 (Audit logging)
- `AuditLoggingMiddleware` registered as outermost middleware in FastAPI
- Logs: access_denied (401/403), login_attempt (auth endpoints), service_role_operation (apikey header)
- Structured JSON format with: event_id, event_type, user_id, ip_address, resource, action, result, duration_ms
- Non-blocking: logs after response is produced
- Standalone `log_audit_event()` function available for explicit audit events from any module

### Pre-existing test failures
- `EditorLayout.spec.ts` and `AutoFixPanel.spec.ts` fail with Vue template SyntaxError (multi-line @click handler) — pre-existing, not caused by this story
