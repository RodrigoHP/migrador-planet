# Story 39.9 — Persistir layoutStates no IndexedDB

**Epic:** 39 — Canvas UX Polish
**Status:** Done
**Gap:** Auditoria Epic 39 — Gap 3
**Escopo:** Frontend (`layout.ts`)
**Estimativa:** 1 ponto

## Descrição

O `persistToIdb()` do layout store omitia `layoutStates` (zoom, selectedNode, selectedField por layout). Ao recarregar a pagina, o estado transiente por layout era perdido — especialmente o zoom customizado por layout. O tipo `LayoutPersistedState` dizia "persistir tudo" (`Omit<LayoutStore, never>`) mas o payload manual nao incluia `layoutStates`.

## Acceptance Criteria

- [x] `layoutStates` incluido no payload de `persistToIdb()`
- [x] `LayoutPersistedState` corrigido para `Omit<LayoutStore, 'pendingScrollToLayout'>` (unico campo efemero)
- [x] Zoom por layout sobrevive reload da pagina
- [x] 1787 testes passando, zero regressoes

## Escopo

**IN:** Adicionar `layoutStates` ao payload de persistencia, corrigir tipo
**OUT:** `pendingScrollToLayout` (efemero por design)
