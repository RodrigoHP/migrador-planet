# Story 28.7 — StructureTree: badges de status de binding visual

## Story
**Como** operador navegando pela aba Estrutura,
**Quero** ver badges coloridos nos nós text/field indicando status de binding (🟩🟥🟨) e barras de cobertura nos containers,
**Para** identificar problemas de mapeamento sem precisar abrir o Inspector de cada nó.

## Status
Done

## Context

Atualmente os nós da StructureTree não têm indicação visual de status de binding:
- `→ {{data.vencimento}}` aparece em texto cinza sem cor — não há distinção entre nó corretamente mapeado e nó com problema
- Nós SEM binding não têm nenhuma indicação visual de problema
- Containers (sections, header, footer) não mostram cobertura de filhos

**O que o operador precisa ver de relance:**
```
ANTES:
▼ 📦 section-header
  · 🔤 text-47   → {{data.vencimento}}
  · 🔤 text-33

DEPOIS:
▼ 📦 Cabeçalho                          3/4 ██░
  · 🔤 Vencimento      🟩 data.venc...
  · 🔤 (sem texto)     🟥 sem binding
```

**Referências de design:**
- Wireframes before/after: `frontend/docs/epic-28-estrutura-audit.md` (seção "Redesign Proposto")
- Comportamento detalhado: `frontend/docs/epic-28-estrutura-audit.md` (regras de cor e nomes)
- Epic: `docs/epics/epic-28-field-mapping-redesign.md`

**Dependências:**
- 28.1 (BindingEditor): para consistência no dado `node.binding`
- 28.2 (Campos redesign): para `fieldNavItems` com status correto que alimentará a coloração

## Acceptance Criteria

## Dev Notes

### Fonte de dados para status dos badges

Os nós da `StructureTree` (`TemplateNode`) têm `node.binding` (string ou null). Isso é suficiente para determinar o status do badge:

```typescript
// Em StructureTreeNode.vue:
const bindingStatus = computed(() => {
  if (!props.node.binding) return 'unbound'         // 🟥

  // Para verificar se é ambíguo, precisamos cruzar com fieldNavItems
  // Opção 1: StructureTree passa fieldNavItems como prop/provide
  // Opção 2: usar mappingStore diretamente no componente
  const navItem = mappingStore.fieldNavItems.find(f => f.path === props.node.binding)
  if (navItem?.status === 'unconfirmed') return 'unconfirmed'  // 🟨

  return 'mapped'  // 🟩
})
```

**Preferência de implementação:** usar `mappingStore` diretamente via `inject` ou `useStore()` — evita prop-drilling profundo em componente recursivo.

### Badge visual nos nós text/field

Adicionar após o texto de binding existente:

```vue
<!-- ANTES (estado atual): -->
<span v-if="node.binding" class="structure-tree-node__binding">
  → {{ node.binding }}
</span>

<!-- DEPOIS: -->
<span v-if="node.binding || isBindable" class="structure-tree-node__binding-row">
  <span
    class="structure-tree-node__badge"
    :class="badgeClass"
    :title="badgeTooltip"
  >●</span>
  <span v-if="node.binding" class="structure-tree-node__binding-text">
    {{ truncatedBinding }}
  </span>
  <span v-else class="structure-tree-node__binding-empty">
    sem binding
  </span>
</span>
```

**Computed para badge:**
```typescript
const badgeClass = computed(() => ({
  'badge--mapped':      bindingStatus.value === 'mapped',
  'badge--unbound':     bindingStatus.value === 'unbound',
  'badge--unconfirmed': bindingStatus.value === 'unconfirmed',
}))

const badgeTooltip = computed(() =>
  bindingStatus.value === 'unbound'
    ? 'sem binding — clicar para vincular'
    : props.node.binding ?? ''
)

const truncatedBinding = computed(() => {
  const b = props.node.binding ?? ''
  return b.length > 20 ? b.substring(0, 17) + '...' : b
})

// Só mostrar badge em nós que podem ter binding (text/field)
const isBindable = computed(() =>
  props.node.type === 'text' || props.node.type === 'field'
)
```

### Mini barra de cobertura nos containers

Para nós container (section, header, footer, flow), mostrar X/Y filhos com binding:

```vue
<!-- Adicionar no template dos containers, após o nome: -->
<div v-if="isContainer && coverageTotal > 0" class="structure-tree-node__coverage">
  <span class="coverage-text">{{ coverageBound }}/{{ coverageTotal }}</span>
  <div class="coverage-bar">
    <div class="coverage-bar__fill" :style="{ width: coveragePercent + '%' }"></div>
  </div>
</div>
```

**Computed para cobertura:**
```typescript
const isContainer = computed(() =>
  ['section', 'header', 'footer', 'flow', 'container'].includes(props.node.type)
)

// Recursivo: conta todos os descendentes bindable (text/field)
const coverageTotal = computed(() => {
  if (!isContainer.value) return 0
  return getAllDescendants(props.node).filter(n =>
    n.type === 'text' || n.type === 'field'
  ).length
})

const coverageBound = computed(() =>
  getAllDescendants(props.node).filter(n =>
    (n.type === 'text' || n.type === 'field') && n.binding
  ).length
)

const coveragePercent = computed(() =>
  coverageTotal.value === 0 ? 0 : Math.round((coverageBound.value / coverageTotal.value) * 100)
)
```
