# Story 26.3 — run_in_background Real via Agent Tool

## Story
**Como** usuário do AIOX,
**Quero** que workflows com `run_in_background: true` realmente rodem em background,
**Para** que eu possa continuar trabalhando enquanto um RCA ou SDC executa autonomamente.

## Context

### Problema
O campo `run_in_background: true` existe no metadata do workflow RCA (`rca-investigation.yaml` line 28), mas é puramente decorativo. Nenhum código no engine o interpreta. O workflow sempre roda no foreground, bloqueando a sessão.

### Design
Implementar no `run-workflow.md` (ou no ponto de entrada do engine) a detecção do flag:

1. Ler `workflow.metadata.run_in_background`
2. Se `true` e `action == yolo_continuous`:
   - Spawnar o workflow inteiro como `Agent(run_in_background: true)` do Claude Code
   - O Agent recebe o prompt completo para executar `run-workflow-engine` com todos os parâmetros
   - Retornar imediatamente ao user: "Workflow {name} rodando em background. Use `*workflow-status` para verificar."
3. Se `false` ou `action != yolo_continuous`: comportamento atual (foreground)

### Considerações
- O Agent tool do Claude Code já suporta `run_in_background: true` nativamente
- O state file serve como canal de comunicação entre a sessão principal e o background
- Se o background morre, 26.1 (auto-resume) e 26.2 (heartbeat) detectam e recuperam

## Acceptance Criteria
- [x] `run-workflow.md` detecta `metadata.run_in_background == true`
- [x] Em background: spawna via `Agent(run_in_background: true)` com prompt completo

## Technical Notes

### Pseudocódigo

```
# Em run-workflow.md, após resolver workflow YAML:
IF workflow.metadata.run_in_background == true AND action == "yolo_continuous":
  instance_id = generate_instance_id(workflow_id)

  # Inicializar state file ANTES de spawnar (para que status check funcione)
  init_state(instance_id, workflow, action="yolo_continuous")

  # Spawnar em background
  Agent(
    prompt: "Execute run-workflow-engine with workflow={workflow_name} action=yolo_continuous instance_id={instance_id}",
    run_in_background: true,
    description: "Engine: {workflow_name}"
  )

  Log: "🚀 Workflow {workflow_name} rodando em background (instance: {instance_id})"
  Log: "Use *workflow-status para verificar progresso."
  RETURN
ELSE:
  # Comportamento atual (foreground)
  ...
```

### Novo comando: *workflow-status

```
FUNCTION workflow_status():
  files = glob(".aios/*-engine-state.yaml")
  FOR each file in files:
    state = read_yaml(file)
    stale = is_workflow_stale(state)  # From 26.2
    Log: "{state.workflow_name} | {state.status} | Step {state.current_step_index}/{state.action_steps_total} | {stale ? '⚠️ STALE' : '✅ alive'}"
```
