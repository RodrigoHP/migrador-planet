# Story 19.2 — Config Externalization

## Story
**Como** operador que configura o engine para diferentes projetos,
**Quero** que todos os valores hardcoded (timeouts, token limits, cost limits, retry counts, loop guard max) sejam externalizados para `.aios/engine-config.yaml` com defaults sensatos,
**Para** que cada projeto possa customizar o comportamento do engine sem editar o pseudocode.

## Status
Draft

## Context

### Problema

O run-workflow-engine.md contem dezenas de valores hardcoded:
- `max_loops: 3` (loop guard)
- Token limits por step
- Cost limits por run
- Timeouts para subagent execution
- Retry counts para parse failures
- Max iterations para self-healing

Cada projeto tem necessidades diferentes: um projeto simples precisa de menos retries, um projeto complexo precisa de mais tokens. Hoje a unica forma de ajustar eh editar o engine diretamente.

### Design

#### Novo arquivo: `.aios/engine-config.yaml`

```yaml
engine:
  version: "1.0"

  execution:
    max_loops: 3                    # Loop guard default
    max_retries_per_step: 2         # Retries antes de abort
    parse_failure_max_retries: 2    # Retries para output parse failure

  tokens:
    max_per_step: 50000             # Token limit por step
    max_per_run: 500000             # Token limit por run completo
    warning_threshold: 0.8          # Alerta quando atingir 80%

  cost:
    max_per_run: 10.00              # USD limit por run
    warning_threshold: 0.8          # Alerta quando atingir 80%

  timeouts:
    step_execution: 300000          # 5 min default per step (ms)
    subagent_spawn: 30000           # 30s para spawn subagent (ms)
    workflow_total: 3600000         # 1h total por workflow (ms)

  self_healing:
    enabled: true
    max_iterations: 2
    severity_threshold: "HIGH"      # Minimo severity para auto-fix

  recovery:
    auto_save_interval: 60000       # Save state a cada 60s (ms)
    max_recovery_attempts: 3
```

#### Carregamento no engine

```
ON engine_start:
  config = load_config(".aios/engine-config.yaml")
  IF config not found:
    config = DEFAULT_CONFIG  # Valores acima como defaults
  VALIDATE config schema
  MERGE config with defaults (user config overrides defaults)
```

#### Backward Compatibility

- Se `.aios/engine-config.yaml` nao existir, engine usa defaults identicos aos valores hardcoded atuais
- Valores parciais sao aceitos — merge com defaults preenche o resto
