# Story 14.2 — Border Editor (F1)

## Story

**Como** operador do editor de templates,
**Quero** controlar bordas de qualquer elemento ou seção (espessura, cor, estilo e raio por lado independente),
**Para** reproduzir documentos com grids e bordas complexas (boletos, notas fiscais, tabelas) sem precisar editar CSS manualmente.

## Status

Done

## Context

### Problema

O editor **não tem NENHUM controle de bordas**. Boletos bancários são ~90% bordas — retângulos, separadores, grids com bordas de espessuras diferentes por lado. O operador não consegue adicionar, remover ou ajustar bordas em nenhum elemento nem seção. Isso bloqueia a reprodução de qualquer documento com grids/tabelas visuais.

**Exemplo concreto — Boleto Bradesco:**
- Grid "Recibo do Sacado": cada célula tem bordas grossas em cima/baixo e finas nos lados
- Seção "Ficha de Compensação": borda dupla (`border-style: double`)
- Bloco de instruções: borda simples envolvendo texto denso

### Estado Atual do Código

**`ElementInspector.vue`** (`frontend/src/organisms/inspectors/ElementInspector.vue`):
- Seções existentes: Posição, Dimensões, Tipografia, Dados, Format String, Estilo Condicional, Posição Avançada, Visibilidade
- **Nenhuma seção de bordas** — zero controles de `border-*`
- Usa `InspectorField` (read-only), `InspectorInput` (editável), `InspectorColorPicker`, `InspectorSelect`
- Propriedades lidas via `p = computed(() => node?.properties ?? {})`

**`SectionInspector.vue`** (`frontend/src/organisms/inspectors/SectionInspector.vue`):
- Seções existentes: Geral, Aparência, Espaçamento, Comportamento
- Padrão de escrita: `setProp(key, value)` → `templateStore.updateNodeProperty(nodeId, key, value)`
- **Nenhuma seção de bordas**

**`InspectorColorPicker.vue`** (`frontend/src/molecules/InspectorColorPicker.vue`):
- HTML5 color picker reutilizável com `v-model` (label + swatch + hex display)
- Pode ser reutilizado diretamente para cores de borda por lado

**`templateStore.ts`** (`frontend/src/stores/templateStore.ts`):
- `updateNodeProperty(nodeId, path, value)` — chama `pushUndoSnapshot()` internamente (line 134)
- `updateNodeProperties(id, props)` — batch update (line 121)
- Undo stack com até 20 snapshots

**`template.types.ts`** / **`editor.types.ts`**:
- Nenhuma definição de tipos para propriedades de border — precisa ser adicionado

### Solução Necessária

1. **Componente `BorderEditor.vue`:** Controle visual para configurar border-width, border-color, border-style e border-radius, com toggle "all sides" / "per side"
2. **Integração no `ElementInspector.vue`:** Nova seção "Bordas" entre "Tipografia" e "Dados"
3. **Integração no `SectionInspector.vue`:** Nova seção "Bordas" entre "Aparência" e "Espaçamento"
4. **Tipos:** Interface `BorderConfig` em `template.types.ts`
5. **Canvas rendering:** Propriedades de border mapeadas para inline styles no canvas

## Acceptance Criteria

1. **AC1 — Border Width per Side:** O operador pode definir `border-width` independente para top, right, bottom e left (input numérico em px) em qualquer elemento ou seção
2. **AC2 — Border Color per Side:** O operador pode definir `border-color` independente para cada lado usando o ColorPicker existente
3. **AC3 — Border Style Select:** O operador pode escolher `border-style` (solid, dashed, dotted, double, none) por lado via dropdown
4. **AC4 — Border Radius:** O operador pode definir `border-radius` para os 4 cantos (top-left, top-right, bottom-right, bottom-left) em px
5. **AC5 — Shorthand Toggle:** Toggle "Todos os lados" aplica o mesmo valor para os 4 lados de width/color/style; toggle "Por lado" permite configuração independente
6. **AC6 — Canvas Live Preview:** Mudanças nos controles de borda são refletidas imediatamente no canvas (via `updateNodeProperty` + re-render)
7. **AC7 — Undo Integration:** Todas as mudanças de borda participam do undo stack existente (`pushUndoSnapshot` chamado automaticamente via `updateNodeProperty`)
8. **AC8 — Sem Regressão:** Todas as seções existentes do ElementInspector e SectionInspector continuam funcionando corretamente após a adição da seção "Bordas"
9. **AC9 — Visual Regression Test:** Teste de regressão visual garante que a renderização de bordas no canvas corresponde ao output esperado (screenshot comparison ou snapshot de inline styles gerados)

### Padrões Existentes a Seguir

**Inspector integration pattern (SectionInspector.vue):**
```typescript
// Leitura de propriedade
const p = computed(() => (props.node?.properties ?? {}) as Record<string, unknown>)

// Escrita de propriedade — sempre via store (undo automático)
function setProp(key: string, value: unknown) {
  if (props.node?.id) {
    templateStore.updateNodeProperty(props.node.id, key, value)
  }
}
```

**Naming convention para propriedades no store:**
- Snake_case: `padding_top`, `padding_bottom`, `background_color`, `font_size`
- Border properties devem seguir: `border_top_width`, `border_top_color`, `border_top_style`, `border_radius_top_left`, etc.

### Estratégia de Propriedades no Store

As propriedades de border são armazenadas como propriedades flat no nó (não como objeto aninhado), seguindo o padrão existente de `padding_top`, `padding_left`, etc.:

```typescript
// Propriedades individuais no node.properties
{
  border_top_width: 1,
  border_top_color: '#000000',
  border_top_style: 'solid',
  border_right_width: 0,
  border_right_color: '#000000',
  border_right_style: 'none',
  border_bottom_width: 1,
  border_bottom_color: '#000000',
  border_bottom_style: 'solid',
  border_left_width: 0,
  border_left_color: '#000000',
  border_left_style: 'none',
  border_radius_top_left: 0,
  border_radius_top_right: 0,
  border_radius_bottom_right: 0,
  border_radius_bottom_left: 0,
}
```

O componente `BorderEditor.vue` converte de/para `BorderConfig` internamente para facilitar a UX, mas persiste como propriedades flat via `updateNodeProperty`.
