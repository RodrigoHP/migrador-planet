## Story

Como operador do editor de templates,
quero que Header, Footer e Flow abram o SectionInspector ao serem selecionados na StructureTree,
para que eu possa editar altura, padding, repetição e visibilidade dessas seções.

- [x] `LEVEL_MAP` em `inspectorStore.ts`: mudar `header/footer/flow` de `'structural'` → `'section'`
- [x] Selecionar Header na árvore abre SectionInspector com altura, padding, repetição, visibilidade
- [x] Selecionar Footer na árvore abre SectionInspector
- [x] Selecionar Flow na árvore abre SectionInspector
- [x] StructuralNodeInfo.vue mantido para nós sem inspector dedicado (container genérico, etc.)
- [x] Verificar que SectionInspector funciona corretamente com nós do tipo header/footer/flow
