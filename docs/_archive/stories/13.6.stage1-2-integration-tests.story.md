# Story 13.6 — Stage 1+2 Integration Tests + Performance Benchmark

## Story
**Como** equipe de desenvolvimento,
**Quero** testes de integração end-to-end para Stages 1→2 com benchmark de performance,
**Para** garantir que os contratos estão corretos e a performance atende ao target antes de avançar.

## Status
Done

## Acceptance Criteria

1. Teste e2e: 1 PDF → Stage 1 (clusters) → Stage 2 (extraction) → contratos 3.1 e 3.2 válidos
2. Teste e2e: 3 PDFs mesmo template → pool único → clusters corretos com `pdf_id` preservado
3. Teste e2e: PDF de template diferente → Homogeneity Check detecta (`shared_ratio < 0.20`)
4. Benchmark: 100 páginas em < 16s (Stage 1 ~5.5s + Stage 2 ~10s)
5. Contratos 3.1 e 3.2 validados com JSON Schema (jsonschema lib)
6. Edge cases: página em branco, PDF rotacionado, tabela sem ruling lines, imagem sem bbox válida
7. `_raw_text_blocks` preservado e acessível para Stage 3 (texto real, não abstrato)
