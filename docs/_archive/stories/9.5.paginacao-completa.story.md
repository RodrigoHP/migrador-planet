# Story 9.5: Loops, Foreach & Layout Engine

## Status
Done

## Story
**As a** operador,
**I want** que o editor detecte loops, gere foreach para arrays dinâmicos, calcule quebras de página via Layout Engine, configure dimensões de página e quebre tabelas entre páginas,
**so that** o template lide corretamente com paginação e conteúdo dinâmico.

## Acceptance Criteria
1. Detecção de Loop: elementos classificados como fixos (tamanho/posição estática) ou dinâmicos (podem crescer com dados) baseado em arrays XSD e padrões visuais (FR11)
2. Geração de Foreach: arrays dinâmicos geram `<!-- ko foreach: arrayField -->` no HTML com template de iteração adequado (FR11)
3. Layout Engine: calcula quebras de página no Canvas em tempo real — `remainingSpace = bodyHeight - headerHeight - footerHeight`, insere quebra de página quando conteúdo excede (FR12)
4. Configuração de página via PageInspector: tamanho (A4/Letter/Custom), orientação, margens → Layout Engine recalcula (FR22)
5. Paginação de Tabela: tabelas que excedem altura da página quebram por linhas; `<thead>` repetido em cada página de continuação; mínimo de linhas por página configurável (padrão 3) via TableInspector (FR12)
6. Canvas mostra linhas de quebra de página: "--- QUEBRA DE PÁGINA ---" com números de página
7. Paginação no Canvas corresponde exatamente ao que base.js produz em runtime (mesmo algoritmo, duas implementações) (FR12)
8. Parâmetros de paginação configuráveis via InspectorPanel (TableInspector: quebra/repetir header/min linhas; PageInspector: dimensões/margens)
9. Testes cobrem: cálculo de paginação, geração de foreach, lógica de quebra de tabela
10. `npm run build` passa sem erros
