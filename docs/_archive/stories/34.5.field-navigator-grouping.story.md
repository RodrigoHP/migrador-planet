## Story

As a template operator, I want to group fields by type (Campos, Tabelas, Graficos, Secoes, Recursos) in addition to status grouping, so that I can find fields more efficiently.

- [x] Toggle ou tabs para alternar entre agrupamento por status (atual) e por tipo
- [x] Agrupamento por tipo: Campos, Tabelas, Graficos, Secoes, Recursos
- [x] Contagem por grupo visivel no header de cada secao
- [x] Estado do toggle persiste na sessao
