# Story 6.8: Coverage + Confidence Popovers e Overlays Visuais

## Status
Done

## Story
**As a** operador,
**I want** clicar nos badges Confiança e Cobertura no toolbar para ver detalhamentos em popovers, e ativar o Modo Cobertura para ver overlays visuais no Canvas e no PDF,
**so that** eu compreenda a qualidade da análise automática.

## Acceptance Criteria
1. Badge Confiança: clique abre popover com 5 fatores (barras de progresso + %): Estabilidade de Layout, Detecção de Âncoras, Qualidade do Grid, Variabilidade de Campos, Concordância da Visão
2. Badge Cobertura: clique abre popover com breakdown: Campos mapeados N/M, Tabelas N/M, Imagens N/M, Gráficos N/M
3. Ambos os popovers exibem nível de threshold: ✅ (≥95%), ⚠️ (80-95%), 🔴 (<80%)
4. Popovers fecham ao clicar fora
5. Badges atualizam por Layout Type — trocar layout atualiza ambos os badges
6. Toggle Modo Cobertura: quando ativo, Canvas exibe overlays — 🟩 verde (binding definido), 🟥 vermelho (sem binding), 🟨 amarelo (não confirmado), 🟪 roxo (tabela), 🟧 laranja tracejado (seção opcional), 📊 laranja sólido (gráfico)
7. Toggle Modo Cobertura: quando ativo, PDF Reference exibe overlays — 🟦 azul (bloco de texto), 🟩 verde (mapeado), 🟥 vermelho (não mapeado), 🟨 amarelo (não confirmado), 🟪 roxo (tabela), 📊 laranja (gráfico)
8. Overlays lidos de `coverageStore` overlay data
9. `npm run build` passa

## Architect Review

**Reviewer:** Aria (System Architect)
**Date:** 2026-03-17
**Status:** APPROVED

### Design Assessment

1. **useClickOutside composable:** Implementação genérica e reutilizável — o padrão correto para Vue 3 Composition API. Event listener no `document` com cleanup em `onUnmounted` previne memory leak. Será reutilizado em Epic 7 para outros popovers/dropdowns.

2. **CoverageOverlay target prop:** Unificar canvas e PDF num único componente via `target: 'canvas' | 'pdf'` é elegante — evita duplicação de lógica de renderização de overlays. As cores distintas por target são configuradas via `OVERLAY_COLORS` centralizado.

3. **Mutex de popovers no TopToolbar:** Apenas um popover aberto por vez gerenciado no organism pai (TopToolbar) é o padrão correto — evita que os popovers precisem conhecer uns aos outros.

4. **coverageStore.overlayData:** Extensão do store existente com `overlayData` por layout é a abordagem correta — mantém a separação de concerns (store gerencia dados, overlay component gerencia visualização).

5. **ConfidenceFactor molecule:** Props bem tipadas com `value: number (0-100)` e lógica de threshold encapsulada internamente — correto para reutilização.

### Decision Log
| Decisão | Justificativa |
|---------|---------------|
| `useClickOutside` composable vs Vue directive | Composable é mais testável e explícito em Composition API |
| CoverageOverlay único vs dois componentes | Lógica idêntica; target prop configura apenas as cores |
| `v-if` nos popovers vs `v-show` | Popovers não precisam estar no DOM quando fechados — v-if é correto |
