# Story 25.1 — Phase Contracts: Input/Output de Cada Fase

## Story
**Como** orquestrador multi-model,
**Quero** contratos formais de input/output para cada fase,
**Para** que subagents isolados saibam exatamente o que recebem e devolvem.

## Status
Draft

## Context

### Problema
Hoje o output de uma fase "flui" pelo contexto acumulado. Com subagents isolados, cada fase precisa de contrato explicito. Sem contrato, o briefing pode omitir dados criticos ou incluir lixo.

### Design
Definir para cada fase (0-6, 8-9):
- **Input:** Lista de campos com tipo e origem (qual fase produziu)
- **Output:** Lista de campos com tipo e formato
- **Validacao:** Campos obrigatorios vs opcionais

Schema YAML completo no epic file. Implementar como secao no investigate.md e como referencia no workflow YAML.

## Acceptance Criteria
- [ ] Contrato input/output definido para 9 fases (0-6, 8-9)
- [ ] Cada campo tem tipo, origem, e obrigatoriedade
- [ ] Contratos documentados no investigate.md
- [ ] Workflow YAML referencia contratos
- [ ] Validacao de campos obrigatorios definida

**OUT:** Implementacao de validacao automatica
