# Story 28.3 — Modal de resolução de ambiguidade

## Story
**Como** operador resolvendo campos com mapeamento ambíguo,
**Quero** clicar em um campo 🟨 e ver um modal com os candidatos XSD e seus scores de confiança,
**Para** selecionar o mapeamento correto e confirmar em uma única ação.

## Status
Done

## Context

O evento `open-ambiguous` já é emitido por `FieldNavItem.vue:81` quando o usuário clica em um campo ambíguo (status `unconfirmed`). Mas em `FieldNavigator.vue`, não existe handler para esse evento — o modal nunca abre.

**Estado atual (dead code de interação):**
```typescript
// FieldNavItem.vue:81
emit('open-ambiguous', { field, candidates })

// FieldNavigator.vue — sem handler:
// @open-ambiguous="???"  ← ausente
```

Os candidatos (`candidates`) já existem no tipo `FieldNavItem`:
```typescript
interface FieldNavItem {
  // ...
  isAmbiguous: boolean
  candidates: Array<{ path: string; score: number }>  // já tipado
}
```

**O que o modal deve fazer:**
1. Listar candidatos com score (ex: "data.vencimento — 87%")
2. Permitir selecionar o correto
3. Confirmar → atualiza `node.binding` + muda status 🟨→🟩
4. Opção "Nenhum dos anteriores" para deixar sem mapeamento

**Referências de design:**
- Wireframe do modal: `frontend/docs/epic-28-campos-behavior-spec.md` (seção "campo 🟨 — ambíguo")
- Comportamento detalhado: `frontend/docs/epic-28-field-mapping-interaction-spec.md` (seção AmbiguousFieldModal)
- Epic: `docs/epics/epic-28-field-mapping-redesign.md`

**Dependências:** 28.1 (BindingEditor / updateNodeBinding action), 28.2 (novos fieldNavItems com status correto)

Adicionar no `<script setup>`:
```typescript
import AmbiguousFieldModal from '@/molecules/AmbiguousFieldModal.vue'

const ambiguousModalField = ref<FieldNavItem | null>(null)

function onOpenAmbiguous(field: FieldNavItem) {
  ambiguousModalField.value = field
}

function onResolveAmbiguous(chosenPath: string | null) {
  if (ambiguousModalField.value) {
    mappingStore.resolveAmbiguous(ambiguousModalField.value.id, chosenPath)
  }
  ambiguousModalField.value = null
}

function onCancelAmbiguous() {
  ambiguousModalField.value = null
}
```

### Action `resolveAmbiguous` em `mapping.ts`

```typescript
resolveAmbiguous(fieldId: string, chosenPath: string | null) {
  // Encontrar o fieldNavItem
  const item = this.fieldNavItems.find(f => f.id === fieldId)
  if (!item) return

  if (chosenPath) {
    // Atualizar binding e status
    item.status = 'mapped'
    item.path = chosenPath
    // Atualizar node no templateStore via mappingStore.updateNodeBinding
    this.updateNodeBinding(item.nodeId ?? item.id, chosenPath)
  } else {
    // "Nenhum dos anteriores"
    item.status = 'unmapped'
    item.path = ''
    this.removeNodeBinding(item.nodeId ?? item.id)
  }
}
```

### Componente `AmbiguousFieldModal.vue`

```vue
<template>
  <Teleport to="body">
    <div class="modal-overlay" @click.self="$emit('cancel')" @keydown.escape="$emit('cancel')">
      <div class="ambiguous-modal" role="dialog" aria-modal="true">
        <h2 class="ambiguous-modal__title">
          Resolver ambiguidade: {{ fieldDisplayName }}
        </h2>
        <p class="ambiguous-modal__subtitle">
          Selecione o campo XSD correto para este dado do PDF:
          <strong>"{{ field.value }}"</strong>
        </p>

        <ul class="ambiguous-modal__candidates">
          <li
            v-for="candidate in sortedCandidates"
            :key="candidate.path"
            class="ambiguous-modal__candidate"
            :class="{ 'is-selected': selected === candidate.path }"
            @click="selected = candidate.path"
          >
            <input type="radio" :value="candidate.path" v-model="selected" />
            <div class="candidate-info">
              <span class="candidate-info__path">{{ candidate.path }}</span>
              <span class="candidate-info__label">{{ semanticLabel(candidate.path) }}</span>
            </div>
            <div class="candidate-score">
              <div class="candidate-score__bar">
                <div class="candidate-score__fill" :style="{ width: (candidate.score * 100) + '%' }"></div>
              </div>
              <span class="candidate-score__value">{{ Math.round(candidate.score * 100) }}%</span>
            </div>
          </li>
        </ul>

        <div class="ambiguous-modal__none">
          <label>
            <input type="radio" :value="null" v-model="selected" />
            Nenhum dos anteriores — deixar sem mapeamento
          </label>
        </div>

        <div class="ambiguous-modal__actions">
          <button @click="$emit('cancel')" class="btn btn--secondary">Cancelar</button>
          <button @click="confirm" class="btn btn--primary" :disabled="selected === undefined">
            Confirmar
          </button>
        </div>
      </div>
    </div>
  </Teleport>
</template>
```

**Props:**
```typescript
interface Props {
  field: FieldNavItem  // campo ambíguo com candidates
}
```

**Emits:**
```typescript
emit('resolve', chosenPath: string | null)
emit('cancel')
```

**Computed e métodos:**
```typescript
const selected = ref<string | null | undefined>(undefined)  // undefined = nada selecionado

const sortedCandidates = computed(() =>
  [...props.field.candidates].sort((a, b) => b.score - a.score)
)

function semanticLabel(path: string): string {
  return path.split('.').pop()?.replace(/_/g, ' ') ?? path
}

function confirm() {
  if (selected.value !== undefined) {
    emit('resolve', selected.value)
  }
}
```
