# Story 21.11 — Handoff RCA→SDC Operacional

## Story
**Como** agente @sm recebendo backlog items de uma investigacao RCA,
**Quero** um handoff artifact estruturado e auto-gerado pela Fase 8,
**Para** que stories de backlog nao se percam entre a investigacao e o ciclo de desenvolvimento.

## Status
Done

## Context

### Problema
O workflow YAML preve `handoff-rca-to-sdc-{date}.yaml` mas nenhum RCA real gera esse artifact. Backlog items ficam documentados no relatorio de investigacao mas nao sao consumidos pelo SDC. Resultado: achados colaterais e melhorias identificadas durante RCA podem ser esquecidos.

### Design
Na Fase 8 (Documentacao), quando backlog items sao identificados:
1. **Gerar artifact**: `.aios/handoffs/handoff-rca-to-sdc-{date}.yaml`
2. **Conteudo**:
   - `from_agent: @qa`
   - `investigation_id: rca-{date}-{slug}`
   - `backlog_items`: lista de stories sugeridas com titulo, prioridade, contexto
   - `consumed: false`
3. **Formato compativel** com handoff protocol existente (agent-handoff.md)
4. **Consumo**: @sm ou @aios-master consome ao iniciar SDC, marcando `consumed: true`

## Acceptance Criteria
- [ ] Fase 8 do investigate.md gera handoff artifact quando backlog items existem
- [ ] Artifact segue formato do handoff protocol existente (.aios/handoffs/)
- [ ] Conteudo inclui: from_agent, investigation_id, backlog_items (titulo, prioridade, contexto)
- [ ] Artifact criado com `consumed: false`
- [ ] Workflow YAML atualizado com step de handoff generation
- [ ] @aios-master greeting (step 5.5) detecta handoff RCA pendente e sugere `*workflow story-development-cycle`
- [ ] Documentacao no investigate.md referencia o handoff

## Scope
**IN:** Fase 8 do investigate.md, handoff artifact, workflow YAML
**OUT:** Consumo automatico pelo SDC (responsabilidade do SDC workflow)
