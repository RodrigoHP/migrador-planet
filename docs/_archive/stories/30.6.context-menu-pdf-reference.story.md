# Story 30.6 — Context menu no PDF Reference panel

## Story
**Como** operador visualizando o PDF original no painel de referência,
**Quero** clicar direito em uma região para criar um campo naquela posição,
**Para** alinhar rapidamente a estrutura do template com o layout do PDF.

## Status
Done

## Business Value
Sem context menu, o operador precisa criar campos na árvore e arrastá-los até
a posição correta no canvas. Com o context menu no PDF Reference, pode criar
diretamente no local visível.

**Estimativa:** 2 story points (M)

## Scope

**IN:**
- `@contextmenu.prevent` no canvas do PDFReference (elemento `<canvas ref="canvasRef">`)
- Context menu usando `ContextMenu.vue` (genérico, já existente)
- Opções: "Criar campo aqui" (type: field), "Criar seção aqui" (type: section)
- Coordenadas calculadas: posição do clique relativa ao canvas, ajustada pelo zoom
- `templateStore.addNode(rootId, type)` → depois `updateNodeProperty` para x, y
- Fechar menu ao clicar fora (via ContextMenu.vue emit close)

**OUT:**
- Seleção de região por drag
- Binding automático via OCR
- Context menu no CoverageOverlay
- Coordinate precision (posição é aproximada — operador pode arrastar)

## Acceptance Criteria

- [x] **AC1:** Clique direito no canvas do PDF Reference abre context menu
- [x] **AC2:** Menu tem opções "Criar campo aqui" e "Criar seção aqui"
- [x] **AC3:** "Criar campo aqui" → `templateStore.addNode(rootId, 'field')` chamado + nó tem x/y aproximados do clique
- [x] **AC4:** Menu fecha ao clicar fora ou pressionar Escape
- [x] **AC5:** Sem PDF carregado (canvas oculto) → context menu não abre

## Dev Notes

**Cálculo de coordenadas:**
```typescript
const rect = canvas.getBoundingClientRect()
const pdfX = Math.round((e.clientX - rect.left) / (editorStore.pdfZoom / 100))
const pdfY = Math.round((e.clientY - rect.top) / (editorStore.pdfZoom / 100))
```

**Parent para addNode:**
Usar o `documentTree.value.root.id` como parent. Se a árvore não estiver carregada,
o menu abre mas `addNode` retorna null silenciosamente.
