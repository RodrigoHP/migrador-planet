## Story

As a template operator, I want to click on a line in the Monaco editor and have the corresponding tree node selected in the Structure panel and Inspector, so that I can navigate code and structure bidirectionally.

## Acceptance Criteria

- [x] Handler `onDidChangeCursorPosition` detects current line
- [x] Extracts `data-node-id` closest to the line (search upward in parsed DOM)
- [x] Calls `editorStore.selectElement(nodeId)` + `inspectorStore.selectNode(node)`
- [x] Tree highlights corresponding node and Inspector opens
- [x] Works only on `index.html` file (not CSS/JS)
