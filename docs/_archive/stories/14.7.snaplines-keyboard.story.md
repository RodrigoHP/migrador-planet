# Story 14.7 — Snap Lines Visuais + Keyboard Shortcuts (F10 + F14)

## Story

**Como** operador do editor de templates,
**Quero** ver linhas de snap visuais durante drag/resize e usar atalhos de teclado para posicionar elementos com precisão,
**Para** alinhar elementos rapidamente seguindo o padrão Figma/Photoshop sem depender exclusivamente do mouse.

## Status

Done

## Context

### Problema

A infraestrutura de snap magnético já existe em `useCanvasInteraction.ts` — tipos `SnapLine[]`, threshold de 8px, cálculo de edges (top, bottom, left, right, center). O snap funciona: elementos "grudam" nas posições corretas durante drag. Porém, o snap é **cego** — não há feedback visual. O operador não sabe por que o elemento parou em determinada posição, não vê as linhas de alinhamento, e não tem labels de distância.

Além disso, não existem keyboard shortcuts para posicionamento fino. O operador depende 100% do mouse para mover e redimensionar elementos, tornando ajustes de 1px impossíveis sem editar coordenadas manualmente no inspector.

### Estado Atual do Código

**`frontend/src/composables/useCanvasInteraction.ts`:**
- Tipo `SnapLine` definido com `position`, `orientation` (horizontal/vertical), `sourceId`
- `threshold = 8` (px de proximidade para snap)
- Cálculo de edges: compara `top`, `bottom`, `left`, `right`, `centerX`, `centerY` do elemento arrastado contra todos os outros elementos visíveis
- Resultado: snap magnético funcional — mas `SnapLine[]` não é exposto para rendering
- Handlers `onDragMove()` e `onResizeMove()` consomem snap internamente

**`frontend/src/organisms/HTMLCanvas.vue`:**
- Canvas wrapper que recebe eventos de mouse
- Não tem key event handlers
- Não renderiza overlays de snap

**`frontend/src/stores/editorStore.ts`:**
- `snapEnabled: boolean` — toggle de snap (existe)
- `gridSize: number` — tamanho do grid (existe)
- `selectedElementId: string | null` — elemento selecionado (existe)

**`frontend/src/stores/templateStore.ts`:**
- `updateNode(id, patch)` — atualiza propriedades do nó
- `deleteNode(id)` — remove nó da árvore
- `pushUndoSnapshot()` — undo stack

**`frontend/src/components/CanvasGuides.vue`:**
- Componente existente que renderiza guias visuais (margin lines, zone overlays)
- Padrão a seguir para overlay visual no canvas

### Solução Necessária

**F10 — Snap Lines Visuais:**
1. Expor `activeSnapLines: SnapLine[]` do composable `useCanvasInteraction` como ref reativa
2. Criar `SnapLineOverlay.vue` que renderiza as linhas ativas durante drag/resize
3. Linhas magenta (#FF00FF) de 1px, estilo dashed, spanning toda a extensão do canvas
4. Labels de distância (px) entre o elemento arrastado e o elemento de referência do snap
5. Linhas desaparecem quando drag/resize termina (activeSnapLines volta a `[]`)

**F14 — Keyboard Shortcuts:**
1. Key event handlers no canvas wrapper (HTMLCanvas.vue) com `@keydown`
2. Arrow keys movem 1px, Shift+Arrow move 10px (ou `gridSize`), Alt+Arrow resize 1px
3. Ctrl+D duplica, Delete remove
4. Todos os shortcuts integram com undo stack

## Acceptance Criteria

1. **AC1 — Snap Line Rendering:** Durante drag de um elemento, quando snap magnético ativa (threshold 8px), linhas magenta (#FF00FF) de 1px aparecem no canvas indicando o alinhamento (horizontal e/ou vertical)
2. **AC2 — Distance Labels:** As snap lines exibem labels com a distância em pixels entre o elemento arrastado e o elemento de referência (ex: "12px")
3. **AC3 — Line Cleanup:** As snap lines desaparecem imediatamente quando o drag/resize termina (mouseup ou escape)
4. **AC4 — Arrow Move 1px:** Com elemento selecionado, pressionar Arrow key move o elemento 1px na direção correspondente
5. **AC5 — Shift+Arrow Move Grid:** Shift+Arrow move o elemento por `gridSize` pixels (ou 10px se grid desabilitado)
6. **AC6 — Alt+Arrow Resize:** Alt+Arrow redimensiona o elemento em 1px na direção correspondente (Right/Down aumenta, Left/Up diminui)
7. **AC7 — Ctrl+D Duplicate:** Ctrl+D duplica o elemento selecionado com offset de +10px em x e y
8. **AC8 — Delete Remove:** Delete key remove o elemento selecionado (com confirmação se configurado)
9. **AC9 — Undo Integration:** Todas as operações de keyboard (move, resize, duplicate, delete) participam do undo stack via `pushUndoSnapshot()`
10. **AC10 — Snap Toggle Respect:** Snap lines só aparecem quando `editorStore.snapEnabled === true`
11. **AC11 — Sem Regressão:** Drag/resize com mouse continuam funcionando normalmente; CanvasGuides.vue não é afetado

### Padrões Existentes a Seguir

**Overlay pattern (CanvasGuides.vue):**
- Componente posicionado absolutamente sobre o canvas content area
- `pointer-events: none` para não interferir com interações
- Recebe dados via props reativos
- Seguir o mesmo padrão para SnapLineOverlay

**Composable pattern (useCanvasInteraction.ts):**
- Retorna refs reativas e handlers
- Composable usado dentro do setup de HTMLCanvas.vue
- `useCanvasKeyboard.ts` deve seguir o mesmo padrão: receber refs, retornar handlers

**Undo pattern (templateStore.ts):**
- `pushUndoSnapshot()` antes de qualquer mutação
- Stack de até 20 snapshots
- Para keyboard moves consecutivos, usar debounce para agrupar em um snapshot

### Stack Técnico

- **Vue 3:** v3.5.25 — Composition API, composables
- **TypeScript:** strict mode
- **Pinia:** v3.0.4 — stores como single source of truth
- **Vitest:** v4.1.0 + @vue/test-utils v2.4.6

### Performance Considerations

- Snap lines são renderizadas durante drag — devem manter 60fps
- Usar CSS transforms ou SVG para rendering eficiente (evitar layout thrash)
- Labels de distância: calcular apenas para snap lines ativas (tipicamente 1-4 linhas simultâneas)
- Keyboard handlers: debounce undo snapshots, não debounce o move visual (deve ser instantâneo)

### UX Reference

- **Figma:** Linhas magenta (#FF00FF), labels de distância em vermelho com fundo branco
- **Photoshop:** Smart Guides — mesma cor, mesma aparição/desaparição
- **Padrão adotado:** Figma — por ser o mais familiar para operadores de templates
