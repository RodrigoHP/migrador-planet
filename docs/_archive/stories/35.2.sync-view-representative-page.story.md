# Story 35.2 — SyncView usa pagina representativa do Layout Type ativo

- **ID:** 35.2
- **Title:** SyncView usa pagina representativa do Layout Type ativo
- **Type:** feature
- **Status:** Done
- **Priority:** P2
- **Epic:** 35
- **Complexity:** S

## Story

As a template operator, I want the SyncView to automatically navigate to the representative page of the active layout type, so that the PDF panel always shows the relevant page for the layout I'm editing.

## Acceptance Criteria

- [x] Ao carregar PDF, usa `layoutStore.activeLayout.representativePages[0]`
- [x] Ao trocar Layout Type, navega para pagina representativa correspondente
- [x] PDF exibido corresponde ao layout selecionado na toolbar

## Tasks

- [x] Watch `layoutStore.activeLayoutId` no SyncView
- [x] Scroll para a pagina representativa ao trocar layout
- [x] Testes

## Scope

**IN:** PDF page navigation on layout switch
**OUT:** Canvas page navigation (canvas already shows correct layout)
