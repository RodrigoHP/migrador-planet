# Story 30.8 — Exportação e filtragem do log de warnings

## Story
**Como** operador analisando warnings do template,
**Quero** filtrar por categoria e exportar a lista para JSON,
**Para** focar em problemas específicos e compartilhar o log com outros.

## Status
Done

## Business Value
ConsolePanel com 30+ warnings é difícil de analisar. Filtro por categoria e
exportação tornam o painel útil como ferramenta de diagnóstico.

**Estimativa:** 1 story point (S)

## Scope

**IN:**
- Filtro de categoria: chips clicáveis (Todos / não mapeado / table_inconsistent / low_confidence / missing_binding)
- Botão "Exportar JSON" → `JSON.stringify(warnings, null, 2)` + download via link
- Dismiss (✕) por warning individual → salvo em `dismissedWarningIds` (ref local, não persistido)
- Warnings dismissados não aparecem na lista filtrada

**OUT:**
- Exportação CSV
- Persistência de dismiss no localStorage ou backend
- Filtros múltiplos simultâneos

## Acceptance Criteria

- [x] **AC1:** Chip "Todos" selecionado por default → todos os warnings visíveis
- [x] **AC2:** Selecionar chip de categoria → só warnings dessa categoria aparecem
- [x] **AC3:** Botão "Exportar" → download de arquivo JSON com warnings filtrados
- [x] **AC4:** Botão ✕ em warning → warning removido da lista (dismiss local)
- [x] **AC5:** Warnings dismissados não reaparecem ao trocar filtro (dentro da sessão)
