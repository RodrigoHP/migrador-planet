# Story 23.14 — Backlog Findings: Materializar como Stories

## Story
**Como** agente @sm planejando proximos ciclos,
**Quero** que achados colaterais de RCAs virem story drafts automaticamente,
**Para** que melhorias identificadas nao se percam em relatorios.

## Status
Done

## Context

### Problema
Achados colaterais (F-1, F-2, AC-01) sao listados nos relatorios RCA mas nunca viram stories. Sao findings "mortos" — documentados mas nao actionados. O handoff artifact (23.7) aponta para eles mas nao os materializa.

### Design
Na Fase 8, para cada achado colateral:

```
## Materializar Backlog Findings

Para cada finding (F-N ou AC-N) identificado:
1. Criar draft de story em docs/stories/backlog/:
   Arquivo: backlog-{rca-slug}-{N}.md
   
   Conteudo:
   ---
   id: backlog-{N}
   title: "{titulo do achado}"
   type: fix | improvement
   status: Draft
   priority: {derivar da severidade do achado}
   origin: "rca-{date}-{slug}"
   finding: "F-{N}"
   ---
   
   # Backlog — {titulo}
   
   ## Origem
   Identificado durante investigacao rca-{date}-{slug}, finding F-{N}.
   
   ## Contexto
   {descricao do achado colateral}
   
   ## Acao Sugerida
   {recomendacao do investigador}

2. Referenciar no handoff artifact (23.7)
3. Log: "Story draft criada: docs/stories/backlog/{filename}"
```

## Acceptance Criteria
- [ ] Fase 8 gera story draft para cada achado colateral

- [ ] Referencia a RCA de origem e finding ID
- [ ] Diretorio docs/stories/backlog/ criado se necessario
