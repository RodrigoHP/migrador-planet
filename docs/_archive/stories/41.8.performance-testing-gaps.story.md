## Dev Notes

### PERF-001 — StructureTree Virtualization
- Uses `@vueuse/core`'s `useVirtualList` (already a dependency, no new package needed)
- Virtual mode activates when node count >= `virtualThreshold` prop (default: 50)
- In virtual mode: flat list of `{node, depth}` items rendered at absolute positions with fixed `ITEM_HEIGHT = 36px`
- Each item renders a `StructureTreeNode` with `flatMode=true` (disables recursive child rendering)
- `flatMode` prop added to `StructureTreeNode` — when true, children template is skipped
- `useVirtualList` from `@vueuse` handles windowed rendering automatically
- Feature-flagged: `virtualScroll` prop (default: `true`) can be disabled per instance

### PERF-003 — Monaco Bundle Optimization
- `vite.config.ts` `manualChunks` updated to split Monaco into 3 chunks:
  - `monaco-core`: editor UI + minimal runtime
  - `monaco-languages`: CSS/JSON/HTML/TS language features (heavy, deferred)
  - `monaco-workers`: worker infrastructure (deferred until language activates)
- Reduces initial Monaco load to just `monaco-core`

### TEST-004 — LoginPage Unit Tests
- Created `frontend/src/pages/LoginPage.spec.ts` with 6 tests:
  1. Renders page title and subtitle
  2. Renders OAuth (Google) login button
  3. Button enabled by default
  4. Calls `signInWithGoogle` on click
  5. Shows loading state during auth
  6. Shows error toast on auth failure
