# Story 9.2: Diff Mode

## Status
Done

## Story
**As a** operador,
**I want** um modo Diff (toggle na toolbar) que compare páginas representativas do mesmo Layout Type entre documentos lado a lado com highlights automáticos,
**so that** eu possa ver visualmente o que mudou entre instâncias de documentos.

## Acceptance Criteria
1. Toggle "🔀 Diff" na toolbar ativa o Modo Diff (FR41)
2. Painel central mostra comparação lado a lado: Documento A (esquerda) vs Documento B (direita) (FR41)
3. Seletor de documentos: dropdowns para escolher quais dois PDFs comparar
4. Highlights automáticos (FR41):
   - 🟩 Verde: conteúdo/posição idênticos
   - 🟨 Amarelo: posição diferente (mesmo conteúdo)
   - 🟥 Vermelho: novo ou ausente (presente em um, faltando no outro)
5. Painel de resumo abaixo da comparação: lista de inferências (campos opcionais, seções condicionais, variações de layout)
6. Operador pode confirmar/rejeitar cada inferência
7. Usa páginas representativas do Layout Type ativo
8. Desativar Modo Diff retorna às abas normais do painel central
9. Renderização de 2 PDFs simultâneos deve manter performance aceitável: lazy loading de páginas (renderizar apenas página visível), máx resolução 150 DPI para diff view
10. `npm run build` passa sem erros

## Dev Notes
- **FR41**: Modo Diff toggle, lado a lado, highlights verde/amarelo/vermelho, resumo de inferências
- **DiffViewer** organismo (alta complexidade): dois PDF renderers + overlay de highlights
- Dados de highlight do pipeline: `multiDocStore.diffData[]` com `{ elementId, statusA, statusB, diffType }`
- diffType: `'identical'` (verde), `'moved'` (amarelo), `'added'` (vermelho), `'removed'` (vermelho)
- Resumo de inferências: mesmas detecções do MultiDoc Analyzer mas apresentadas no contexto de diff
- Usa PDF.js para renderizar ambos os documentos
- Comparação: alinhar páginas pelo representante do Layout Type ativo
- Dependência: `multiDocStore` (story 9.1) para lista de PDFs e dados de detecção
- Performance: renderizar dois PDFs simultâneos pode ser pesado — considerar lazy loading de páginas
