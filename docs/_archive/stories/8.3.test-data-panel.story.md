# Story 8.3: Painel de Dados de Teste

## Status
Done

## Story
**As a** operador,
**I want** um painel de Dados de Teste na seção inferior onde eu possa gerenciar datasets (upload, validar contra XSD, aplicar no Canvas, executar testes),
**so that** eu possa verificar que o template funciona com diferentes dados.

## Acceptance Criteria
1. **AC1** — Painel inferior aba "Dados de Teste" exibe: lista de datasets (esquerda), detalhes do dataset (direita) (FR42)
2. **AC2** — Lista de datasets: nome, badge de status (✓ validado, ⚠ aviso, ✕ inválido), botão excluir 🗑️; dataset ativo marcado com ●
3. **AC3** — Botão "Upload Dataset": aceita arquivo XML ou JSON, valida contra XSD automaticamente
4. **AC4** — Validação: verifica nomes de campos correspondem ao XSD, tipos correspondem, campos obrigatórios presentes
5. **AC5** — Indicadores de status: ✓ validado (tudo OK), ⚠ aviso (campos opcionais ausentes), ✕ inválido (campos obrigatórios ausentes ou tipo incompatível)
6. **AC6** — Painel de detalhes do dataset: contagem de campos, contagem de loops, tamanho, status
7. **AC7** — Botão "Aplicar no Canvas": renderiza template com dataset selecionado em tempo real no Canvas
8. **AC8** — Botão "Editar Dataset...": abre modal com Monaco Editor para edição inline
9. **AC9** — Máximo 5 datasets por template (limite MVP)
10. **AC10** — `npm run build` passa sem erros
