## Descricao

`template_name` eh input do usuario no upload, persistido como `template_name.txt` no backend e exibido no frontend (TopToolbar, save/export ZIP filename) sem sanitizacao de conteudo.

## Problema Tecnico

- **Backend:** `backend/routers/upload.py:36` — recebe `template_name: str = Form("")` sem validacao
- **Persistencia:** `upload.py:89-90` — grava diretamente como `template_name.txt`
- **Frontend display:** `TopToolbar.vue:10` — exibe via template interpolation (seguro contra XSS)
- **Frontend filename:** `TopToolbar.vue:393` — usado como nome de arquivo no export ZIP

## Fix Proposto

### Backend (upload.py)
Sanitizar `template_name` antes de persistir:
- Strip HTML tags
- Limitar charset a alfanumerico + espacos + hifens + underscores
- Max 100 caracteres
- Trim whitespace

### Frontend (session store)
Sanitizar no `loadFromPipelineResult` como defesa em profundidade.

## Criterios de Aceitacao

- [x] AC1: Backend sanitiza template_name no endpoint upload_unified (strip HTML, charset, max 100 chars)
- [x] AC2: Caracteres especiais/HTML sao removidos antes de persistir
- [x] AC3: Frontend sanitiza template_name ao carregar do pipeline result
- [x] AC4: Teste unitario backend cobre sanitizacao
- [x] AC5: Teste unitario frontend cobre sanitizacao no store

## Escopo

**IN:** upload.py (sanitizacao backend), session.ts (sanitizacao frontend)
**OUT:** Renomear template inline (feature futura), UploadPage.vue (input field — ja usa v-model seguro)

## Riscos

- LOW: Template names existentes com caracteres especiais podem mudar na re-exibicao
